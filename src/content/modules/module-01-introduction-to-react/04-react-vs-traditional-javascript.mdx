# React vs Traditional JavaScript

ការសរសេរ Vanilla JavaScript បែបបុរាណតម្រូវឱ្យ developer តាមដាន និងគ្រប់គ្រង DOM elements ដោយផ្ទាល់ (query selectors, update attributes, sync state)។ រីឯ React ចាត់ទុក UI គឺជាលទ្ធផលដែលឆ្លុះបញ្ចាំងចេញពី state ដោយផ្ទាល់ (`UI = f(State)`)។

### Key Concepts & Rules:

- Vanilla JS តម្រូវឱ្យ developer ធ្វើការ sync រវាង UI និង memory state ដោយដៃ (manual bookkeeping)។
- React ធ្វើបច្ចុប្បន្នភាព UI ដោយស្វ័យប្រវត្តិតាមរយៈ reactive state bindings។
- លុបបំបាត់បញ្ហា spaghetti code ដែលកើតឡើងដោយសារកូដ DOM mutations រាយប៉ាយពាសពេញ file។

### Code Example: Vanilla JS vs Declarative React

```tsx
// Comparison: Updating a dynamic badge
// Vanilla JS
function updateBadge(unreadCount) {
  const el = document.getElementById('badge');
  if (unreadCount > 0) {
    el.innerText = unreadCount;
    el.style.display = 'inline-block';
  } else {
    el.style.display = 'none';
  }
}

// React: purely declarative projection
function UnreadBadge({ count }: { count: number }) {
  if (count <= 0) return null;
  return <span className="bg-rose-500 text-white text-xs px-2 py-0.5 rounded-full">{count}</span>;
}
```
