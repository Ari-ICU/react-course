# React Application Architecture

កម្មវិធី React ត្រូវបានរៀបចំឡើងជាទម្រង់មែកធាង (component tree)។ Root component នឹងបញ្ជូន props ចុះក្រោមទៅកាន់ child components ហើយរាល់ events នឹង trigger ឱ្យមាន state updates ដែលបង្កឱ្យមាន downward reconciliation។

### Key Concepts & Rules:

- Root component (`App` ឬ Root Layout) ដើរតួជាគ្រឹះបង្គោលសម្រាប់ Virtual DOM tree ទាំងមូល។
- Unidirectional props ហូរពីលើចុះក្រោម (top-to-bottom)។
- Lifting state up គឺជាបច្ចេកទេសលើក state ទៅកាន់ parent component រួម ដើម្បីចែករំលែកទិន្នន័យរវាង sibling nodes។

### Code Example: Component Tree Architecture

```jsx
/*
        [App Root]
         ├── [Header]
         │    ├── [Logo]
         │    └── [NavMenu]
         ├── [CourseView]
         │    ├── [ModuleList]  <── (State: selectedModule)
         │    └── [SlideDisplay]
         └── [Footer]
*/
```
