# Creating a React Application

ទោះបីជា Create-React-App ត្រូវបាន deprecated ក៏ដោយ developer សម័យទំនើបប្រើប្រាស់ Vite សម្រាប់បង្កើត Client-Side Single Page Application (SPA) ដែលមានល្បឿនលឿន ឬ Next.js សម្រាប់បង្កើត full-stack web application ដែលគាំទ្រ SEO យ៉ាងល្អប្រសើរ។

### Key Concepts & Rules:

- Vite: ផ្តល់នូវ Hot Module Replacement (HMR) យ៉ាងរហ័សផ្អែកលើ native ES modules និង esbuild។
- Next.js: Full-stack framework ជាមួយ App Router, Server-Side Rendering (SSR), Static Site Generation (SSG) និង Server Actions។

### Code Example: Scaffolding Modern React Applications

```jsx
// Scaffolding a modern SPA with Vite:
npm create vite@latest my-react-app -- --template react-ts

// Scaffolding an enterprise full-stack app with Next.js:
npx create-next-app@latest my-next-app --typescript --tailwind --eslint --app
```
