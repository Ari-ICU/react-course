# Running a React Application

Understanding `npm run dev` for dev server with HMR, `npm run build` for optimized production bundles, and `npm run preview` / `npm start` for production serving.

### Key Concepts & Rules:

- Fast Refresh maintains component state across edits.
- Source maps provide clean browser DevTools debugging.

### Code Example: Standard NPM Scripts

```tsx
// package.json scripts
"scripts": {
  "dev": "next dev",           // Starts local development server
  "build": "next build",       // Compiles production-optimized code
  "start": "next start",       // Runs production server
  "lint": "eslint ."           // Code quality inspection
}
```
