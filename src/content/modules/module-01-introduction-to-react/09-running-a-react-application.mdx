# Running a React Application

ការយល់ដឹងអំពី scripts ដូចជា `npm run dev` សម្រាប់ dev server ជាមួយ HMR, `npm run build` សម្រាប់បង្កើត optimized production bundles, និង `npm run preview` ឬ `npm start` សម្រាប់ serve production build ក្នុងការធ្វើតេស្ត។

### Key Concepts & Rules:

- Fast Refresh រក្សាទុក state របស់ component មិនឱ្យបាត់បង់ពេលកែប្រែកូដ (instant feedback)។
- Source maps ជួយសម្រួលដល់ការ debug កូដនៅលើ browser DevTools ឱ្យឃើញកូដដើមយ៉ាងច្បាស់។

### Code Example: Standard NPM Scripts

```jsx
// package.json scripts
"scripts": {
  "dev": "next dev",           // Starts local development server
  "build": "next build",       // Compiles production-optimized code
  "start": "next start",       // Runs production server
  "lint": "eslint ."           // Code quality inspection
}
```
