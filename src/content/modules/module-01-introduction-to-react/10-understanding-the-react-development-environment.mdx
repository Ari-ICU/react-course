# Understanding the React Development Environment

In development, React StrictMode deliberately mounts and unmounts components twice to uncover accidental side-effects and missing cleanup functions in effects.

### Key Concepts & Rules:

- StrictMode runs effects twice in dev mode to enforce idempotency.
- React Developer Tools browser extension allows inspecting props, state, and render timelines.

### Code Example: React StrictMode Wrapper

```tsx
// React.StrictMode wraps your application tree
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```
