# Module 01: Introduction to React

Understand what React is, its declarative mental model, virtual DOM mechanics, modern Vite tooling, and development environment setup.

## Module Syllabus (10 Lessons)

- **Lesson 01**: What is React? - *A declarative, component-based JavaScript library for building interactive user interfaces created by Meta.*
- **Lesson 02**: Why React? - *Learn why React dominates the modern web ecosystem and developer tooling.*
- **Lesson 03**: React Features - *JSX, Virtual DOM, React Fiber Reconciler, and Server Components.*
- **Lesson 04**: React vs Traditional JavaScript - *Direct DOM manipulation vs React's state-driven reconciliation model.*
- **Lesson 05**: React Application Architecture - *Understanding the unidirectional data tree and component hierarchy.*
- **Lesson 06**: React Project Structure - *Scalable folder layouts for enterprise React and Next.js applications.*
- **Lesson 07**: Creating a React Application - *Scaffolding options: Vite, Next.js, and modern React toolchains.*
- **Lesson 08**: Vite + React - *How Vite leverages native ESM and Rollup for instant developer builds.*
- **Lesson 09**: Running a React Application - *Development server, hot reloading, port binding, and build scripts.*
- **Lesson 10**: Understanding the React Development Environment - *React DevTools, React StrictMode, and double-rendering behavior.*
