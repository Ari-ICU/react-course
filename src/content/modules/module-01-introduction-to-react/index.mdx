# Module 01: Introduction to React

ស្វែងយល់ស៊ីជម្រៅអំពី React គោលគំនិត declarative mental model យន្តការ Virtual DOM ឧបករណ៍ modern Vite tooling និងការរៀបចំ development environment ប្រកបដោយប្រសិទ្ធភាព។

## Module Syllabus (10 Lessons)

- **Lesson 01**: What is React? - *ស្វែងយល់អំពី JavaScript library បែប declarative និង component-based សម្រាប់បង្កើត interactive user interfaces បង្កើតឡើងដោយ Meta។*
- **Lesson 02**: Why React? - *មូលហេតុចម្បងដែលធ្វើឱ្យ React គ្រងតំណែងនាំមុខគេក្នុង modern web ecosystem និង developer tooling។*
- **Lesson 03**: React Features - *លក្ខណៈពិសេសរួមមាន JSX, Virtual DOM, React Fiber Reconciler និង Server Components។*
- **Lesson 04**: React vs Traditional JavaScript - *ការប្រៀបធៀបរវាង direct DOM manipulation និង state-driven reconciliation model របស់ React។*
- **Lesson 05**: React Application Architecture - *ស្វែងយល់អំពីរចនាសម្ព័ន្ធ unidirectional data tree និង component hierarchy។*
- **Lesson 06**: React Project Structure - *ការរៀបចំ folder structure កម្រិត enterprise សម្រាប់ scalable React និង Next.js applications។*
- **Lesson 07**: Creating a React Application - *ជម្រើស scaffolding ពេញនិយមរួមមាន Vite, Next.js និង modern React toolchains។*
- **Lesson 08**: Vite + React - *របៀបដែល Vite ប្រើប្រាស់ native ESM និង Rollup ដើម្បីផ្តល់ build speed យ៉ាងលឿនបំផុត។*
- **Lesson 09**: Running a React Application - *ការដំណើរការ development server, hot reloading (HMR), port binding និង build scripts ផ្សេងៗ។*
- **Lesson 10**: Understanding the React Development Environment - *ការប្រើប្រាស់ React DevTools, React StrictMode និងការយល់ដឹងពី double-rendering behavior ក្នុង development។*
