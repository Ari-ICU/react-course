# JSX Expressions

រាល់ JavaScript expression ត្រឹមត្រូវ (ដូចជា variables, ការគណនាគណិតវិទ្យា, function calls, ឬ ternary operators) អាចដាក់នៅចន្លោះសញ្ញា curly braces `{}` នៅក្នុង JSX បានទាំងអស់។

### Key Concepts & Rules:

- Statements ដូចជា `if`, `for`, `while` មិនអាចសរសេរនៅខាងក្នុង `{}` បានឡើយ។ ត្រូវប្រើ ternary operators ឬ array methods (ដូចជា `.map()`, `.filter()`) ជំនួសវិញ។
- Numbers និង strings នឹងត្រូវបង្ហាញលើ UI ដោយផ្ទាល់ ចំណែកឯ booleans (`true`/`false`), `null`, និង `undefined` ត្រូវបាន React ignore (មិនបង្ហាញលើអេក្រង់ឡើយ)។

### Code Example: Expressions Inside JSX

```tsx
export function UserGreeting({ username, points }: { username: string; points: number }) {
  const multiplier = 1.5;

  return (
    <div className="p-4 bg-slate-900 rounded-lg text-white">
      <h2 className="text-xl">Welcome back, {username.toUpperCase()}!</h2>
      <p className="text-slate-400">
        Adjusted score: {(points * multiplier).toFixed(0)} XP
      </p>
    </div>
  );
}
```
