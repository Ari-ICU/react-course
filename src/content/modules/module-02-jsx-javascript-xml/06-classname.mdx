# className

ដោយសារពាក្យ `class` គឺជា reserved keyword នៅក្នុង JavaScript (ប្រើសម្រាប់ប្រកាស ES6 classes) ដូចនេះ React ប្រើប្រាស់ `className` ជំនួសវិញសម្រាប់កំណត់ឈ្មោះ CSS classes ទៅលើ elements។

### Key Concepts & Rules:

- ប្រើ `className` សម្រាប់គ្រប់ CSS classes ទាំងអស់។
- ប្រើ utility function `cn()` (ការរួមបញ្ចូលគ្នារវាង `clsx` និង `tailwind-merge`) ដើម្បីគ្រប់គ្រង conditional និង dynamic class names ឱ្យមានរបៀបរៀបរយ និងមិនជាន់គ្នា។

### Code Example: className with Dynamic Utility

```tsx
import { cn } from "@/lib/utils";

export function StatusBadge({ status }: { status: "active" | "inactive" | "pending" }) {
  return (
    <span
      className={cn(
        "px-2.5 py-1 text-xs font-semibold rounded-full border",
        status === "active" && "bg-emerald-950/50 text-emerald-400 border-emerald-800",
        status === "pending" && "bg-amber-950/50 text-amber-400 border-amber-800",
        status === "inactive" && "bg-rose-950/50 text-rose-400 border-rose-800"
      )}
    >
      {status.toUpperCase()}
    </span>
  );
}
```
