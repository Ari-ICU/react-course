# JSX Fragments

Fragments (សរសេរពេញ `<React.Fragment>` ឬសរសេរកាត់ `<>...</>`) អនុញ្ញាតឱ្យយើង return sibling elements ច្រើនក្នុងពេលតែមួយ ដោយមិនបាច់បន្ថែម `<div>` tags ឥតប្រយោជន៍ទៅក្នុង DOM tree ឡើយ។

### Key Concepts & Rules:

- ការសរសេរកាត់ `<>...</>` មិនបង្កើត DOM node បន្ថែមឡើយ (zero DOM overhead)។
- Fragments ជួយការពារបញ្ហាខូច layout នៅពេលប្រើប្រាស់ជាមួយ CSS Flexbox ឬ CSS Grid ដែលទាមទារ direct child relationships។
- ប្រសិនបើត្រូវកំណត់ attributes ដូចជា `key` (នៅពេលសិក្សាអំពី dynamic lists នៅ Module 05) ត្រូវប្រើ syntax ពេញ `<React.Fragment key={...}>` ព្រោះទម្រង់កាត់ `<>` មិនអាចទទួល attribute បានឡើយ។

### Code Example: Using React Fragments

```jsx
export function CourseOverview() {
  return (
    <>
      <h2 className="text-xl font-bold text-white">React Fundamentals</h2>
      <p className="text-slate-400">Master JSX, components, and core modern concepts.</p>
      <span className="text-xs text-indigo-400">No extra wrapper DOM node created</span>
    </>
  );
}
```
