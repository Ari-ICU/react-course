# JSX Fragments

Fragments (សរសេរពេញ `<React.Fragment>` ឬសរសេរកាត់ `<>...</>`) អនុញ្ញាតឱ្យយើង return sibling components ច្រើនក្នុងពេលតែមួយ ដោយមិនបាច់បន្ថែម `<div>` tags ឥតប្រយោជន៍ទៅក្នុង DOM tree ឡើយ។

### Key Concepts & Rules:

- ការសរសេរកាត់ `<>...</>` មិនបង្កើត DOM node បន្ថែមឡើយ (zero DOM overhead)។
- ត្រូវប្រើ syntax ពេញ `<React.Fragment key={item.id}>` នៅពេល render fragments នៅក្នុង loop ដែលទាមទារឱ្យមាន `key` prop។

### Code Example: React Fragments with Keys

```tsx
import React from 'react';

export function TableRowGroup({ items }: { items: { id: string; label: string; value: string }[] }) {
  return (
    <dl className="grid grid-cols-2 gap-2">
      {items.map((item) => (
        // Key is required here, so use explicit React.Fragment:
        <React.Fragment key={item.id}>
          <dt className="text-slate-400 font-medium">{item.label}</dt>
          <dd className="text-white text-right">{item.value}</dd>
        </React.Fragment>
      ))}
    </dl>
  );
}
```
