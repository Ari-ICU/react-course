# JSX Rules

គោលការណ៍គ្រឹះ ៤ យ៉ាងនៃ JSX រួមមាន៖ ១) ត្រូវតែ return single root element (ឬ Fragment); ២) ត្រូវតែបិទ tags ទាំងអស់ (close all tags); ៣) ប្រើប្រាស់ camelCase សម្រាប់ attributes ស្ទើរតែទាំងអស់; ៤) ប្រើ double quotes `""` សម្រាប់ static strings និង curly braces `{}` សម្រាប់ dynamic expressions។

### Key Concepts & Rules:

- ទាមទារ single parent element ជាដាច់ខាត។
- រាល់ HTML elements ទាំងអស់ត្រូវតែបិទ (closed explicitly)។
- Attribute `style` ត្រូវតែជា JavaScript object មិនមែនជា CSS string ធម្មតាឡើយ។

### Code Example: JSX Core Rules Summary

```jsx
// Summary of Core JSX Rules:
// 1. Single Root
return <div className="card">...</div>;

// 2. Closed Tags
<input type="text" />

// 3. camelCase
<input tabIndex={0} autoComplete="off" />

// 4. Expression braces
<h1>{`Hello ${user.name}`}</h1>
```
