# JSX Rules

JSX requires: 1) Return a single root element (or Fragment); 2) Close all tags; 3) camelCase most attributes; 4) Quote static strings with `""` and dynamic expressions with `{}`.

### Key Concepts & Rules:

- Single parent element required.
- All elements must be closed explicitly.
- Style must be an object, not a CSS string.

### Code Example: JSX Core Rules Summary

```tsx
// Summary of Core JSX Rules:
// 1. Single Root
return <div className="card">...</div>;

// 2. Closed Tags
<input type="text" />

// 3. camelCase
<button onClick={handleClick} tabIndex={0}>Click</button>

// 4. Expression braces
<h1>{`Hello ${user.name}`}</h1>
```
