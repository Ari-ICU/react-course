# Common JSX Mistakes

កំហុសដែលកើតឡើងញឹកញាប់បំផុតនៅក្នុង JSX គឺការប្រើប្រាស់ `count && <Component />`៖ ប្រសិនបើ `count` ស្មើ `0` នោះ JavaScript នឹង evaluate `0 && ...` ស្មើ `0` ដែលធ្វើឱ្យលេខ `0` បង្ហាញលើអេក្រង់ជំនួសឱ្យការលាក់បាត់!

### Key Concepts & Rules:

- មិនត្រូវសរសេរ `items.length && <List />` ឡើយ -> ត្រូវប្តូរមកប្រើ `items.length > 0 && <List />` ឬប្រើ ternary `items.length ? <List /> : null`។
- ជៀសវាងការប្រើប្រាស់ array index ជា `key` នៅពេលដែលបញ្ជីទិន្នន័យអាចមានការតម្រៀបឡើងវិញ (reorder) ឬលុបចេញ (remove)។

### Code Example: The Logical AND Zero Bug

```jsx
import React, { useState } from 'react';

export function MessageNotificationCenter() {
  const [messages, setMessages] = useState<string[]>([]);

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-4">
      <h4 className="text-white font-bold">Notification Inbox</h4>

      {/* ❌ PITFALL: When messages is empty (length === 0), JavaScript renders the number "0" onto the screen!
          <div>{messages.length && <span>You have new messages</span>}</div>
      */}

      {/* ✅ FIX 1: Explicit boolean comparison > 0 */}
      <div>
        {messages.length > 0 && (
          <span className="px-2 py-1 bg-blue-600 text-white text-xs rounded-full">
            {messages.length} New Messages
          </span>
        )}
      </div>

      {/* ✅ FIX 2: Ternary operator */}
      <p className="text-xs text-slate-400">
        {messages.length > 0
          ? 'Click to view unread conversations'
          : 'Inbox is completely clear'}
      </p>

      <button
        onClick={() => setMessages(prev => [...prev, 'New alert'])}
        className="px-3 py-1 bg-slate-800 hover:bg-slate-700 text-white rounded text-xs"
      >
        Receive Test Message
      </button>
    </div>
  );
}
```
