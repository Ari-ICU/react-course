# Module 02: JSX (JavaScript XML)

Master JSX syntax rules, expressions, attribute mappings, inline styling, Fragments, and conditional rendering techniques.

## Module Syllabus (12 Lessons)

- **Lesson 01**: What is JSX? - *Syntax extension for JavaScript that looks like HTML and compiles to React elements.*
- **Lesson 02**: JSX Syntax - *Tags must close, self-closing tags, and single parent element rules.*
- **Lesson 03**: JSX Expressions - *Embedding dynamic expressions, calculations, and variables inside curly braces.*
- **Lesson 04**: JavaScript inside JSX - *Function invocation, template literals, and object references.*
- **Lesson 05**: JSX Attributes - *camelCase property naming conventions and boolean props.*
- **Lesson 06**: className - *Why React uses className instead of class for CSS styling.*
- **Lesson 07**: Inline Styles - *Passing style objects with camelCase keys to the style attribute.*
- **Lesson 08**: JSX Fragments - *Grouping lists of children without adding extra wrapper DOM nodes.*
- **Lesson 09**: Conditional JSX - *Ternary operators, early returns, and logical short-circuiting.*
- **Lesson 10**: Rendering Dynamic Content - *Displaying dynamic strings, numbers, dates, and localized strings.*
- **Lesson 11**: JSX Rules - *Strict closing tags, single root element, and property casing rules.*
- **Lesson 12**: Common JSX Mistakes - *Rendering 0 with logical AND `&&`, forgetting keys, and class vs className.*
