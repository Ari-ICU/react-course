# Module 02: JSX (JavaScript XML)

ស្វែងយល់ស៊ីជម្រៅអំពី JSX syntax rules ការប្រើប្រាស់ expressions ការកំណត់ attributes ការប្រើប្រាស់ inline styles, Fragments និងបច្ចេកទេស conditional rendering ទំនើបៗ។

## Module Syllabus (12 Lessons)

- **Lesson 01**: What is JSX? - *ស្វែងយល់ពី syntax extension សម្រាប់ JavaScript ដែលមានទម្រង់ដូច HTML និង compile ទៅជា React elements។*
- **Lesson 02**: JSX Syntax - *គោលការណ៍បិទ tags ឱ្យបានត្រឹមត្រូវ self-closing tags និងច្បាប់នៃ single parent element។*
- **Lesson 03**: JSX Expressions - *ការបង្កប់ dynamic expressions ការគណនា និង variables នៅខាងក្នុង curly braces `{}`។*
- **Lesson 04**: JavaScript inside JSX - *ការហៅ function ដំណើរការ ការប្រើប្រាស់ template literals និងការទាញយក object properties។*
- **Lesson 05**: JSX Attributes - *ក្បួនដាក់ឈ្មោះ attributes ជាទម្រង់ camelCase និងការប្រើប្រាស់ boolean props។*
- **Lesson 06**: className - *មូលហេតុដែល React ប្រើប្រាស់ className ជំនួសឱ្យ class សម្រាប់កំណត់ CSS styling។*
- **Lesson 07**: Inline Styles - *ការបញ្ជូន style objects ដោយប្រើ camelCase keys ទៅកាន់ style attribute។*
- **Lesson 08**: JSX Fragments - *ការប្រមូលផ្តុំបញ្ជី children ច្រើនបញ្ចូលគ្នាដោយមិនបាច់បន្ថែម wrapper DOM nodes ឥតប្រយោជន៍។*
- **Lesson 09**: Conditional JSX - *ការប្រើប្រាស់ ternary operators, early returns និង logical short-circuiting។*
- **Lesson 10**: Rendering Dynamic Content - *ការបង្ហាញ dynamic strings, numbers, dates និង localized strings នៅលើ UI។*
- **Lesson 11**: JSX Rules - *សេចក្តីសង្ខេបអំពីច្បាប់បិទ tags ឱ្យបានម៉ត់ចត់ single root element និង property casing។*
- **Lesson 12**: Common JSX Mistakes - *កំហុសទូទៅដូចជាការ render ចេញលេខ 0 ពេលប្រើ logical AND `&&`, ការភ្លេចដាក់ keys និងបញ្ហា class vs className។*
