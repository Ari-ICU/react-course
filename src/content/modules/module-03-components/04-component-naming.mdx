# Component Naming

React components ត្រូវតែចាប់ផ្តើមដោយអក្សរធំជានិច្ច (`PascalCase`)។ ប្រសិនបើ component ចាប់ផ្តើមដោយអក្សរតូច JSX នឹងចាត់ទុកវាជា built-in HTML tag ធម្មតាដូចជា `<div>`, `<span>` ឬ `<header>` ដែលបណ្តាលឱ្យ React មិនអាចស្គាល់ component របស់អ្នកបានឡើយ។

### Key Concepts & Rules:

- ប្រើប្រាស់ PascalCase ជានិច្ចសម្រាប់ React components ដូចជា `UserProfile`, `NavigationDrawer`, `ProductCard`។
- ដាក់ឈ្មោះ helper/child components ឱ្យមានលំដាប់លំដោយសមហេតុផលដូចជា `CardHeader`, `CardBody`, `CardFooter`។
- ដាក់ឈ្មោះឱ្យឆ្លុះបញ្ចាំងពីមុខងារជាក់ស្តែង (Domain-driven) ជៀសវាងឈ្មោះទូទៅពេកដូចជា `Item` ឬ `Data`។

### Code Example: PascalCase Naming Rule

```jsx
import React from 'react';

// ❌ INCORRECT: Lowercase is treated by JSX parser as native HTML tag:
// function userAvatar() { return <img>...</img>; } // JSX evaluates <userAvatar /> as <useravatar></useravatar>

// ✅ CORRECT: PascalCase is recognized by React as a custom component:
function UserAvatar({ src, alt }: { src: string; alt: string }) {
  return <img src={src} alt={alt} className="w-10 h-10 rounded-full border border-slate-700" />;
}

// ✅ Predictable Domain-Driven naming hierarchy:
export function UserProfileCard() {
  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl flex items-center gap-3">
      <UserAvatar src="/avatars/dara.jpg" alt="Dara Chan" />
      <div>
        <h4 className="text-white font-bold text-sm">Dara Chan</h4>
        <p className="text-xs text-slate-400">Full-Stack Engineer</p>
      </div>
    </div>
  );
}
```
