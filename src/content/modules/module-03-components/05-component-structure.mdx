# Component Structure

រចនាសម្ព័ន្ធ component ដែលមានស្តង់ដារច្បាស់លាស់ជួយឱ្យកូដមានភាពងាយស្រួលក្នុងការអាន និងស្មានដឹងជាមុន (Predictable)៖ ១) Imports; ២) Component declaration; ៣) Internal variables & helper logic; ៤) JSX return statement។ (នៅ Modules បន្តបន្ទាប់ យើងនឹងបន្ថែម Props, Event Handlers និង State ទៅក្នុងរចនាសម្ព័ន្ធនេះជាបន្តបន្ទាប់)។

### Key Concepts & Rules:

- រៀបចំ import statements ទាំងអស់នៅផ្នែកខាងលើបង្អស់នៃ file។
- រៀបចំ variables និង helper formatting logic មុនពេល return JSX។
- return JSX markup យ៉ាងច្បាស់លាស់ និងមាន structure ងាយយល់។

### Code Example: Predictable Component Layout Structure

```jsx
// 1. Imports
import { Sparkles } from 'lucide-react';

// 2. Component Declaration
export function WelcomeBanner() {
  // 3. Variables & Helper Logic
  const courseTitle = "Mastering Modern React";
  const badgeText = "Foundations";

  // 4. JSX Return
  return (
    <div className="p-6 bg-slate-900 border border-slate-800 rounded-2xl space-y-2">
      <div className="inline-flex items-center gap-1.5 px-2.5 py-0.5 rounded-full bg-indigo-500/10 text-indigo-400 text-xs font-medium">
        <Sparkles className="w-3.5 h-3.5" />
        <span>{badgeText}</span>
      </div>
      <h2 className="text-xl font-bold text-white">{courseTitle}</h2>
      <p className="text-sm text-slate-400">
        Learn React step-by-step with clean component structure.
      </p>
    </div>
  );
}
```
