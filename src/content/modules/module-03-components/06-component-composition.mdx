# Component Composition

Composition គឺជាអានុភាពដ៏ខ្លាំងក្លាបំផុតរបស់ React (React's core superpower)។ ជំនួសឱ្យការសរសេរកូដ UI ទាំងអស់ចូលគ្នាក្នុង monolithic component ដ៏ធំមួយ វិធីសាស្ត្រត្រឹមត្រូវគឺការផ្គុំ components តូចៗដែលផ្តោតលើមុខងារតែមួយបញ្ចូលគ្នា។

### Key Concepts & Rules:

- បំបែកអេក្រង់ធំៗឱ្យទៅជា components តូចៗដែលឯករាជ្យពីគ្នា។
- ផ្គុំ components តូចៗទាំងនោះបញ្ចូលគ្នានៅក្នុង layout ឬ page component ធំមួយ។
- ជួយបង្កើនភាពច្បាស់លាស់នៃកូដ និងងាយស្រួលក្នុងការ debug។

### Code Example: Component Composition Pattern

```jsx
function Header() {
  return (
    <header className="p-4 bg-slate-900 border-b border-slate-800">
      <h1 className="text-xl font-bold text-white">Dashboard Overview</h1>
    </header>
  );
}

function Sidebar() {
  return (
    <aside className="w-64 p-4 bg-slate-900/50 border-r border-slate-800 text-slate-300">
      <nav className="space-y-2">
        <p className="text-sm font-semibold text-slate-400">Navigation</p>
        <p className="text-sm hover:text-white cursor-pointer">Analytics</p>
        <p className="text-sm hover:text-white cursor-pointer">Settings</p>
      </nav>
    </aside>
  );
}

function ContentArea() {
  return (
    <main className="flex-1 p-6 text-slate-200">
      <h2 className="text-lg font-semibold text-white">Main Activity</h2>
      <p className="text-sm text-slate-400 mt-1">Here is your daily activity feed.</p>
    </main>
  );
}

// Composing multiple components together into a complete page
export function DashboardPage() {
  return (
    <div className="min-h-screen bg-slate-950 flex flex-col">
      <Header />
      <div className="flex flex-1">
        <Sidebar />
        <ContentArea />
      </div>
    </div>
  );
}
```
