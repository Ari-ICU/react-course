# Reusable Components

Reusable component គឺជា component ដែលត្រូវបានបង្កើតឡើងយ៉ាងមានរបៀបរៀបរយ ដើម្បីអាចយកទៅហៅប្រើប្រាស់ឡើងវិញបានច្រើនកន្លែងនៅក្នុង application ដោយមិនបាច់សរសេរកូដ JSX ដដែលៗឡើងវិញឡើយ។

### Key Concepts & Rules:

- បង្កើត component តែមួយដង តែអាចយកទៅ reuse បាននៅគ្រប់ទីកន្លែងក្នុង application។
- កាត់បន្ថយការចម្លង markup និង styles ដដែលៗ (DRY - Don't Repeat Yourself)។
- ងាយស្រួលកែសម្រួល UI ពីព្រោះនៅពេលកែ component ដើមតែមួយ កន្លែងដែលបាន reuse ទាំងអស់នឹង update ដោយស្វ័យប្រវត្តិ។

### Code Example: Reusing Components Across the UI

```jsx
// 1. Self-contained component with its own markup and styles
export function SubscribeCard() {
  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl text-center space-y-3">
      <h3 className="font-semibold text-white">Subscribe to Newsletter</h3>
      <p className="text-xs text-slate-400">Get modern React tips directly in your inbox.</p>
      <button className="px-4 py-1.5 bg-blue-600 hover:bg-blue-700 text-white text-sm rounded-lg transition-colors">
        Subscribe Now
      </button>
    </div>
  );
}

// 2. Reusing the exact same component in different pages/sections
export function HomePage() {
  return (
    <div className="space-y-6 max-w-xl mx-auto">
      <section className="p-4 bg-slate-950 border border-slate-800 rounded-lg">
        <h2 className="text-sm font-semibold text-slate-400 mb-3">Main Content</h2>
        <SubscribeCard />
      </section>

      <section className="p-4 bg-slate-950 border border-slate-800 rounded-lg">
        <h2 className="text-sm font-semibold text-slate-400 mb-3">Sidebar Widget</h2>
        <SubscribeCard />
      </section>
    </div>
  );
}
```
