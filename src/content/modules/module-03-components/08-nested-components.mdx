# Nested Components

យើងអាច render components បង្កប់គ្នាក្នុង parent-child hierarchy បានយ៉ាងងាយស្រួល។ ប៉ុន្តែសូមកុំប្រកាស (declare) function component មួយនៅខាងក្នុង body នៃ component មួយផ្សេងទៀតឱ្យសោះ ព្រោះវានឹងត្រូវ re-create ថ្មីរាល់ពេល render ដែលនាំឱ្យបាត់បង់ state ខាងក្នុង និងបញ្ហា performance ធ្ងន់ធ្ងរ។

### Key Concepts & Rules:

- ត្រូវប្រកាស child components នៅ module scope (ខាងក្រៅ parent component) ជានិច្ច។
- បញ្ជូនទិន្នន័យពី parent ទៅកាន់ child components តាមរយៈ props។
- រៀបចំ component tree ឱ្យមាន hierarchy ច្បាស់លាស់ដើម្បីងាយស្រួលតាមដាន data flow។

### Code Example: Properly Nesting Components

```tsx
// ❌ Anti-pattern: Defining child inside parent
/*
function Parent() {
  function Child() { return <div>Recreated every render!</div>; }
  return <Child />;
}
*/

// ✅ Correct: Declared at module scope
function Child({ title }: { title: string }) {
  return <li className="text-slate-300 py-1">{title}</li>;
}

export function Parent() {
  return (
    <ul className="list-disc pl-5">
      <Child title="First Topic" />
      <Child title="Second Topic" />
    </ul>
  );
}
```
