# Nested Components

យើងអាច render components បង្កប់គ្នាក្នុង parent-child hierarchy បានយ៉ាងងាយស្រួល។ ប៉ុន្តែសូមកុំប្រកាស (declare) function component មួយនៅខាងក្នុង body នៃ component មួយផ្សេងទៀតឱ្យសោះ ព្រោះវានឹងត្រូវ re-create ថ្មីរាល់ពេល render ដែលនាំឱ្យបាត់បង់ state ខាងក្នុង និងបញ្ហា performance ធ្ងន់ធ្ងរ។

### Key Concepts & Rules:

- ត្រូវប្រកាស child components នៅ module scope (ខាងក្រៅ parent component) ជានិច្ច។
- ហៅប្រើប្រាស់ child components នៅក្នុង JSX នៃ parent component តាមរយៈ syntax `<ChildComponent />`។
- រៀបចំ component tree ឱ្យមាន hierarchy ច្បាស់លាស់ដើម្បីងាយស្រួលអាន និងថែទាំ។

### Code Example: Properly Nesting Components

```jsx
// ❌ Anti-pattern: Defining child component INSIDE parent component
/*
function Parent() {
  // Re-declared on every single render!
  function UserAvatar() { 
    return <div className="w-10 h-10 rounded-full bg-blue-500" />; 
  }
  return <UserAvatar />;
}
*/

// ✅ Correct: Declared at module scope (outside parent)
function UserAvatar() {
  return (
    <div className="w-10 h-10 rounded-full bg-gradient-to-tr from-blue-500 to-indigo-600 flex items-center justify-center text-white font-bold">
      R
    </div>
  );
}

function UserDetails() {
  return (
    <div>
      <p className="text-sm font-medium text-white">Ratha Tech</p>
      <p className="text-xs text-slate-400">Full-Stack Developer</p>
    </div>
  );
}

// Parent rendering nested child components
export function UserCard() {
  return (
    <div className="flex items-center gap-3 p-4 bg-slate-900 border border-slate-800 rounded-xl">
      <UserAvatar />
      <UserDetails />
    </div>
  );
}
```
