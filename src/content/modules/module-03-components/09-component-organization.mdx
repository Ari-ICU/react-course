# Component Organization

រក្សា atomic primitives ទូទៅនៅក្នុង `@/components/ui` (ដូចជា Button, Input), រក្សា composite widgets នៅក្នុង `@/components` (ដូចជា Header, Sidebar) និងរក្សា domain-specific components នៅក្នុង `@/features` (ដូចជា CartDrawer, StudentTable)។

### Key Concepts & Rules:

- Atomic Primitives: Button, Input, Checkbox, Badge (មិនមាន business logic)។
- Compound Components: Modal, DropdownMenu, NavigationDrawer។
- Feature Components: StudentTable, CartDrawer, ProductGrid (ចងភ្ជាប់ជាមួយ feature logic)។

### Code Example: Component Tier Hierarchy

```tsx
src/
├── components/
│   ├── ui/             # Primitives: Button.tsx, Input.tsx
│   └── layout/         # Header.tsx, Sidebar.tsx
└── features/
    └── cart/           # CartDrawer.tsx, CartItem.tsx, CartSummary.tsx
```
