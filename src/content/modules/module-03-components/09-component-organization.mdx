# Component Organization

Keep generic atomic components in `@/components/ui`, complex compound widgets in `@/components`, and domain-specific logic in `@/features`.

### Key Concepts & Rules:

- Atomic primitives: Button, Input, Checkbox, Badge.
- Compound components: Modal, DropdownMenu, NavigationDrawer.
- Feature components: StudentTable, CartDrawer, ProductGrid.

### Code Example: Component Tier Hierarchy

```tsx
src/
├── components/
│   ├── ui/             # Primitives: Button.tsx, Input.tsx
│   └── layout/         # Header.tsx, Sidebar.tsx
└── features/
    └── cart/           # CartDrawer.tsx, CartItem.tsx, CartSummary.tsx
```
