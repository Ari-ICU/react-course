# Feature-based Components

Feature folders ជួយប្រមូលផ្តុំរាល់អ្វីៗទាំងអស់ដែលពាក់ព័ន្ធនឹង business domain តែមួយនៅកន្លែងតែមួយ៖ components, hooks, utils, និង API services។ នៅពេលអ្នកចង់កែប្រែ ឬលុប feature ណាមួយចេញ រាល់ files ពាក់ព័ន្ធទាំងអស់ស្ថិតនៅជាមួយគ្នា មិនរាយប៉ាយឡើយ។

### Key Concepts & Rules:

- បង្កើន maintainability នៃ project នៅពេលដែល codebase រីកធំឡើងលើសពី ១០០+ files។
- បង្កើតព្រំដែនច្បាស់លាស់រវាង feature-specific code និង shared reusable UI components។
- ងាយស្រួលក្នុងការធ្វើ code review, testing និង onboarding សមាជិកថ្មីក្នុងក្រុម។

### Code Example: Feature Folder Structure

```jsx
features/auth/
├── components/
│   ├── LoginForm.jsx
│   ├── RegisterModal.jsx
│   └── PasswordStrength.jsx
├── hooks/
│   └── useAuth.js
├── services/
│   └── authApi.js
└── utils/
    └── authHelper.js
```
