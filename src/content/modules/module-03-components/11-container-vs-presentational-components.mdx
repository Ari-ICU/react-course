# Container vs Presentational Components

Presentational components ផ្តោតតែទៅលើការបង្ហាញរូបរាង UI ប៉ុណ្ណោះ (Visual layout និង styles)។ ចំណែកឯ Container components ផ្តោតលើការរៀបចំ structural layout (ដែលយើងនឹងបន្ថែម props និង state នៅ Modules បន្តបន្ទាប់)។

### Key Concepts & Rules:

- Presentational (Pure UI): ផ្តោតលើ visual elements, CSS styles និង HTML structure។
- Container (Structural / Layout): រៀបចំ layout wrapper និងកំណត់ទីតាំងសម្រាប់ presentational components។
- ជួយឱ្យកូដមានភាពច្បាស់លាស់ ងាយស្រួលរៀបចំ និង reuse។

### Code Example: Container vs Presentational Pattern

```jsx
// 1. Presentational Component: Focuses purely on visual UI layout & styling
export function ProfileCardUI() {
  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-2xl text-center max-w-sm mx-auto">
      <div className="w-16 h-16 mx-auto rounded-full bg-indigo-600 flex items-center justify-center text-white text-xl font-bold">
        RT
      </div>
      <h3 className="mt-3 text-lg font-bold text-white">Ratha Tech</h3>
      <p className="text-sm text-slate-400">Frontend Engineer</p>
      <div className="mt-4 pt-3 border-t border-slate-800 flex justify-around text-xs text-slate-300">
        <span>12 Courses</span>
        <span>48 Projects</span>
      </div>
    </div>
  );
}

// 2. Container Component: Provides structural layout wrapper
export function ProfileContainer() {
  return (
    <section className="p-8 bg-slate-950 border border-slate-800/60 rounded-3xl max-w-md mx-auto">
      <h2 className="text-xs uppercase tracking-wider text-slate-400 font-semibold mb-4 text-center">
        User Profile Overview
      </h2>
      <ProfileCardUI />
    </section>
  );
}
```
