# Component Best Practices

រក្សា components ឱ្យមានទំហំល្មម និងផ្តោតលើទំនួលខុសត្រូវតែមួយ (Single Responsibility Principle)។ ប្រសិនបើ component មួយទទួល props លើសពី ៧-៨ props អ្នកគួរពិចារណាប្រមូលផ្តុំ props ទាំងនោះជា object តែមួយ ឬបំបែកវាទៅជា compound components។

### Key Concepts & Rules:

- រក្សា component ឱ្យមាន Purity៖ នៅពេលទទួលបាន props ដដែល ត្រូវតែ return JSX ដូចគ្នាជានិច្ច។
- ជៀសវាង side effects ក្នុងអំឡុងពេល rendering (ដូចជាការ mutate external variables) — ត្រូវធ្វើ side effects នៅក្នុង `useEffect` ឬ event handlers ប៉ុណ្ណោះ។
- កុំសរសេរ component តែមួយឱ្យទទួលបន្ទុកច្រើនពេក (Do one thing and do it well)។

### Code Example: Enforcing Component Purity

```tsx
// Golden Rule of React: Purity during render
// ❌ Impure: Mutating external variables during render
let renderCount = 0;
function BadComponent() {
  renderCount++; // Side effect!
  return <div>Render {renderCount}</div>;
}

// ✅ Pure: Rendering has no observable external mutations
function GoodComponent({ title }: { title: string }) {
  return <h2 className="text-xl font-semibold">{title}</h2>;
}
```
