# Module 03: Components

Functional components, naming conventions, component composition, nested architectures, and container vs presentational patterns.

## Module Syllabus (12 Lessons)

- **Lesson 01**: What is a Component? - *The primary reusable, self-contained UI building block in React.*
- **Lesson 02**: Functional Components - *Modern standard for React components using standard JavaScript functions.*
- **Lesson 03**: Creating Components - *Writing, exporting, importing, and organizing components across files.*
- **Lesson 04**: Component Naming - *PascalCase convention and domain naming guidelines.*
- **Lesson 05**: Component Structure - *Internal organization: imports, interfaces, state, handlers, and JSX return.*
- **Lesson 06**: Component Composition - *Building complex interfaces by assembling smaller atomic pieces.*
- **Lesson 07**: Reusable Components - *Designing flexible, configurable UI building blocks.*
- **Lesson 08**: Nested Components - *Rendering child components inside parent trees without defining them inline.*
- **Lesson 09**: Component Organization - *Organizing generic UI components vs page-specific components.*
- **Lesson 10**: Feature-based Components - *Structuring by business capability rather than technical role.*
- **Lesson 11**: Container vs Presentational Components - *Separating data fetching and business logic from visual rendering.*
- **Lesson 12**: Component Best Practices - *Single responsibility principle, purity, and prop count hygiene.*
