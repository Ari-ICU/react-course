# Module 03: Components

ស្វែងយល់ស៊ីជម្រៅអំពី Functional Components, ក្បួនដាក់ឈ្មោះ PascalCase, យុទ្ធសាស្ត្រ Component Composition, រចនាសម្ព័ន្ធ Nested Architecture និង Container vs Presentational patterns។

## Module Syllabus (12 Lessons)

- **Lesson 01**: What is a Component? - *ស្វែងយល់អំពី UI building block ស្នូលដែលមានភាពឯករាជ្យ និងអាចយកទៅប្រើឡើងវិញបានក្នុង React។*
- **Lesson 02**: Functional Components - *ស្តង់ដារទំនើបសម្រាប់បង្កើត React components ដោយប្រើ JavaScript functions ជាមួយ Hooks។*
- **Lesson 03**: Creating Components - *របៀបសរសេរ ការ export ការ import និងការរៀបចំ components ឆ្លងកាត់ files ផ្សេងៗ។*
- **Lesson 04**: Component Naming - *ក្បួនដាក់ឈ្មោះ PascalCase និងគោលការណ៍ណែនាំដាក់ឈ្មោះតាម domain business។*
- **Lesson 05**: Component Structure - *ការរៀបចំរចនាសម្ព័ន្ធផ្ទៃក្នុង៖ imports, types, state, event handlers និង JSX return។*
- **Lesson 06**: Component Composition - *ការផ្គុំ UI ស្មុគស្មាញដោយការផ្គុំ atomic components តូចៗបញ្ចូលគ្នា (Composition over Inheritance)។*
- **Lesson 07**: Reusable Components - *ការឌីហ្សាញ UI components ដែលមានភាពបត់បែនខ្ពស់ អាចកំណត់ props និង extensible តាមតម្រូវការ។*
- **Lesson 08**: Nested Components - *ការបង្ហាញ child components នៅខាងក្នុង parent tree ដោយជៀសវាងការប្រកាស function នៅខាងក្នុង body ផ្ទាល់។*
- **Lesson 09**: Component Organization - *ការរៀបចំ atomic UI components ទូទៅ និង page-specific components ឱ្យមានរបៀបរៀបរយ។*
- **Lesson 10**: Feature-based Components - *ការរៀបចំ folders តាម domain capability ជំនួសឱ្យការបែងចែកតាម technical role។*
- **Lesson 11**: Container vs Presentational Components - *ការបំបែក business logic និង data fetching ចេញពីការ render visual UI ឱ្យដាច់ពីគ្នា។*
- **Lesson 12**: Component Best Practices - *គោលការណ៍ Single Responsibility, Component Purity និងការគ្រប់គ្រង props ឱ្យមានអនាម័យកូដល្អ។*
