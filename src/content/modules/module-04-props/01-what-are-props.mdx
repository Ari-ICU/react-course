# What are Props?

Props (short for properties) are the mechanism by which parent components pass data and callback functions downward to child components. Props are strictly read-only (immutable) within the child component.

### Key Concepts & Rules:

- Props flow unidirectionally from parent to child.
- Components must never modify their own props directly.
- TypeScript interfaces provide autocomplete and type safety for props.

### Code Example: Basic Props with TypeScript

```tsx
interface AlertProps {
  type: "info" | "warning" | "error";
  message: string;
}

export function Alert({ type, message }: AlertProps) {
  const bg = type === "error" ? "bg-rose-950/60 border-rose-800 text-rose-300" 
           : type === "warning" ? "bg-amber-950/60 border-amber-800 text-amber-300"
           : "bg-blue-950/60 border-blue-800 text-blue-300";

  return <div className={`p-3 border rounded-lg ${bg}`}>{message}</div>;
}
```
