# What are Props?

Props (មកពីពាក្យ properties) គឺជាយន្តការដែល parent components ប្រើដើម្បីបញ្ជូនទិន្នន័យ និង callback functions ចុះក្រោមទៅកាន់ child components។ Props មានលក្ខណៈ strictly read-only (immutable) មិនអាចកែប្រែដោយផ្ទាល់នៅខាងក្នុង child component បានឡើយ។

### Key Concepts & Rules:

- Props ហូរតាមទិសដៅតែមួយ (Unidirectional) ពី parent ចុះទៅ child។
- Child components ដាច់ខាតមិនត្រូវកែប្រែ (mutate) តម្លៃ props របស់ខ្លួនឡើយ (Props are immutable)។
- Props អនុញ្ញាតឱ្យ component មួយអាចទទួលទិន្នន័យផ្សេងៗគ្នា ដើម្បីបង្ហាញ UI តាមតម្រូវការ។

### Code Example: Basic Props in Component

```jsx
export function Alert({ type, message }) {
  const bg = type === "error" ? "bg-rose-950/60 border-rose-800 text-rose-300" 
           : type === "warning" ? "bg-amber-950/60 border-amber-800 text-amber-300"
           : "bg-blue-950/60 border-blue-800 text-blue-300";

  return <div className={`p-3 border rounded-lg ${bg}`}>{message}</div>;
}
```
