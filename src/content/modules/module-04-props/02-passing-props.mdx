# Passing Props

អ្នកអាចបញ្ជូន props ទៅកាន់ components ដូចគ្នានឹងការកំណត់ attributes ទៅឱ្យ HTML tags ដែរ៖ `<Header title="Dashboard" count={42} isVisible />`។

### Key Concepts & Rules:

- បញ្ជូន string literals ដោយប្រើប្រាស់ quotes ធម្មតា៖ `title="React"`។
- បញ្ជូន numbers, booleans, objects, arrays និង functions ដោយប្រើរង្វង់ក្រចកទោល (curly braces)៖ `count={10}`, `isActive={true}`។
- ប្រសិនបើបញ្ជូន boolean prop ដោយមិនដាក់តម្លៃ (ឧ. `<Modal isOpen />`) នោះវាស្មើនឹង `isOpen={true}` ដោយស្វ័យប្រវត្តិ។

### Code Example: Passing Diverse Prop Types

```jsx
<CourseCard 
  title="Advanced Next.js"
  moduleCount={27}
  isPublished={true}
  tags={["React", "Next.js", "Zustand"]}
  onEnroll={(id) => console.log("Enrolled in", id)}
/>
```
