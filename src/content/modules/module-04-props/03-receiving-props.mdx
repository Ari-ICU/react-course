# Receiving Props

Argument ទីមួយនៃ functional component គឺជា `props` object។ អ្នកអាចទាញយក properties តាមរយៈ `props.title` ឬប្រើបច្ចេកទេស destructuring ដោយផ្ទាល់នៅត្រង់ parameters។

### Key Concepts & Rules:

- Props គឺជា JavaScript object ធម្មតាដែលផ្ទុករាល់ attributes ទាំងអស់ដែលបានបញ្ជូនមកពី parent។
- អ្នកអាចពិនិត្យមើលតម្លៃ props ដោយប្រើ `console.log(props)` ដើម្បីយល់ច្បាស់ពីទិន្នន័យដែលបានបញ្ជូនមក។

### Code Example: Receiving the Props Object

```jsx
export function CourseHeader(props) {
  return (
    <div>
      <h1 className="text-3xl font-bold text-white">{props.title}</h1>
      <p className="text-slate-400">{props.subtitle}</p>
    </div>
  );
}
```
