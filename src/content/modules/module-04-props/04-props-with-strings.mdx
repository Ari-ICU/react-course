# Props with Strings

String props can be passed without curly braces when literal: `<Button label="Save Changes" />`.

### Key Concepts & Rules:

- No curly braces needed for static strings.

### Code Example: String Literal Props

```tsx
<UserProfile 
  name="Alice Doe" 
  role="Senior Frontend Architect" 
  country="Cambodia" 
/>
```
