# Props with Strings

String props អាចបញ្ជូនបានយ៉ាងងាយស្រួលដោយមិនចាំបាច់ប្រើ curly braces ឡើយ នៅពេលដែលវាជា static literal value៖ `<Button label="Save Changes" />`។

### Key Concepts & Rules:

- មិនចាំបាច់ប្រើ curly braces សម្រាប់ static string literals ឡើយ។
- ប្រើ curly braces លុះត្រាតែ string នោះជា JavaScript variable ឬ template literal expression៖ `title={userName}` ឬ `title={\`Hello \${name}\`}`។

### Code Example: String Literal Props

```tsx
<UserProfile 
  name="Alice Doe" 
  role="Senior Frontend Architect" 
  country="Cambodia" 
/>
```
