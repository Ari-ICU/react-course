# Props with Numbers

តម្លៃជាលេខ (Numbers) ត្រូវតែបញ្ជូននៅខាងក្នុង curly braces ជានិច្ច (ឧទាហរណ៍ `rating={4.9}`)។ ប្រសិនបើសរសេរក្នុង double quotes នោះ JSX នឹងចាត់ទុកវាជា string literal ទៅវិញ។

### Key Concepts & Rules:

- `<Widget count=5 />` គឺជា invalid syntax ក្នុង JSX — ត្រូវសរសេរ `<Widget count={5} />`។
- ជួយការពារបញ្ហា type coercion ក្នុង JavaScript (ដូចជា `5 + "5" = "55"`)។

### Code Example: Passing Numeric Props

```jsx
<RatingBadge 
  score={4.85} 
  totalReviews={1240} 
  stars={5} 
/>
```
