# Props with Numbers

Numbers MUST be passed inside curly braces (e.g. `rating={4.9}`), otherwise they are parsed as literal strings.

### Key Concepts & Rules:

- `<Widget count=5 />` is invalid syntax; write `<Widget count={5} />`.

### Code Example: Passing Numeric Props

```tsx
<RatingBadge 
  score={4.85} 
  totalReviews={1240} 
  stars={5} 
/>
```
