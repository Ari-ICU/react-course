# Props with Objects

Pass objects inside curly braces: `user={{ name: 'Alice', age: 28 }}`. Note the double curly braces.

### Key Concepts & Rules:

- Outer curly braces denote JSX expression; inner braces denote object literal.

### Code Example: Passing Object Props

```tsx
const currentUser = { id: "u123", name: "Dara", role: "Instructor" };

// Pass variable or inline object:
<AccountSettings 
  user={currentUser}
  themeConfig={{ mode: "dark", accent: "#3b82f6" }}
/>
```
