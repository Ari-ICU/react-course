# Props with Objects

បញ្ជូន objects នៅខាងក្នុង curly braces៖ `user={{ name: 'Alice', age: 28 }}`។ សូមកត់សម្គាល់ការប្រើប្រាស់ double curly braces `{{ ... }}`។

### Key Concepts & Rules:

- រង្វង់ក្រចកខាងក្រៅ `{}` បញ្ជាក់ថាជា JSX expression ចំណែកឯរង្វង់ក្រចកខាងក្នុង `{}` បញ្ជាក់ថាជា JavaScript object literal។
- អាចបញ្ជូនតាមរយៈ variable ផ្ទាល់ ឬសរសេរជា inline object។
- ជៀសវាងការបង្កើត inline objects ថ្មីរាល់ពេល render បើ component កូនត្រូវបាន memoize (អាចប៉ះពាល់ដល់ performance)។

### Code Example: Passing Object Props

```jsx
const currentUser = { id: "u123", name: "Dara", role: "Instructor" };

// Pass variable or inline object:
<AccountSettings 
  user={currentUser}
  themeConfig={{ mode: "dark", accent: "#3b82f6" }}
/>
```
