# Props with Arrays

យើងអាចបញ្ជូន arrays ទៅកាន់ components តាមរយៈ props ដើម្បីចែករំលែកបណ្តុំទិន្នន័យ ដូចជា tags, categories ឬ navigation links។

### Key Concepts & Rules:

- បញ្ជូន arrays នៅខាងក្នុង curly braces៖ `items={['A', 'B', 'C']}` ឬ `features={featureList}`។
- Child component អាចទទួលយក array prop និងទាញយកធាតុមកបង្ហាញតាមរយៈ array indexing (ដូចជា `features[0]`)។
- ការ loop បង្ហាញធាតុ array ទាំងអស់ដោយស្វ័យប្រវត្តិ នឹងត្រូវសិក្សាលម្អិតនៅ Module 05 (Rendering Data តាមរយៈ `.map()`)។

### Code Example: Passing Array Props

```jsx
// 1. Child component receives an array prop
export function FeatureBadges({ features }) {
  return (
    <div className="flex flex-wrap gap-2">
      <span className="px-2.5 py-1 bg-slate-800 text-xs rounded-md text-indigo-300">
        {features[0]}
      </span>
      <span className="px-2.5 py-1 bg-slate-800 text-xs rounded-md text-indigo-300">
        {features[1]}
      </span>
      <span className="px-2.5 py-1 bg-slate-800 text-xs rounded-md text-indigo-300">
        {features[2]}
      </span>
    </div>
  );
}

// 2. Parent component passes an array as a prop
export function CourseFeatureCard() {
  const courseFeatures = ["Components", "JSX Syntax", "Props System"];
  return <FeatureBadges features={courseFeatures} />;
}
```
