# Props with Functions

ការបញ្ជូន functions ចុះក្រោមជា props អនុញ្ញាតឱ្យ child components អាចប្រាប់ដំណឹង (notify) ទៅកាន់ parent component វិញបាន នៅពេលដែលមាន event កើតឡើង (ដូចជាពេលចុច button ឬវាយបញ្ចូលអក្សរក្នុង input)។

### Key Concepts & Rules:

- ដើរតួជាយន្តការទំនាក់ទំនងពី Child ទៅ Parent (Child-to-parent communication)។
- បញ្ជូន function reference (កុំ invoke function ដោយប្រើ `()` ក្នុងពេល render ឱ្យសោះ)។
- ដាក់ឈ្មោះ function props ដោយប្រើបុព្វបទ `on` (ដូចជា `onDelete`, `onSelect`, `onSubmit`)។

### Code Example: Passing Callback Function Props

```tsx
export function DeleteButton({ onDelete }: { onDelete: (id: string) => void }) {
  return (
    <button 
      onClick={() => onDelete("item-42")}
      className="px-3 py-1 bg-rose-600 hover:bg-rose-700 text-white rounded text-sm"
    >
      Delete Record
    </button>
  );
}
```
