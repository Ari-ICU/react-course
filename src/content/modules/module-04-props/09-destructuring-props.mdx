# Destructuring Props

ការធ្វើ Destructuring props ជួយឱ្យកូដខ្លី ស្អាត មិនបាច់សរសេរពាក្យ `props.` ដដែលៗ និងបង្ហាញយ៉ាងច្បាស់នូវរាល់ properties ណាខ្លះដែល component កំពុងប្រើប្រាស់។

### Key Concepts & Rules:

- ធ្វើ Destructure ដោយផ្ទាល់នៅត្រង់ parameters នៃ function៖ `({ label, value, trend })`។
- អាចកំណត់ default fallback values ឬ rename properties បានយ៉ាងងាយស្រួល។
- អាចប្រើ Rest parameter `...rest` ដើម្បីចាប់យក props ដែលនៅសល់ទាំងអស់។

### Code Example: Destructuring in Function Signature

```jsx
export function MetricCard({ 
  label, 
  value, 
  trend = "up" 
}) {
  return (
    <div className="p-4 bg-slate-900 border border-slate-800 rounded-xl">
      <p className="text-sm text-slate-400">{label}</p>
      <div className="flex items-baseline gap-2 mt-1">
        <span className="text-2xl font-bold text-white">{value}</span>
        <span className={trend === "up" ? "text-emerald-400 text-xs" : "text-rose-400 text-xs"}>
          {trend === "up" ? "▲ +12%" : "▼ -4%"}
        </span>
      </div>
    </div>
  );
}
```
