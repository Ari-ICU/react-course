# Children Props

The `children` prop represents whatever content is placed between the opening and closing tags of a component: `<Modal><h2>Title</h2><p>Body</p></Modal>`.

### Key Concepts & Rules:

- Type with `React.ReactNode` in TypeScript.
- Foundation of wrapper layouts, cards, modals, and providers.

### Code Example: Children Prop Composition

```tsx
interface CardProps {
  title: string;
  children: React.ReactNode;
}

export function Card({ title, children }: CardProps) {
  return (
    <div className="bg-slate-900 border border-slate-800 rounded-xl p-5">
      <h3 className="text-lg font-semibold text-white mb-3">{title}</h3>
      <div className="text-slate-300">{children}</div>
    </div>
  );
}
```
