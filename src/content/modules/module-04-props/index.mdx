# Module 04: Props

Passing and receiving props, destructuring, children props, default values, one-way data flow, and props vs state.

## Module Syllabus (13 Lessons)

- **Lesson 01**: What are Props? - *Arguments passed into React components to customize their behavior and rendering.*
- **Lesson 02**: Passing Props - *Supplying values to components via JSX attributes.*
- **Lesson 03**: Receiving Props - *Accessing the props object in the component function parameter.*
- **Lesson 04**: Props with Strings - *Passing string literals directly using double quotes.*
- **Lesson 05**: Props with Numbers - *Passing numeric values using curly brace expressions.*
- **Lesson 06**: Props with Objects - *Passing complex objects and configuring nested structures.*
- **Lesson 07**: Props with Arrays - *Passing lists of items to components for iteration.*
- **Lesson 08**: Props with Functions - *Passing callback functions to handle user actions.*
- **Lesson 09**: Destructuring Props - *Clean prop extraction in function signature.*
- **Lesson 10**: Default Props - *Setting fallback values for optional props using ES6 default parameters.*
- **Lesson 11**: Children Props - *Composing component tags around nested JSX elements using children.*
- **Lesson 12**: Props vs State - *External immutable data vs internal mutable reactive data.*
- **Lesson 13**: One-way Data Flow - *Unidirectional data binding prevents circular dependency bugs.*
