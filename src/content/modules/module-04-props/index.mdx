# Module 04: Props

ស្វែងយល់ស៊ីជម្រៅអំពីការបញ្ជូន និងទទួល Props, Destructuring, Children Props, Default Values, One-way Data Flow និងភាពខុសគ្នារវាង Props vs State។

## Module Syllabus (13 Lessons)

- **Lesson 01**: What are Props? - *ទិន្នន័យ (Arguments) បញ្ជូនទៅកាន់ React components ដើម្បីកំណត់ឥរិយាបថ និងការ render UI។*
- **Lesson 02**: Passing Props - *ការបញ្ជូនតម្លៃផ្សេងៗទៅកាន់ components តាមរយៈ JSX attributes។*
- **Lesson 03**: Receiving Props - *ការចាប់យក props object តាមរយៈ parameters នៃ component function។*
- **Lesson 04**: Props with Strings - *ការបញ្ជូន static strings ដោយផ្ទាល់ដោយប្រើប្រាស់ double quotes ធម្មតា។*
- **Lesson 05**: Props with Numbers - *ការបញ្ជូនតម្លៃជាលេខ (Numeric values) ដោយប្រើប្រាស់ curly braces `{}`។*
- **Lesson 06**: Props with Objects - *ការបញ្ជូន objects ស្មុគស្មាញ និងការកំណត់ nested configuration structures។*
- **Lesson 07**: Props with Arrays - *ការបញ្ជូនបញ្ជីទិន្នន័យ (Lists) ទៅកាន់ components សម្រាប់ធ្វើការ iterate/map។*
- **Lesson 08**: Props with Functions - *ការបញ្ជូន callback functions ដើម្បីឆ្លើយតបទៅនឹង user events និង actions។*
- **Lesson 09**: Destructuring Props - *បច្ចេកទេសទាញយក props យ៉ាងខ្លីស្អាតនៅត្រង់ function signature។*
- **Lesson 10**: Default Props - *ការកំណត់ fallback values សម្រាប់ optional props ដោយប្រើ ES6 default parameters។*
- **Lesson 11**: Children Props - *ការផ្គុំ component tags ព័ទ្ធជុំវិញ nested JSX elements ដោយប្រើប្រាស់ `children` prop។*
- **Lesson 12**: Props vs State - *ការប្រៀបធៀបទិន្នន័យខាងក្រៅដែលមិនអាចកែប្រែបាន (Props) និងទិន្នន័យខាងក្នុងដែលមានប្រតិកម្មរហ័ស (State)។*
- **Lesson 13**: One-way Data Flow - *លំហូរទិន្នន័យតែមួយទិស (Unidirectional) ការពារបញ្ហា circular dependency bugs ក្នុងកម្មវិធី។*
