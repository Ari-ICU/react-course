# Rendering Arrays

React អនុញ្ញាតឱ្យយើង render arrays នៃ elements ដោយផ្ទាល់នៅលើ UI។ នៅពេលដែល array នៃ JSX elements ត្រូវបានបញ្ជូនចូល React នឹងធ្វើការ iterate និង mount រាល់ element នីមួយៗតាមលំដាប់លំដោយ។

### Key Concepts & Rules:

- Arrays ត្រូវបាន render ទៅលើ screen តាមលំដាប់លំដោយនៃធាតុនៅក្នុង array។
- រាល់ top-level element ទាំងអស់នៅក្នុង array ចាំបាច់ត្រូវតែមាន `key` prop មួយដែលមានតម្លៃ unique (មិនជាន់គ្នា)។
- ជៀសវាងការ render array ដែលផ្ទុក plain objects ដោយផ្ទាល់ ព្រោះ React មិនអនុញ្ញាតឱ្យ render object ជា child element ឡើយ។

### Code Example: Rendering Simple Arrays

```jsx
export function NumberList() {
  const numbers = [10, 20, 30, 40, 50];
  return (
    <ul className="flex gap-2">
      {numbers.map((n) => (
        <li key={n} className="px-3 py-1 bg-slate-800 rounded text-blue-400 font-mono">
          {n}
        </li>
      ))}
    </ul>
  );
}
```
