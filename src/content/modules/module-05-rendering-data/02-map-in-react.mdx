# map() in React

Method `.map()` របស់ JavaScript គឺជាវិធីសាស្ត្រស្តង់ដារដ៏ពេញនិយមបំផុតសម្រាប់បំប្លែង (transform) array នៃទិន្នន័យទៅជា array នៃ JSX elements។ ដោយសារតែ `.map()` return ត្រឡប់មកវិញនូវ new array នោះយើងអាចបង្កប់វាដោយផ្ទាល់នៅក្នុងរង្វង់ក្រចកទោល `{}` នៃ JSX បានយ៉ាងងាយស្រួល។

### Key Concepts & Rules:

- ប្រើ `.map()` ជំនួសឱ្យ `forEach` ឬ `for` loop ធម្មតា ព្រោះ `.map()` return នូវ array ថ្មីដែល React អាចយកទៅ render បានភ្លាមៗ។
- រក្សា mapping callback function ឱ្យនៅជា pure function និងសរសេរឱ្យខ្លី ងាយយល់។
- ត្រូវប្រាកដថាបានដាក់ `key` prop នៅលើ outer element បំផុតដែលបាន return ចេញពី `.map()`។

### Code Example: Mapping Objects to JSX Elements

```jsx
interface Student {
  id: string;
  name: string;
  score: number;
}

export function Leaderboard({ students }: { students: Student[] }) {
  return (
    <div className="divide-y divide-slate-800">
      {students.map((student, index) => (
        <div key={student.id} className="flex justify-between py-2 text-sm">
          <span className="text-slate-300">#{index + 1} {student.name}</span>
          <span className="font-bold text-emerald-400">{student.score} pts</span>
        </div>
      ))}
    </div>
  );
}
```
