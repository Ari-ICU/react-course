# Rendering Lists

Combining `.map()` with reusable card components enables dynamic rendering of products, blog posts, or comments.

### Key Concepts & Rules:

- Extract list items into dedicated subcomponents for clarity and memoization.

### Code Example: Rendering List of Grid Cards

```jsx
export function ModuleGrid({ modules }: { modules: ModuleItem[] }) {
  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
      {modules.map((mod) => (
        <ModuleCard key={mod.id} module={mod} />
      ))}
    </div>
  );
}
```
