# Rendering Lists

ការរួមបញ្ចូលគ្នារវាង `.map()` ជាមួយនឹង reusable components អនុញ្ញាតឱ្យយើងបង្កើត dynamic lists, product feeds, ឬ comment sections បានយ៉ាងរលូន និងមានរចនាសម្ព័ន្ធច្បាស់លាស់។

### Key Concepts & Rules:

- បំបែក list item នីមួយៗឱ្យទៅជា dedicated component ដាច់ដោយឡែក ដើម្បីបង្កើនភាពច្បាស់លាស់នៃកូដ និងងាយស្រួលធ្វើ memoization។
- បញ្ជូន data ទៅកាន់ child component តាមរយៈ props ឬ object prop (`module={mod}`)។
- ដាក់ `key` prop នៅលើ custom component ផ្ទាល់នៅកម្រិត loop (`<ModuleCard key={mod.id} ... />`) មិនមែននៅខាងក្នុង root tag របស់ component នោះទេ។

### Code Example: Rendering List of Grid Cards

```jsx
export function ModuleGrid({ modules }: { modules: ModuleItem[] }) {
  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
      {modules.map((mod) => (
        <ModuleCard key={mod.id} module={mod} />
      ))}
    </div>
  );
}
```
