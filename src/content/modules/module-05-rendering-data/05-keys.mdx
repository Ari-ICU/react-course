# Keys

Keys ផ្តល់នូវអត្តសញ្ញាណស្ថិតស្ថេរ (stable identity) ដល់ elements ឆ្លងកាត់ការ render នីមួយៗ។ នៅពេលដែលធាតុក្នុង array ផ្លាស់ប្តូរលំដាប់ ត្រូវបានបន្ថែម ឬលុបចេញ React នឹងប្រៀបធៀប keys ទាំងនេះដើម្បីដឹងថាតើ DOM nodes ណាខ្លះត្រូវរក្សាទុកប្រើឡើងវិញ (reuse) ឬត្រូវបង្កើតជាថ្មី ដោយមិនចាំបាច់ render បញ្ជីទាំងមូលឡើងវិញឡើយ។

### Key Concepts & Rules:

- Keys ត្រូវតែមានតម្លៃ unique (មិនជាន់គ្នា) ក្នុងចំណោមធាតុបងប្អូន (siblings) ជាមួយគ្នា។
- ដាច់ខាតកុំប្រើ `Math.random()` ជា key ព្រោះវានឹងផ្លាស់ប្តូរតម្លៃគ្រប់ពេល render ដែលធ្វើឱ្យ React បង្កើត DOM node ថ្មីរាល់ពេល។
- ចៀសវាងការប្រើ array index ជា key ប្រសិនបើតារាងទិន្នន័យអាចមានការ sort, filter, ឬបន្ថែម/លុបធាតុ។

### Code Example: Correct Key Usage in React

```jsx
// ✅ Use stable IDs from your database/backend
{todos.map(todo => (
  <TodoItem key={todo.id} todo={todo} />
))}

// ⚠️ Array index is acceptable ONLY if list is strictly static:
{['Home', 'About', 'Contact'].map((item, idx) => (
  <span key={idx}>{item}</span>
))}
```
