# Conditional Rendering

Choose between early return, ternary operators, or switch statements depending on whether the UI is mutually exclusive or inline.

### Key Concepts & Rules:

- Early return for page-level state guards (unauthenticated, loading, error).
- Ternary for inline component switches.

### Code Example: Conditional Rendering Pattern

```tsx
export function AccountStatus({ status }: { status: 'loading' | 'verified' | 'unverified' }) {
  if (status === 'loading') {
    return <p className="text-slate-500">Checking status...</p>;
  }

  return (
    <div>
      {status === 'verified' ? (
        <span className="text-emerald-400">Account Active ✓</span>
      ) : (
        <span className="text-amber-400">Please verify your email address</span>
      )}
    </div>
  );
}
```
