# Conditional Rendering

នៅក្នុង React យើងអាចជ្រើសរើសបង្ហាញ UI ផ្សេងៗគ្នាអាស្រ័យលើតម្លៃនៃ state ឬ props។ អ្នកអាចជ្រើសរើសប្រើប្រាស់បច្ចេកទេស early return, ternary operators (`? :`), ឬ `switch` statement ផ្អែកលើទម្រង់ UI ជាក់ស្តែង។

### Key Concepts & Rules:

- ប្រើ **Early Return** សម្រាប់គ្រប់គ្រង state កម្រិតទំព័រ (page-level guards) ដូចជាស្ថានភាព unauthenticated, loading, ឬ error។
- ប្រើ **Ternary Operator** សម្រាប់ការផ្លាស់ប្តូរ UI ពីរជម្រើសនៅខាងក្នុង JSX markup ដោយផ្ទាល់។
- រៀបចំកូដឱ្យមានភាពច្បាស់លាស់ ដោយជៀសវាងការដាក់ nested conditionals ច្រើនជាន់ដែលពិបាកអាន។

### Code Example: Conditional Rendering Pattern

```jsx
export function AccountStatus({ status }: { status: 'loading' | 'verified' | 'unverified' }) {
  if (status === 'loading') {
    return <p className="text-slate-500">Checking status...</p>;
  }

  return (
    <div>
      {status === 'verified' ? (
        <span className="text-emerald-400">Account Active ✓</span>
      ) : (
        <span className="text-amber-400">Please verify your email address</span>
      )}
    </div>
  );
}
```
