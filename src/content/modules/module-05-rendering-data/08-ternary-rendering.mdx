# Ternary Rendering

The ternary operator `condition ? <A /> : <B />` is ideal for toggling between two mutually exclusive UI elements inside JSX markup.

### Key Concepts & Rules:

- Great for binary switches: Dark/Light theme, Active/Inactive tab.

### Code Example: Inline Ternary Operator

```tsx
<button className={isActive ? "bg-blue-600 text-white" : "bg-slate-800 text-slate-400"}>
  {isActive ? "Currently Selected" : "Select Option"}
</button>
```
