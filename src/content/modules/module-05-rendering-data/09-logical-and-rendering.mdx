# Logical AND Rendering

ការប្រើប្រាស់ syntax `condition && <Element />` នឹងធ្វើការ render `<Element />` ប្រសិនបើ `condition` មានតម្លៃ truthy ហើយវានឹងរំលងមិន render អ្វីទាំងអស់ប្រសិនបើតម្លៃជា `false` ឬ `null`។

### Key Concepts & Rules:

- ប្រើប្រាស់នៅពេលដែលអ្នកចង់បង្ហាញ UI តែមួយជម្រើស (render ពេលពិត ឬមិន render ទាល់តែសោះ)។
- ត្រូវប្រាកដថា operand ខាងឆ្វេងមានតម្លៃជា boolean ពិតប្រាកដ (ឧ. `Boolean(val)`, `val > 0`, ឬ `!!val`) ដើម្បីជៀសវាងការ render ចេញលេខ `0` ឬ `NaN` ដោយអចេតនា។
- ស័ក្តិសមបំផុតសម្រាប់ badge alerts, discount banners, ឬ error indicators។

### Code Example: Logical AND Guard

```jsx
export function NotificationBanner({ hasDiscount, discountCode }: BannerProps) {
  return (
    <div>
      {hasDiscount && (
        <div className="bg-emerald-950/80 border border-emerald-800 p-2 text-emerald-300 text-xs rounded">
          Use code <strong>{discountCode}</strong> for 20% off!
        </div>
      )}
    </div>
  );
}
```
