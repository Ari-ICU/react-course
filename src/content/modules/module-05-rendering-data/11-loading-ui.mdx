# Loading UI

Skeleton loaders ជួយកាត់បន្ថយបាតុភូត Cumulative Layout Shift (CLS) ដោយការបង្ហាញគ្រោង layout ដែលមានទម្រង់ និងទំហំប្រហាក់ប្រហែលនឹងទិន្នន័យពិត ខណៈពេលដែល network request កំពុងដំណើរការ។

### Key Concepts & Rules:

- ប្រើប្រាស់ utility class ដូចជា `animate-pulse` របស់ Tailwind CSS ដើម្បីបង្កើត effect ភ្លឺផ្លេកៗសម្រាប់ skeleton placeholders។
- រៀបចំ skeleton ឱ្យត្រូវគ្នានឹង card, list item, ឬ page structure ដែលនឹងត្រូវបង្ហាញ។
- ជួយបង្កើន perceived performance ធ្វើឱ្យអ្នកប្រើប្រាស់មានអារម្មណ៍ថាកម្មវិធីដំណើរការរហ័ស និងឆ្លើយតបទាន់ចិត្ត។

### Code Example: Tailwind Skeleton Loader

```jsx
export function CardSkeleton() {
  return (
    <div className="p-4 bg-slate-900 border border-slate-800 rounded-xl animate-pulse space-y-3">
      <div className="h-5 bg-slate-800 rounded w-2/3" />
      <div className="h-4 bg-slate-800/60 rounded w-full" />
      <div className="h-4 bg-slate-800/60 rounded w-4/5" />
      <div className="h-8 bg-slate-800 rounded w-24 mt-4" />
    </div>
  );
}
```
