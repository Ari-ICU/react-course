# Error UI

នៅពេលដែលដំណើរការទាញយកទិន្នន័យជួបការបរាជ័យ (failed) កម្មវិធីត្រូវតែបង្ហាញនូវផ្ទាំង Error UI តាមរយៈ conditional rendering ដើម្បីផ្តល់ព័ត៌មានមានប្រយោជន៍ដល់អ្នកប្រើប្រាស់។

### Key Concepts & Rules:

- ប្រើ conditional rendering ដើម្បីប្តូររវាង Normal UI និង Error UI ផ្អែកលើ status នៃទិន្នន័យ។
- បង្ហាញ error message ដែលងាយស្រួលយល់ និងមិនស្មុគស្មាញពេកសម្រាប់អ្នកប្រើប្រាស់ទូទៅ។
- ប្រើពណ៌សម្គាល់សមស្រប (ដូចជា tông ពណ៌ rose ឬ red) ដើម្បីឱ្យអ្នកប្រើប្រាស់ចាប់អារម្មណ៍ភ្លាមៗ (ចំណែកឯ button interactions នឹងត្រូវសិក្សានៅ Module 06)។

### Code Example: Conditional Error UI Component

```jsx
export function DataDisplay({ isError, errorMessage, data }) {
  // Conditional Error UI rendering
  if (isError) {
    return (
      <div className="p-5 bg-rose-950/40 border border-rose-800/60 rounded-xl text-center">
        <p className="text-rose-300 font-medium">{errorMessage}</p>
        <p className="mt-2 text-xs text-rose-400">
          Please check your connection and refresh the page.
        </p>
      </div>
    );
  }

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl">
      <h3 className="text-white font-bold">{data.title}</h3>
      <p className="text-slate-400 text-sm mt-1">{data.description}</p>
    </div>
  );
}
```
