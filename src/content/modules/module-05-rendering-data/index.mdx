# Module 05: Rendering Data

ស្វែងយល់អំពីការបង្ហាញទិន្នន័យលើ UI តាមរយៈ .map(), ក្បួនច្បាប់នៃការប្រើប្រាស់ Key prop, Conditional Rendering, Skeleton Loading UI និងការរៀបចំ Error States ឱ្យមានប្រសិទ្ធភាពខ្ពស់។

## Module Syllabus (12 Lessons)

- **Lesson 01**: Rendering Arrays - *ការបង្ហាញទិន្នន័យជាបណ្តុំ (Arrays) នៃ primitives ឬ objects នៅលើអេក្រង់។*
- **Lesson 02**: map() in React - *ការប្រើប្រាស់ declarative array method ស្តង់ដារដើម្បីបំប្លែងទិន្នន័យទៅជា JSX elements។*
- **Lesson 03**: Rendering Objects - *របៀបទាញយក និងបង្ហាញ properties របស់ object នៅខាងក្នុង JSX templates ឱ្យបានត្រឹមត្រូវ។*
- **Lesson 04**: Rendering Lists - *ការកសាង dynamic lists និង card grids ដែលមានទំហំធំ និងអាច scale បានយ៉ាងងាយស្រួល។*
- **Lesson 05**: Keys - *សារៈសំខាន់នៃ `key` prop និងរបៀបដែល React reconciliation ប្រើវាដើម្បីតាមដានធាតុនីមួយៗ។*
- **Lesson 06**: Dynamic Components - *ការជ្រើសរើស component មកបង្ហាញដោយស្វ័យប្រវត្តិតាម runtime ដោយប្រើ lookup dictionaries/maps។*
- **Lesson 07**: Conditional Rendering - *យុទ្ធសាស្ត្រផ្សេងៗក្នុងការបង្ហាញ UI ផ្អែកលើលក្ខខណ្ឌ និង state របស់កម្មវិធី។*
- **Lesson 08**: Ternary Rendering - *ការប្រើប្រាស់ Ternary Operator (`? :`) សម្រាប់ inline if/else logic យ៉ាងខ្លីស្អាត។*
- **Lesson 09**: Logical AND Rendering - *ការប្រើប្រាស់ Logical AND (`&&`) ដើម្បី render UI នៅពេលដែលលក្ខខណ្ឌពិត (truthy)។*
- **Lesson 10**: Empty States - *ការរចនាទម្រង់ Empty State ប្រកបដោយភាពទាក់ទាញ នៅពេលដែលបញ្ជីទិន្នន័យទទេស្អាត។*
- **Lesson 11**: Loading UI - *ការប្រើ Skeleton loaders និង spinners ដើម្បីបង្កើន perceived performance សម្រាប់ UX ទំនើប។*
- **Lesson 12**: Error UI - *ការបង្ហាញសារប្រាប់ដំណឹងអំពី error និងប៊ូតុង retry ដើម្បីផ្តល់បទពិសោធន៍ល្អដល់អ្នកប្រើប្រាស់។*
