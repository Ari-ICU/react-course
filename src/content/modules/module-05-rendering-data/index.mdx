# Module 05: Rendering Data

Iterating arrays with map(), key prop rules, conditional rendering, loading skeletons, and error UI states.

## Module Syllabus (12 Lessons)

- **Lesson 01**: Rendering Arrays - *Displaying collections of primitives or objects on screen.*
- **Lesson 02**: map() in React - *The standard declarative array transformation method for JSX.*
- **Lesson 03**: Rendering Objects - *Accessing and formatting object properties inside templates.*
- **Lesson 04**: Rendering Lists - *Building scalable dynamic lists and cards from data feeds.*
- **Lesson 05**: Keys - *Why React requires keys and how reconciliation uses them.*
- **Lesson 06**: Dynamic Components - *Selecting components at runtime using lookup dictionaries.*
- **Lesson 07**: Conditional Rendering - *Strategies for rendering different UI based on state flags.*
- **Lesson 08**: Ternary Rendering - *Compact inline if/else expression.*
- **Lesson 09**: Logical AND Rendering - *Rendering an element only when a condition is truthy.*
- **Lesson 10**: Empty States - *Designing engaging fallbacks when arrays or datasets are empty.*
- **Lesson 11**: Loading UI - *Skeleton loaders vs spinners for modern UX perceived performance.*
- **Lesson 12**: Error UI - *Displaying informative error recovery states.*
