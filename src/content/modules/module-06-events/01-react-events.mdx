# React Events

React wraps native browser events in a cross-browser `SyntheticEvent` instance that ensures identical event behavior across Safari, Chrome, Firefox, and Edge.

### Key Concepts & Rules:

- Synthetic events match W3C standards.
- Named in camelCase: `onClick`, `onChange`, `onKeyDown`.

### Code Example: React SyntheticEvent Handling

```jsx
export function EventLogger() {
  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log("Event Type:", e.type);
    console.log("Coordinates:", e.clientX, e.clientY);
  };

  return <button onClick={handleClick}>Log Event</button>;
}
```
