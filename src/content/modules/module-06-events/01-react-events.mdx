# React Events

នៅក្នុង React រាល់ event ទាំងអស់មិនត្រូវបាន bind ទៅលើ DOM ផ្ទាល់ដូច JavaScript ធម្មតានោះឡើយ។ React ប្រើប្រាស់ប្រព័ន្ធ `SyntheticEvent` ដែលជា wrapper ព័ទ្ធជុំវិញ native browser event ដើម្បីធានាថា event ដំណើរការដូចគ្នាបេះបិទលើគ្រប់ web browsers ទាំងអស់ មិនថា Chrome, Safari, Firefox, ឬ Edge ឡើយ។

### Key Concepts & Rules:

- React Synthetic Events ត្រូវគ្នានឹងស្តង់ដារ W3C និងផ្តល់នូវ cross-browser consistency យ៉ាងរលូន។
- Event attributes នៅក្នុង JSX ត្រូវបានសរសេរជាទម្រង់ camelCase ជានិច្ច ដូចជា `onClick`, `onChange`, `onKeyDown` ជំនួសឱ្យ `onclick`, `onchange`។
- React ធ្វើការ delegated events នៅកម្រិត root container ដើម្បីបង្កើន memory performance និងល្បឿនប្រតិបត្តិការ។

### Code Example: React SyntheticEvent Handling

```jsx
export function EventLogger() {
  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log("Event Type:", e.type);
    console.log("Coordinates:", e.clientX, e.clientY);
  };

  return <button onClick={handleClick}>Log Event</button>;
}
```
