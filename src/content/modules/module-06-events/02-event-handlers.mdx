# Event Handlers

You must pass the function reference (`onClick={handleClick}`), NOT invoke it (`onClick={handleClick()}`). Invoking it runs the function during render!

### Key Concepts & Rules:

- Pass function reference: `onClick={handleClick}`.
- Pass inline arrow function if parameters are needed: `onClick={() => handleDelete(id)}`.

### Code Example: Function Reference vs Invocation

```tsx
// ❌ Wrong: handleClick runs immediately on render!
// <button onClick={handleClick()}>Click</button>

// ✅ Correct: Function reference passed
<button onClick={handleClick}>Click</button>

// ✅ Correct: Arrow function wrapper for arguments
<button onClick={() => handleDelete(item.id)}>Delete</button>
```
