# Event Handlers

កំហុសឆ្គងទូទៅបំផុតមួយសម្រាប់អ្នកចាប់ផ្តើមរៀន React គឺការដាក់វង់ក្រចក `()` នៅពេលភ្ជាប់ handler។ អ្នកត្រូវតែបញ្ជូន **Function Reference** (`onClick={handleClick}`) មិនមែនជាការហៅ function ដោយផ្ទាល់ (`onClick={handleClick()}`) នោះទេ ព្រោះការហៅ function នឹងធ្វើឱ្យកូដនោះដំណើរការភ្លាមៗនៅពេល component កំពុង render។

### Key Concepts & Rules:

- បញ្ជូន Function Reference ដោយគ្មានវង់ក្រចក៖ `onClick={handleClick}`។
- ប្រសិនបើអ្នកត្រូវការបញ្ជូន arguments បន្ថែម ចូរប្រើ inline arrow function៖ `onClick={() => handleDelete(id)}`។
- ការសរសេរ `onClick={handleClick()}` នឹង return តម្លៃរបស់ function ទៅឱ្យ onClick ដែលមិនត្រឹមតែរត់ខុសពេលនោះទេ ថែមទាំងធ្វើឱ្យ event លែងដំណើរការទៀតផង។

### Code Example: Function Reference vs Invocation

```jsx
import { useState } from 'react';

export function EventHandlerDemo() {
  const [log, setLog] = useState('No action yet');

  // Function reference to pass
  function handleDirectClick() {
    setLog('Direct click triggered via reference!');
  }

  // Handler accepting custom parameter
  function handleDelete(id) {
    setLog(`Deleted item #${id} via arrow wrapper!`);
  }

  return (
    <div className="p-6 bg-slate-900 border border-slate-800 rounded-xl space-y-4">
      <p className="text-sm font-mono text-emerald-400">Status: {log}</p>

      <div className="flex flex-wrap gap-3">
        {/* ✅ Correct: Pass function reference without parentheses */}
        <button
          onClick={handleDirectClick}
          className="px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white rounded-lg text-sm font-medium"
        >
          onClick={'{handleDirectClick}'}
        </button>

        {/* ✅ Correct: Arrow function to pass arguments */}
        <button
          onClick={() => handleDelete(101)}
          className="px-4 py-2 bg-rose-600 hover:bg-rose-700 text-white rounded-lg text-sm font-medium"
        >
          onClick={'{\(\) => handleDelete\(101\)}'}
        </button>

        {/* ❌ INCORRECT: handleDirectClick() runs immediately during render!
            <button onClick={handleDirectClick()}>Wrong!</button>
        */}
      </div>
    </div>
  );
}
```
