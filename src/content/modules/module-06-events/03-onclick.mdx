# onClick

`onClick` គឺជា event handler ដែលត្រូវបានប្រើប្រាស់ញឹកញាប់បំផុតនៅក្នុងកម្មវិធី React។ វាត្រូវបាន trigger នៅពេលដែលអ្នកប្រើប្រាស់ចុច mouse, ប៉ះលើ touchscreen, ឬចុចគ្រាប់ចុច Enter/Space នៅលើ element នោះ។

### Key Concepts & Rules:

- ដំណើរការជាមួយ mouse clicks, mobile touches និង keyboard navigation នៅពេលប្រើប្រាស់ HTML elements ស្តង់ដារដូចជា `<button>`។
- ប្រសិនបើអ្នកដាក់ `onClick` លើ `<div>` ធម្មតា ត្រូវប្រាកដថាបានបន្ថែម accessibility attributes ដូចជា `role="button"` និង `tabIndex={0}`។
- អាចចាប់យក click coordinates, modifier keys (Shift, Ctrl, Alt) តាមរយៈ event object `e`។

### Code Example: onClick Handler

```jsx
<button 
  onClick={(e) => {
    e.stopPropagation();
    console.log("Clicked!");
  }}
  className="px-4 py-2 bg-blue-600 rounded-lg text-white"
>
  Click Me
</button>
```
