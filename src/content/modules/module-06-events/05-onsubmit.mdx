# onSubmit

តាមលំនាំដើមរបស់ browser នៅពេលដែល form ត្រូវបាន submit វានឹងធ្វើការ refresh ទំព័រទាំងមូល ឬបញ្ជូន HTTP request ទៅកាន់ action URL។ នៅក្នុងកម្មវិធី Single Page Application (SPA) យើងត្រូវតែប្រើប្រាស់ `e.preventDefault()` នៅខាងក្នុង `onSubmit` handler ដើម្បីទប់ស្កាត់ការ reload និងអនុញ្ញាតឱ្យ JavaScript ចាត់ចែង submission តាមរយៈ API។

### Key Concepts & Rules:

- ត្រូវហៅ `e.preventDefault()` ជានិច្ចនៅដើមបន្ទាត់នៃ form handler function។
- ភ្ជាប់ `onSubmit` ទៅកាន់ `<form>` tag ផ្ទាល់ មិនមែនភ្ជាប់ `onClick` ទៅកាន់ submit button នោះទេ ដើម្បីឱ្យ user អាច submit តាមរយៈការចុច Enter បាន។
- ជួយឱ្យ form validation ដើរស្របតាមស្តង់ដារ HTML5 (ដូចជា required attributes) មុនពេល handler ដំណើរការ។

### Code Example: onSubmit Form Handler

```jsx
export function LoginForm() {
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    console.log("Form submitted safely without page reload!");
  };

  return (
    <form onSubmit={handleSubmit} className="space-y-3">
      <input type="email" placeholder="Email" required />
      <button type="submit" className="bg-blue-600 px-4 py-2 rounded text-white">Log In</button>
    </form>
  );
}
```
