# onMouseEnter & onMouseLeave

`onMouseEnter` និង `onMouseLeave` ត្រូវបានប្រើប្រាស់សម្រាប់ចាប់យកសកម្មភាព hover របស់ mouse cursor ចូល និងចេញពី element។ ព្រឹត្តិការណ៍ទាំងពីរនេះស័ក្តិសមបំផុតសម្រាប់ការបង្កើត interactions, preview popovers, ឬ logging animations។

### Key Concepts & Rules:

- `onMouseEnter` និង `onMouseLeave` មិនធ្វើការ bubble ឡើងលើ parent ឡើយ (ខុសពី `onMouseOver` និង `onMouseOut`) ដែលជួយកាត់បន្ថយបញ្ហា flickering នៅពេល hover លើ child elements។
- ចាប់យក mouse cursor coordinates ឬ trigger custom logic ក្នុងពេល hover (ចំណែកឯការផ្លាស់ប្តូរ UI តាមរយៈ State នឹងត្រូវសិក្សានៅ Module 07 បន្ទាប់)។
- ត្រូវប្រាកដថាបានផ្តល់នូវ keyboard alternative (ដូចជា `onFocus` និង `onBlur`) សម្រាប់អ្នកប្រើប្រាស់ដែលមិនប្រើ mouse។

### Code Example: Hover Handlers

```jsx
export function HoverPreview() {
  const handleMouseEnter = () => {
    console.log("Mouse cursor entered container");
  };

  const handleMouseLeave = () => {
    console.log("Mouse cursor left container");
  };

  return (
    <div 
      onMouseEnter={handleMouseEnter}
      onMouseLeave={handleMouseLeave}
      className="p-6 border border-slate-800 rounded-xl bg-slate-900 hover:border-indigo-500 transition-colors text-center text-slate-300 cursor-pointer"
    >
      Hover over me! (Check browser console for event logs)
    </div>
  );
}
```
