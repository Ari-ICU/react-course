# onMouseEnter & onMouseLeave

Used to build interactive tooltips, preview cards, and custom cursor animations.

### Key Concepts & Rules:

- React's mouseEnter does not bubble, mimicking standard CSS hover.

### Code Example: Hover Handlers

```tsx
export function HoverPreview() {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <div 
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      className="p-4 border rounded-lg transition-colors bg-slate-900 hover:border-blue-500"
    >
      Hover over me!
      {isHovered && <p className="text-xs text-blue-400 mt-1">✨ Tooltip content visible</p>}
    </div>
  );
}
```
