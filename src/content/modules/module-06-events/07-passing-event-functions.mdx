# Passing Event Functions

នៅក្នុង React ទិន្នន័យហូរពីលើចុះក្រោម (One-way Data Flow) ប៉ុន្តែនៅពេលដែល child component ចង់ប្រាប់ parent អំពីសកម្មភាពណាមួយ Parent ត្រូវតែបញ្ជូន callback function មួយចុះក្រោមតាមរយៈ props ដើម្បីឱ្យ child អាចហៅ (trigger) ឡើងវិញបាន។

### Key Concepts & Rules:

- **ក្បួនដាក់ឈ្មោះស្តង់ដារ**៖ ប្រើបុព្វបទ `on*` សម្រាប់ props (ឧ. `onSelect`, `onSubmit`) និង `handle*` សម្រាប់ function definitions (ឧ. `handleSelect`, `handleSubmit`)។
- Parent component ជាអ្នកគ្រប់គ្រង state និងសម្រេចចិត្តថាតើត្រូវធ្វើអ្វីបន្ត នៅពេលដែល child ធ្វើការ trigger event។
- ជួយឱ្យ child components មានភាព reusable ខ្ពស់ ព្រោះពួកវាមិនចាំបាច់ដឹងពី business logic ស៊ីជម្រៅរបស់ parent ឡើយ។

### Code Example: Passing Event Callbacks

```jsx
interface TopicItemProps {
  topic: TopicItem;
  onSelectTopic: (topic: TopicItem) => void;
}

export function TopicCard({ topic, onSelectTopic }: TopicItemProps) {
  return (
    <div onClick={() => onSelectTopic(topic)} className="cursor-pointer">
      <h4>{topic.title}</h4>
    </div>
  );
}
```
