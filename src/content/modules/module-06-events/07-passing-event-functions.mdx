# Passing Event Functions

Prefix custom event props with `on` (e.g., `onSelectTopic`, `onDelete`) and implementation handlers with `handle` (`handleSelectTopic`).

### Key Concepts & Rules:

- Naming convention: `onEvent` for props, `handleEvent` for functions.

### Code Example: Passing Event Callbacks

```jsx
interface TopicItemProps {
  topic: TopicItem;
  onSelectTopic: (topic: TopicItem) => void;
}

export function TopicCard({ topic, onSelectTopic }: TopicItemProps) {
  return (
    <div onClick={() => onSelectTopic(topic)} className="cursor-pointer">
      <h4>{topic.title}</h4>
    </div>
  );
}
```
