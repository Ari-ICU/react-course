# Event Parameters

ជាញឹកញាប់នៅក្នុងបញ្ជីទិន្នន័យ (Lists) អ្នកត្រូវការបញ្ជូនតម្លៃជាក់លាក់ណាមួយ (ដូចជា Item ID, index ឬ record object) ទៅកាន់ handler ពេលចុចលើធាតុនីមួយៗ។ ដំណោះស្រាយដ៏សាមញ្ញ និងមានប្រសិទ្ធភាពបំផុតគឺការប្រើ inline arrow function ដើម្បី wrap ពីលើ handler នោះ។

### Key Concepts & Rules:

- ប្រើ syntax៖ `onClick={(e) => handleAction(item.id, e)}` ដើម្បីបញ្ជូនទាំង ID និង event object។
- ជៀសវាងការសរសេរ `onClick={handleAction(item.id)}` ដាច់ខាត ព្រោះវានឹងរត់កូដភ្លាមៗពេល render។
- វិធីសាស្ត្រនេះជួយឱ្យកូដមានភាពសាមញ្ញ ងាយយល់ និងស្អាតបាត។

### Code Example: Passing Custom Parameters

```jsx
import React, { useState } from 'react';

interface Task {
  id: string;
  title: string;
  isComplete: boolean;
}

export function TaskActionList() {
  const [tasks, setTasks] = useState<Task[]>([
    { id: 't-1', title: 'Review PR #42', isComplete: false },
    { id: 't-2', title: 'Setup Vitest suite', isComplete: true },
  ]);

  // Handler receiving custom item parameters + SyntheticEvent
  const handleToggleStatus = (id: string, currentStatus: boolean, e: React.MouseEvent) => {
    e.stopPropagation(); // Access event methods cleanly
    setTasks(prev => prev.map(t => t.id === id ? { ...t, isComplete: !currentStatus } : t));
  };

  return (
    <ul className="space-y-2">
      {tasks.map((task) => (
        <li key={task.id} className="flex items-center justify-between p-3 bg-slate-900 border border-slate-800 rounded-lg">
          <span className={task.isComplete ? "line-through text-slate-500" : "text-slate-200"}>
            {task.title}
          </span>
          {/* Passing custom arguments via inline arrow function */}
          <button
            onClick={(e) => handleToggleStatus(task.id, task.isComplete, e)}
            className="px-3 py-1 text-xs font-semibold rounded bg-blue-600 hover:bg-blue-700 text-white"
          >
            {task.isComplete ? "Undo" : "Complete"}
          </button>
        </li>
      ))}
    </ul>
  );
}
```
