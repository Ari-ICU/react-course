# Event Parameters

Use inline arrow functions to pass record IDs, indices, or custom payloads into event handlers.

### Key Concepts & Rules:

- Signature: `(e) => handleAction(id, e)`.

### Code Example: Passing Custom Parameters

```jsx
<button onClick={(e) => handleArchive(item.id, e)}>
  Archive Item
</button>
```
