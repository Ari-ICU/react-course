# Event Parameters

ជាញឹកញាប់នៅក្នុងបញ្ជីទិន្នន័យ (Lists) អ្នកត្រូវការបញ្ជូនតម្លៃជាក់លាក់ណាមួយ (ដូចជា Item ID, index ឬ record object) ទៅកាន់ handler ពេលចុចលើធាតុនីមួយៗ។ ដំណោះស្រាយដ៏សាមញ្ញ និងមានប្រសិទ្ធភាពបំផុតគឺការប្រើ inline arrow function ដើម្បី wrap ពីលើ handler នោះ។

### Key Concepts & Rules:

- ប្រើ syntax៖ `onClick={(e) => handleAction(item.id, e)}` ដើម្បីបញ្ជូនទាំង ID និង event object។
- ជៀសវាងការសរសេរ `onClick={handleAction(item.id)}` ដាច់ខាត ព្រោះវានឹងរត់កូដភ្លាមៗពេល render។
- វិធីសាស្ត្រនេះជួយឱ្យកូដមានភាពសាមញ្ញ ងាយយល់ និងស្អាតបាត។

### Code Example: Passing Custom Parameters

```jsx
<button onClick={(e) => handleArchive(item.id, e)}>
  Archive Item
</button>
```
