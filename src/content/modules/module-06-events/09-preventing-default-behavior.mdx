# Preventing Default Behavior

ធាតុ HTML មួយចំនួនមានឥរិយាបថលំនាំដើមរបស់ browser (default browser action) ដូចជា tag `<a>` នឹងបើកតំណភ្ជាប់ថ្មី, tag `<form>` នឹង reload ទំព័រពេល submit, ឬគ្រាប់ចុច arrow keys នឹង scroll ទំព័រ។ តាមរយៈ method `e.preventDefault()` យើងអាចទប់ស្កាត់សកម្មភាពទាំងនេះ ដើម្បីជំនួសដោយ custom logic របស់យើងវិញ។

### Key Concepts & Rules:

- នៅក្នុង React ការ return `false` ពី handler មិនមានប្រសិទ្ធភាពទប់ស្កាត់ default behavior ឡើយ — អ្នកត្រូវតែហៅ `e.preventDefault()` ដោយផ្ទាល់។
- ប្រើលើ `<form onSubmit>` ដើម្បីការពារកុំឱ្យ reload ទំព័រ។
- ប្រើលើ tag `<a>` នៅពេលដែលអ្នកចង់ប្រើ SPA routing (ដូចជា `router.push`) ជំនួសឱ្យ hard browser navigation។

### Code Example: e.preventDefault() Usage

```jsx
const handleLinkClick = (e: React.MouseEvent<HTMLAnchorElement>) => {
  e.preventDefault();
  router.push('/custom-destination');
};
```
