# Preventing Default Behavior

Prevents the default browser action (e.g. following links, submitting forms, scrolling on arrow keys).

### Key Concepts & Rules:

- In React, returning `false` does not work; you must call `e.preventDefault()`.

### Code Example: e.preventDefault() Usage

```jsx
const handleLinkClick = (e: React.MouseEvent<HTMLAnchorElement>) => {
  e.preventDefault();
  router.push('/custom-destination');
};
```
