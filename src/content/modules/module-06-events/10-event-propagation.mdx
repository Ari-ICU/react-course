# Event Propagation

នៅក្នុង Document Object Model (DOM) ព្រឹត្តិការណ៍ clicks និង interactions ផ្សេងៗនឹងធ្វើដំណើរផុសឡើងលើ (Event Bubbling) ពី child element ឡើងទៅកាន់ parent elements តាមលំដាប់រហូតដល់ root។ ការហៅ `e.stopPropagation()` អនុញ្ញាតឱ្យយើងបញ្ឈប់ដំណើរ bubbling នេះមិនឱ្យប៉ះពាល់ដល់ parent handlers ឡើយ។

### Key Concepts & Rules:

- សំខាន់បំផុតសម្រាប់ nested clickable elements ដូចជាប៊ូតុង "Delete" ឬ "Bookmark" ដែលស្ថិតនៅក្នុង clickable card។
- `e.stopPropagation()` បញ្ឈប់ការបញ្ជូន event ទៅកាន់ parent components ខាងលើ។
- ខុសពី `e.preventDefault()`៖ `preventDefault` ទប់ស្កាត់ browser default action ចំណែក `stopPropagation` ទប់ស្កាត់កុំឱ្យ event រត់ឡើងទៅ parent។

### Code Example: e.stopPropagation() in Nested Elements

```jsx
export function CardWithAction() {
  return (
    <div onClick={() => console.log("Card opened")} className="p-4 border rounded">
      <h3>Card Title</h3>
      <button 
        onClick={(e) => {
          e.stopPropagation(); // Prevents card opening!
          console.log("Deleted");
        }}
        className="text-rose-500"
      >
        Delete
      </button>
    </div>
  );
}
```
