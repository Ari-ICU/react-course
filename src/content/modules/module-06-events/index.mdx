# Module 06: Events

React synthetic events, onClick, onChange, onSubmit, event propagation, preventDefault, and event handling patterns.

## Module Syllabus (12 Lessons)

- **Lesson 01**: React Events - *Cross-browser SyntheticEvent wrapper system.*
- **Lesson 02**: Event Handlers - *Passing handler function references vs invoking functions.*
- **Lesson 03**: onClick - *Handling click interactions on buttons, links, and cards.*
- **Lesson 04**: onChange - *Tracking input, textarea, and select changes in real time.*
- **Lesson 05**: onSubmit - *Handling form submissions and preventing full-page reloads.*
- **Lesson 06**: onMouseEnter & onMouseLeave - *Hover states and tooltips.*
- **Lesson 07**: Passing Event Functions - *Passing custom event triggers through props.*
- **Lesson 08**: Event Parameters - *Supplying additional data along with synthetic events.*
- **Lesson 09**: Preventing Default Behavior - *Using e.preventDefault() on forms, links, and keyboard events.*
- **Lesson 10**: Event Propagation - *Event bubbling and e.stopPropagation().*
- **Lesson 11**: Keyboard Events - *Handling onKeyDown, Escape modal closing, and Cmd+K shortcuts.*
- **Lesson 12**: Event Handling Best Practices - *Debouncing rapid clicks, avoiding inline allocations when unnecessary.*
