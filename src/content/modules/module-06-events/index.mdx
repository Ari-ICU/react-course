# Module 06: Events

ស្វែងយល់ស៊ីជម្រៅអំពី React SyntheticEvent System, onClick, onChange, onSubmit, Event Bubbling/Propagation, ការប្រើប្រាស់ preventDefault និងគោលការណ៍ Best Practices ក្នុងការគ្រប់គ្រង Events ឱ្យមានសុវត្ថិភាព។

## Module Syllabus (12 Lessons)

- **Lesson 01**: React Events - *ប្រព័ន្ធ SyntheticEvent របស់ React ដែលធ្វើការ wrap native browser events ឱ្យដំណើរការដូចគ្នានៅលើគ្រប់ browsers។*
- **Lesson 02**: Event Handlers - *ភាពខុសគ្នារវាងការបញ្ជូន Function Reference និងការហៅ Function (Invocation) ពេល render។*
- **Lesson 03**: onClick - *ការចាប់យក និងគ្រប់គ្រង Click interactions លើ buttons, links, និង UI cards។*
- **Lesson 04**: onChange - *ការតាមដានការផ្លាស់ប្តូរទិន្នន័យ (Real-time updates) លើ text inputs, textareas, និង select dropdowns។*
- **Lesson 05**: onSubmit - *ការគ្រប់គ្រង Form submissions និងការការពារមិនឱ្យ browser refresh/reload ទំព័រ។*
- **Lesson 06**: onMouseEnter & onMouseLeave - *ការគ្រប់គ្រង Hover interactions, animations និងការបង្ហាញ tooltips។*
- **Lesson 07**: Passing Event Functions - *ការបញ្ជូន custom event callback functions ឆ្លងកាត់ props ចុះទៅកាន់ child components។*
- **Lesson 08**: Event Parameters - *ការបញ្ជូន arguments បន្ថែម (ដូចជា record ID) ទៅកាន់ event handlers តាមរយៈ inline arrow functions។*
- **Lesson 09**: Preventing Default Behavior - *ការប្រើប្រាស់ `e.preventDefault()` លើ forms, links និង keyboard shortcuts។*
- **Lesson 10**: Event Propagation - *ស្វែងយល់អំពី Event Bubbling និងការទប់ស្កាត់ parent trigger ដោយប្រើ `e.stopPropagation()`។*
- **Lesson 11**: Keyboard Events - *ការគ្រប់គ្រង Keyboard interactions ដូចជាការចុច Enter, Escape ដើម្បីបិទ modal, និង shortcut Cmd+K។*
- **Lesson 12**: Event Handling Best Practices - *គោលការណ៍ល្អៗដូចជា Debouncing, ការការពារ Double-submit, និងការរៀបចំ handler logic ឱ្យមានរបៀប។*
