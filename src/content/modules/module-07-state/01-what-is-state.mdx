# What is State?

State is data that changes over time in response to user actions or network responses. When state changes, React schedules a re-render of the component and updates the DOM.

### Key Concepts & Rules:

- State is private to the component instance.
- State persists across re-renders.
- Updating state triggers reconciliation.

### Code Example: Basic State Declaration

```jsx
import { useState } from 'react';

export function Counter() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)} className="px-4 py-2 bg-blue-600 text-white rounded">
      Count: {count}
    </button>
  );
}
```
