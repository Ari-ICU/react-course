# State vs Props

Props configure a component from the outside; State stores interactive changes on the inside.

### Key Concepts & Rules:

- Props are passed down; State is managed internally.

### Code Example: State vs Props in Action

```jsx
// Props: Read-only input from parent
function Display({ message }: { message: string }) {
  return <h1>{message}</h1>;
}

// State: Internal interactive value
function Editor() {
  const [text, setText] = useState("Hello");
  return <Display message={text} />;
}
```
