# State vs Props

ខណៈពេលដែល Props ត្រូវបានប្រើដើម្បី configure component ពីខាងក្រៅ (ដូច parameters នៃ function) State វិញត្រូវបានប្រើដើម្បីផ្ទុក និងគ្រប់គ្រងទិន្នន័យដែលមានប្រតិកម្មរហ័ស (interactive changes) នៅខាងក្នុង component ផ្ទាល់។

### Key Concepts & Rules:

- **Props**៖ បញ្ជូនពីលើចុះក្រោម (Parent -> Child) និងមានលក្ខណៈ Read-only (Immutable)។
- **State**៖ បង្កើត និងគ្រប់គ្រងផ្ទៃក្នុង component ដោយអាចធ្វើការកែប្រែតម្លៃបានតាមរយៈ updater function។
- Component អាចបញ្ជូន state របស់ខ្លួនចុះក្រោមទៅឱ្យ child component ប្រើប្រាស់ក្នុងនាមជា props បាន។

### Code Example: State vs Props in Action

```jsx
// Props: Read-only input from parent
function Display({ message }: { message: string }) {
  return <h1>{message}</h1>;
}

// State: Internal interactive value
function Editor() {
  const [text, setText] = useState("Hello");
  return <Display message={text} />;
}
```
