# State and Re-rendering

React ធ្វើការប្រៀបធៀបតម្លៃ state ចាស់ និងថ្មីដោយប្រើប្រាស់ algorithm `Object.is()`។ ប្រសិនបើតម្លៃ memory reference នៅដដែល (មិនប្រែប្រួល) React នឹងសន្មតថាគ្មានអ្វីផ្លាស់ប្តូរឡើយ ហើយរំលងការ re-render ចោល។ ហេតុនេះហើយបានជាការ mutate objects ឬ arrays ដោយផ្ទាល់មិនអាចធ្វើឱ្យ UI ធ្វើបច្ចុប្បន្នភាពបាន។

### Key Concepts & Rules:

- ការ mutate object/array ដោយផ្ទាល់រក្សា memory reference ដដែល -> React មិន trigger re-render ឡើយ!
- ត្រូវតែ return object ឬ array ថ្មីជានិច្ចតាមរយៈ Spread Operator (`...`) ឬ Immutable methods។
- រាល់ការផ្លាស់ប្តូរ state ដោយជោគជ័យនឹងជំរុញឱ្យ component និង child components របស់វា re-render ឡើងវិញ។

### Code Example: Immutability & Object.is() Comparison

```jsx
import React, { useState } from 'react';

export function ImmutableItemList() {
  const [items, setItems] = useState<string[]>(['Learn JSX', 'Master Hooks']);

  // ❌ Bug: Mutating array in-place keeps identical memory reference
  // Object.is(items, items) === true -> React skips re-render!
  const handleMutateBug = () => {
    // items.push('New Item');
    // setItems(items); // Does NOT update the UI!
  };

  // ✅ Correct: Create a new array reference via spread operator
  const handleImmutableAdd = () => {
    const newItem = `Item #${items.length + 1}`;
    setItems(prev => [...prev, newItem]); // New reference -> triggers re-render!
  };

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-4">
      <ul className="list-disc pl-5 text-slate-300 text-sm space-y-1">
        {items.map((item, idx) => (
          <li key={idx}>{item}</li>
        ))}
      </ul>
      <button
        onClick={handleImmutableAdd}
        className="px-4 py-2 bg-emerald-600 hover:bg-emerald-700 text-white rounded-lg text-sm font-semibold"
      >
        Add Item (Immutable Spread)
      </button>
    </div>
  );
}
```
