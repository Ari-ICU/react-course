# State and Re-rendering

React compares old state with new state using `Object.is()`. If the reference is unchanged, React skips re-rendering. This is why mutating objects in place fails to trigger updates!

### Key Concepts & Rules:

- Mutating an object/array in-place keeps identical memory reference -> no re-render!
- Always return a new object or array copy via spread operator.

### Code Example: Immutability & Object.is() Comparison

```tsx
// ❌ Bug: Mutating array in place fails to re-render
/*
items.push(newItem);
setItems(items); // Identical reference! React does nothing.
*/

// ✅ Fix: Create new array reference via spread
setItems(prev => [...prev, newItem]);
```
