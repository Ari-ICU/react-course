# Updating Objects

នៅក្នុង JavaScript អថេរ object គឺជា reference type។ នៅពេលអ្នកចង់កែប្រែ property ណាមួយនៅក្នុង object state អ្នកត្រូវតែប្រើប្រាស់ Object Spread Operator (`...`) ដើម្បីចម្លង properties ចាស់ៗទាំងអស់ រួច overwrite លើ property ណាដែលអ្នកចង់ផ្លាស់ប្តូរតម្លៃ។

### Key Concepts & Rules:

- រូបមន្តទូទៅ៖ `setUser(prev => ({ ...prev, name: 'New Name' }))`។
- កុំកែប្រែដោយផ្ទាល់ដូចជា `user.name = 'New Name'` ដាច់ខាត។
- ត្រូវប្រាកដថា wrap object literals ដោយវង់ក្រចក `({ ... })` ពេល return ចេញពី arrow function។

### Code Example: Updating Object State Immutably

```jsx
interface Profile {
  name: string;
  theme: 'light' | 'dark';
  notifications: boolean;
}

const [profile, setProfile] = useState<Profile>({
  name: 'Alex',
  theme: 'dark',
  notifications: true,
});

// Update single field safely:
const toggleTheme = () => {
  setProfile(prev => ({
    ...prev,
    theme: prev.theme === 'dark' ? 'light' : 'dark',
  }));
};
```
