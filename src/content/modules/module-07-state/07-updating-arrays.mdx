# Updating Arrays

Arrays នៅក្នុង State មិនត្រូវកែប្រែតាមរយៈ mutating methods ដូចជា `.push()`, `.pop()`, `.splice()`, ឬ `.reverse()` ឡើយ។ ជំនួសមកវិញ អ្នកត្រូវតែប្រើប្រាស់ immutable methods ដូចជា `.filter()` សម្រាប់លុបធាតុ, `.map()` សម្រាប់កែប្រែធាតុ និង `[...prev, item]` សម្រាប់បន្ថែមធាតុថ្មី។

### Key Concepts & Rules:

- **បន្ថែមធាតុថ្មី**៖ `[...items, newItem]`
- **លុបធាតុ**៖ `items.filter(i => i.id !== id)`
- **កែប្រែធាតុជាក់លាក់**៖ `items.map(i => i.id === id ? { ...i, done: true } : i)`
- វិធីសាស្ត្រទាំងអស់នេះបង្កើត array ថ្មីមួយជានិច្ច ដែលធ្វើឱ្យ React ដឹងពីការប្រែប្រួល និង re-render UI ភ្លាមៗ។

### Code Example: Immutable Array Helpers

```jsx
// Common Immutable Array Operations:
// 1. Add
setTodos(prev => [...prev, newTodo]);

// 2. Remove
setTodos(prev => prev.filter(todo => todo.id !== deleteId));

// 3. Update single item
setTodos(prev => prev.map(todo => 
  todo.id === targetId ? { ...todo, completed: !todo.completed } : todo
));
```
