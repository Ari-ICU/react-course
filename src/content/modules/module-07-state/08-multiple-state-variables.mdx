# Multiple State Variables

Split unrelated state into independent `useState` calls. Group state into an object only if fields change together or represent a unified form model.

### Key Concepts & Rules:

- Independent state variables make code easier to reason about and refactor.

### Code Example: Multiple State Slices

```jsx
// Good: Independent concerns kept separate
const [searchQuery, setSearchQuery] = useState('');
const [currentPage, setCurrentPage] = useState(1);
const [isLoading, setIsLoading] = useState(false);
```
