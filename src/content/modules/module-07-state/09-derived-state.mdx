# Derived State

Never store in state what can be calculated from existing props or state! Calculate derived values directly during rendering.

### Key Concepts & Rules:

- Storing redundant state leads to out-of-sync bugs.
- Use `useMemo` only if derived calculation is computationally heavy.

### Code Example: Derived State Pattern

```tsx
// ❌ Redundant state anti-pattern:
// const [items, setItems] = useState([]);
// const [itemCount, setItemCount] = useState(0); // Redundant!

// ✅ Derived state:
export function CartView({ items }: { items: CartItem[] }) {
  // Purely derived calculation during render:
  const itemCount = items.length;
  const totalPrice = items.reduce((sum, item) => sum + item.price * item.quantity, 0);

  return <div>Total ({itemCount} items): ${totalPrice.toFixed(2)}</div>;
}
```
