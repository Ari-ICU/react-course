# State Batching

React automatically batches state updates across async boundaries (setTimeout, fetch promises, native events) into a single re-render.

### Key Concepts & Rules:

- Reduces unnecessary intermediate renders and boosts performance.

### Code Example: Automatic Async Batching

```tsx
async function handleAsyncSave() {
  await api.save();
  // In React 18+, both updates batch into 1 single render:
  setIsLoading(false);
  setSuccess(true);
}
```
