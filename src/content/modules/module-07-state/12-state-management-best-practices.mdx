# State Management Best Practices

ការគ្រប់គ្រង State ឱ្យមានរបៀបរៀបរយគឺជាគន្លឹះចម្បងក្នុងការជៀសវាង bugs និងធ្វើឱ្យកម្មវិធី React ងាយស្រួលពង្រីក។ គោលការណ៍ចម្បងគឺត្រូវរក្សា State ឱ្យនៅជិតបំផុតទៅនឹងទីកន្លែងដែលត្រូវប្រើប្រាស់វា (State Colocation) និងជៀសវាងការបង្កើត Global State ដោយមិនចាំបាច់។

### Key Concepts & Rules:

- **State Colocation**៖ រក្សា state ឱ្យនៅខាងក្នុង component ផ្ទាល់។ លើក state ឡើងទៅ parent (Lifting State Up) លុះត្រាតែមាន sibling components ផ្សេងទៀតត្រូវការប្រើប្រាស់ទិន្នន័យនោះរួមគ្នា។
- **Single Source of Truth**៖ កុំចម្លង props ទៅដាក់ក្នុង state លុះត្រាតែអ្នកមានបំណងចង់ឱ្យវាដើរតួជា initial value ស៊ីដាច់ដោយឡែក។
- រក្សា state ឱ្យនៅជាទម្រង់សាមញ្ញ និងប្រើ derived values ជំនួសការបង្កើត state ស្ទួន។

### Code Example: State Colocation Rule

```jsx
import React, { useState } from 'react';

// 1. Child component collocates its own toggle state locally
function SearchModal() {
  const [isOpen, setIsOpen] = useState(false); // Colocated: App root does not need this!

  return (
    <div>
      <button onClick={() => setIsOpen(true)} className="text-sm text-blue-400">
        Open Search
      </button>
      {isOpen && (
        <div className="fixed inset-0 bg-black/60 flex items-center justify-center p-4">
          <div className="bg-slate-900 border border-slate-800 p-6 rounded-xl space-y-3">
            <h3 className="text-white font-bold">Search Modal</h3>
            <button onClick={() => setIsOpen(false)} className="px-3 py-1 bg-slate-700 text-white rounded">
              Close
            </button>
          </div>
        </div>
      )}
    </div>
  );
}

// 2. Compute Derived State instead of storing redundant state variables:
export function UserProfileCard() {
  const [firstName, setFirstName] = useState('Dara');
  const [lastName, setLastName] = useState('Chan');

  // ✅ Derived value computed on render (No redundant useState needed!):
  const fullName = `${firstName} ${lastName}`;

  return (
    <div className="p-4 bg-slate-900 border border-slate-800 rounded-xl space-y-2">
      <h4 className="text-white font-semibold">User: {fullName}</h4>
      <SearchModal />
    </div>
  );
}
```
