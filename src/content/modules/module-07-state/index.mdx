# Module 07: State

useState, state vs props, re-rendering triggers, updating objects and arrays immutably, and derived state.

## Module Syllabus (12 Lessons)

- **Lesson 01**: What is State? - *Component memory that triggers UI re-renders upon mutation.*
- **Lesson 02**: State vs Props - *Internal mutable component data vs external immutable inputs.*
- **Lesson 03**: useState - *Declaring state variables and updater functions.*
- **Lesson 04**: Updating State - *Direct replacement vs functional updater pattern.*
- **Lesson 05**: State and Re-rendering - *How React triggers reconciliation when Object.is() returns false.*
- **Lesson 06**: Updating Objects - *Copying object properties with spread syntax.*
- **Lesson 07**: Updating Arrays - *Adding, filtering, updating, and removing array elements immutably.*
- **Lesson 08**: Multiple State Variables - *When to split state vs when to group related fields into an object.*
- **Lesson 09**: Derived State - *Calculating values on the fly instead of storing redundant state.*
- **Lesson 10**: State Initialization - *Lazy state initialization for expensive setup computations.*
- **Lesson 11**: State Batching - *React 18+ automatic grouping of multiple updates in promises and timeouts.*
- **Lesson 12**: State Management Best Practices - *Keep state local, lift state only when needed, and avoid duplicate sources of truth.*
