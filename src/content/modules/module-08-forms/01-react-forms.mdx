# React Forms

In standard HTML, form inputs hold their own internal DOM state. In React, we bind input values to React state, making React the single source of truth.

### Key Concepts & Rules:

- Controlled inputs bind `value` to state and `onChange` to state setters.

### Code Example: Controlled Input

```jsx
export function SimpleForm() {
  const [name, setName] = useState('');
  return (
    <input 
      value={name} 
      onChange={(e) => setName(e.target.value)} 
      className="p-2 border rounded"
    />
  );
}
```
