# Controlled Components

Controlled Component ធានាថារាល់អ្វីៗដែលអ្នកប្រើប្រាស់មើលឃើញនៅលើអេក្រង់ គឺតែងតែស៊ីសង្វាក់គ្នា (synchronized) ជាមួយ React State ជានិច្ច។ វិធីសាស្ត្រនេះអនុញ្ញាតឱ្យយើងអាចត្រួតពិនិត្យ (validate), កែតម្រូវទម្រង់ (format), និងសម្អាត (sanitize) តម្លៃដែលបញ្ចូលមកបានភ្លាមៗក្នុង real-time។

### Key Concepts & Rules:

- តម្លៃរបស់ element ត្រូវបានកំណត់ និងគ្រប់គ្រងដោយ State ជានិច្ច (`value={state}`)។
- រាល់ការផ្លាស់ប្តូរតម្លៃត្រូវតែឆ្លងកាត់ `onChange` handler ជាមុនសិន មុនពេលបង្ហាញឡើងវិញនៅលើអេក្រង់។
- អ្នកអាចបដិសេធ ឬកែសម្រួលអក្សរដែលអ្នកប្រើប្រាស់វាយចូល (ឧទាហរណ៍៖ អនុញ្ញាតឱ្យវាយតែលេខ) យ៉ាងងាយស្រួល។

### Code Example: Controlled Input with Sanitization

```jsx
export function PhoneInput() {
  const [phone, setPhone] = useState('');

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    // Only allow digits:
    const cleaned = e.target.value.replace(/\D/g, '').slice(0, 10);
    setPhone(cleaned);
  };

  return <input value={phone} onChange={handleChange} placeholder="Digits only" />;
}
```
