# Input Fields

ធាតុ `<input>` ស្តង់ដារនៅក្នុង React មានឥរិយាបថដូចគ្នានឹង HTML input ធម្មតាដែរ ប៉ុន្តែ attributes មួយចំនួនត្រូវបានប្តូរទៅជាទម្រង់ camelCase។ អ្នកអាចប្រើប្រាស់ input types ផ្សេងៗដូចជា `text`, `email`, `password`, ឬ `number` ជាមួយ Controlled State បានយ៉ាងរលូន។

### Key Concepts & Rules:

- ប្រើប្រាស់ `type="email"` ឬ `type="password"` ជាមួយនឹង controlled values ជានិច្ច។
- តែងតែផ្តល់នូវ `placeholder` និង label ច្បាស់លាស់ដើម្បីបង្កើន accessibility និងបទពិសោធន៍អ្នកប្រើប្រាស់។
- ប្រើ Tailwind classes ដើម្បីរៀបចំ styles ឱ្យស្រស់ស្អាត ដូចជា focus ring និង border states។

### Code Example: Password Input

```jsx
<input 
  type="password"
  value={password}
  onChange={(e) => setPassword(e.target.value)}
  placeholder="Enter secure password"
  className="px-3 py-2 bg-slate-900 border border-slate-800 rounded-lg text-white"
/>
```
