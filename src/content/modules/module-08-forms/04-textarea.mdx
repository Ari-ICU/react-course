# Textarea

Unlike HTML where textarea content sits between tags (`<textarea>hello</textarea>`), React uses the `value` attribute: `<textarea value={bio} onChange={...} />`.

### Key Concepts & Rules:

- Use `value` attribute, not children.

### Code Example: Controlled Textarea

```jsx
<textarea 
  value={bio} 
  onChange={(e) => setBio(e.target.value)} 
  rows={4} 
  className="w-full bg-slate-900 border rounded-lg p-3 text-white"
/>
```
