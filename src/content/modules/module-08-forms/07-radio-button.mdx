# Radio Button

Radio buttons share a common `name` attribute and are controlled by comparing `checked={selectedOption === value}`.

### Key Concepts & Rules:

- Bind all radios in group to the same state string.

### Code Example: Controlled Radio Group

```tsx
export function PlanSelector() {
  const [plan, setPlan] = useState<'free' | 'pro'>('pro');

  return (
    <div className="flex gap-4">
      {['free', 'pro'].map((option) => (
        <label key={option} className="flex items-center gap-2">
          <input 
            type="radio" 
            name="plan" 
            value={option} 
            checked={plan === option} 
            onChange={(e) => setPlan(e.target.value as 'free' | 'pro')} 
          />
          <span className="capitalize">{option} Plan</span>
        </label>
      ))}
    </div>
  );
}
```
