# Radio Button

Radio Buttons ត្រូវបានប្រើប្រាស់នៅពេលដែលអ្នកចង់ឱ្យអ្នកប្រើប្រាស់ជ្រើសរើសយកជម្រើសតែមួយគត់ (Single-choice) ចេញពីជម្រើសជាច្រើន។ គ្រប់ radio inputs នៅក្នុង group តែមួយត្រូវតែប្រើប្រាស់ `name` attribute ដូចគ្នា និងត្រូវគ្រប់គ្រងដោយការប្រៀបធៀប `checked={selectedOption === value}`។

### Key Concepts & Rules:

- ចងភ្ជាប់ radio buttons ទាំងអស់ក្នុង group ទៅកាន់ state string តែមួយ។
- លក្ខខណ្ឌជ្រើសរើសត្រូវបានកំណត់តាមរយៈ boolean expression៖ `checked={plan === option}`។
- ប្រើ `.map()` ដើម្បី render radio buttons ចេញពី array ដើម្បីកាត់បន្ថយកូដស្ទួន។

### Code Example: Controlled Radio Group

```jsx
export function PlanSelector() {
  const [plan, setPlan] = useState<'free' | 'pro'>('pro');

  return (
    <div className="flex gap-4">
      {['free', 'pro'].map((option) => (
        <label key={option} className="flex items-center gap-2">
          <input 
            type="radio" 
            name="plan" 
            value={option} 
            checked={plan === option} 
            onChange={(e) => setPlan(e.target.value as 'free' | 'pro')} 
          />
          <span className="capitalize">{option} Plan</span>
        </label>
      ))}
    </div>
  );
}
```
