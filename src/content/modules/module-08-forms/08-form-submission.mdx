# Form Submission

Handle form submission on `<form onSubmit={...}>` with validation before dispatching to an API service.

### Key Concepts & Rules:

- Always prevent default browser reload.

### Code Example: Safe Form Submission Handler

```jsx
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  setIsSubmitting(true);
  try {
    await apiClient.post('/users', formData);
    showSuccessToast('User registered successfully');
  } catch (err) {
    showErrorToast('Failed to register user');
  } finally {
    setIsSubmitting(false);
  }
};
```
