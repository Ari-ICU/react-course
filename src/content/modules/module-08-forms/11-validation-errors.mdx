# Validation Errors

Display red borders on invalid inputs and contextual error messages below them.

### Key Concepts & Rules:

- Accessible error messages linked via `aria-describedby`.

### Code Example: Inline Validation Error

```jsx
<div>
  <input 
    className={cn("border rounded p-2", errors.email && "border-rose-500 bg-rose-950/20")}
    value={email}
    onChange={(e) => setEmail(e.target.value)}
  />
  {errors.email && <p className="text-xs text-rose-400 mt-1">{errors.email}</p>}
</div>
```
