# Validation Errors

ការបង្ហាញកំហុសនៅលើ UI គួរតែមានភាពច្បាស់លាស់ និងនៅកៀកនឹង input field ផ្ទាល់ (Inline Errors)។ អ្នកអាចផ្លាស់ប្តូរពណ៌ border នៃ input ទៅជាពណ៌ក្រហម (rose/red) និងបង្ហាញ error text នៅពីក្រោម input ដើម្បីឱ្យអ្នកប្រើប្រាស់ងាយស្រួលកែតម្រូវ។

### Key Concepts & Rules:

- ផ្លាស់ប្តូរ CSS border classes ដោយផ្អែកលើវត្តមានរបស់ error (ឧ. `errors.email && "border-rose-500"`).
- បង្ហាញ conditional message ខាងក្រោម input ដោយប្រើ syntax `errors.field && <p>{errors.field}</p>`។
- ប្រើ attribute `aria-describedby` សម្រាប់ accessibility ដើម្បីឱ្យ screen readers អាចអាន error message បាន។

### Code Example: Inline Validation Error

```jsx
<div>
  <input 
    className={cn("border rounded p-2", errors.email && "border-rose-500 bg-rose-950/20")}
    value={email}
    onChange={(e) => setEmail(e.target.value)}
  />
  {errors.email && <p className="text-xs text-rose-400 mt-1">{errors.email}</p>}
</div>
```
