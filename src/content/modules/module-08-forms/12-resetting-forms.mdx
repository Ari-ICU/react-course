# Resetting Forms

Reset state back to initial constants after a successful submission.

### Key Concepts & Rules:

- Extract `INITIAL_STATE` constant for easy resetting.

### Code Example: Resetting Form State

```jsx
const INITIAL_FORM = { title: '', description: '' };

export function CreateTaskForm() {
  const [form, setForm] = useState(INITIAL_FORM);

  const handleSuccess = () => {
    // Reset to blank:
    setForm(INITIAL_FORM);
  };
}
```
