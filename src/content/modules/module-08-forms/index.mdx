# Module 08: Forms

Controlled vs uncontrolled components, input types, form validation, error states, and reusable form components.

## Module Syllabus (13 Lessons)

- **Lesson 01**: React Forms - *HTML form elements vs React's state-driven input models.*
- **Lesson 02**: Controlled Components - *Inputs whose values are strictly driven by React state.*
- **Lesson 03**: Input Fields - *Handling text, number, email, and password types.*
- **Lesson 04**: Textarea - *Multi-line text input with controlled value prop.*
- **Lesson 05**: Select - *Dropdown select with controlled option values.*
- **Lesson 06**: Checkbox - *Boolean inputs using checked prop and e.target.checked.*
- **Lesson 07**: Radio Button - *Single-choice selection from a group.*
- **Lesson 08**: Form Submission - *Packaging form data and sending to API endpoints.*
- **Lesson 09**: Form State - *Managing multi-field forms with a single state object.*
- **Lesson 10**: Form Validation - *Client-side synchronous validation rules.*
- **Lesson 11**: Validation Errors - *Rendering user-friendly error banners and inline field messages.*
- **Lesson 12**: Resetting Forms - *Restoring form state back to clean initial values.*
- **Lesson 13**: Reusable Form Components - *Building generic TextField, CheckboxField, and SelectField components.*
