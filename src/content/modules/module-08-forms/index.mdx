# Module 08: Forms

ស្វែងយល់ស៊ីជម្រៅអំពី Controlled vs Uncontrolled Components, ប្រភេទ Input ផ្សេងៗ (Text, Textarea, Select, Checkbox, Radio), Form Validation, ការគ្រប់គ្រង Error States និងការបង្កើត Reusable Form Components។

## Module Syllabus (13 Lessons)

- **Lesson 01**: React Forms - *ភាពខុសគ្នារវាងទម្រង់ Form ធម្មតាក្នុង HTML និង State-driven model របស់ React។*
- **Lesson 02**: Controlled Components - *ការគ្រប់គ្រងតម្លៃ Inputs ទាំងស្រុងតាមរយៈ React State (Single Source of Truth)។*
- **Lesson 03**: Input Fields - *ការគ្រប់គ្រង input types ផ្សេងៗដូចជា text, number, email និង password។*
- **Lesson 04**: Textarea - *ការគ្រប់គ្រង multi-line text input ដោយប្រើ controlled `value` prop ជំនួសឱ្យ children។*
- **Lesson 05**: Select - *ការគ្រប់គ្រង Dropdown select ដោយកំណត់ `value` ផ្ទាល់លើ `<select>` tag។*
- **Lesson 06**: Checkbox - *ការគ្រប់គ្រង boolean inputs តាមរយៈ `checked` prop និង `e.target.checked`។*
- **Lesson 07**: Radio Button - *ការគ្រប់គ្រងការជ្រើសរើសជម្រើសតែមួយគត់ចេញពីក្រុម (Radio Group)។*
- **Lesson 08**: Form Submission - *ការវេចខ្ចប់ទិន្នន័យ Form និងការបញ្ជូនទៅកាន់ API endpoints ដោយសុវត្ថិភាព។*
- **Lesson 09**: Form State - *ការគ្រប់គ្រង inputs ច្រើន fields ក្នុងពេលតែមួយដោយប្រើ State Object តែមួយ។*
- **Lesson 10**: Form Validation - *ក្បួនច្បាប់នៃការ validate ទិន្នន័យ synchronously នៅខាង client-side។*
- **Lesson 11**: Validation Errors - *ការបង្ហាញសារប្រាប់ error ឱ្យស្អាត និងងាយយល់នៅកៀកនឹង input fields នីមួយៗ (Inline Errors)។*
- **Lesson 12**: Resetting Forms - *ការសម្អាត និងកំណត់ទម្រង់ form ឱ្យត្រឡប់ទៅតម្លៃដើមវិញក្រោយ submit រួច។*
- **Lesson 13**: Reusable Form Components - *ការកសាង reusable wrappers ដូចជា FormField, TextField និង SelectField សម្រាប់ enterprise apps។*
