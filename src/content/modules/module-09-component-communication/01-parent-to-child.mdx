# Parent to Child

Parents pass state and configuration down to children as props.

### Key Concepts & Rules:

- Standard unidirectional data flow in React.

### Code Example: Parent to Child Data Flow

```tsx
<ChildComponent message="Hello from parent!" count={42} />
```
