# Parent to Child

នៅក្នុង React មធ្យោបាយចម្បងក្នុងការបញ្ជូនទិន្នន័យគឺការហូរចុះក្រោមពី Parent Component ទៅកាន់ Child Component តាមរយៈ **Props**។ Parent អាចបញ្ជូនទាំង primitive values, objects, arrays, ឬសូម្បីតែ JSX elements ទៅឱ្យ Child បានយ៉ាងងាយស្រួល។

### Key Concepts & Rules:

- ជាទម្រង់ស្តង់ដារនៃ **Unidirectional Data Flow** (លំហូរទិន្នន័យមួយទិស) ក្នុង React។
- Child Component ទទួលបាន Props ក្នុងលក្ខណៈ Read-only (មិនអាចកែប្រែតម្លៃដើមបានឡើយ)។
- នៅពេលដែលទិន្នន័យនៅក្នុង Parent ផ្លាស់ប្តូរ Child Component នឹងធ្វើការ re-render ដោយស្វ័យប្រវត្តិតាមតម្លៃថ្មីនោះ។

### Code Example: Parent to Child Data Flow

```jsx
<ChildComponent message="Hello from parent!" count={42} />
```
