# Child to Parent

Children notify parents of actions by calling function props supplied by the parent.

### Key Concepts & Rules:

- Children invoke callbacks with arguments.

### Code Example: Child to Parent Notification

```jsx
// Parent:
<ChildComponent onSelect={(itemId) => setSelected(itemId)} />

// Child:
<button onClick={() => onSelect('item-1')}>Select Item</button>
```
