# Passing Functions

ការបញ្ជូន Functions តាមរយៈ Props (Callback Delegation) ជួយផ្តាច់ UI Rendering របស់ Child ចេញពី State Management Logic របស់ Parent។ បច្ចេកទេសនេះធ្វើឱ្យ Child Components មានភាពឯករាជ្យ និងអាចយកទៅប្រើប្រាស់ឡើងវិញបានច្រើនកន្លែង (Highly Reusable) ជាមួយឥរិយាបថខុសៗគ្នា។

### Key Concepts & Rules:

- Child Component គ្រាន់តែទទួលរ៉ាប់រងលើ visual presentation និងការ trigger callbacks ប៉ុណ្ណោះ។
- បង្កើនភាពងាយស្រួលក្នុងការ reuse Child Component ឆ្លងកាត់ features ផ្សេងៗក្នុង app។
- ជួយឱ្យការធ្វើ Unit Test លើ UI Component មានភាពសាមញ្ញ ព្រោះគ្រាន់តែ mock callback functions។

### Code Example: Callback Action Delegation

```jsx
export function ActionToolbar({ onSave, onCancel }: ToolbarProps) {
  return (
    <div className="flex gap-2">
      <button onClick={onSave} className="bg-emerald-600 px-3 py-1 text-white rounded">Save</button>
      <button onClick={onCancel} className="bg-slate-700 px-3 py-1 text-white rounded">Cancel</button>
    </div>
  );
}
```
