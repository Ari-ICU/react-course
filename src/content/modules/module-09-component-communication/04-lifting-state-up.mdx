# Lifting State Up

នៅពេលដែល Components ពីរបងប្អូន (Siblings) ត្រូវការចែករំលែកទិន្នន័យ ឬធ្វើសមកាលកម្ម (synchronize) ជាមួយគ្នា អ្នកមិនអាចបញ្ជូនទិន្នន័យពីបងប្អូនមួយទៅមួយទៀតដោយផ្ទាល់បានទេ។ អ្នកត្រូវតែ **លើក State ឡើង (Lift State Up)** ចេញពី components ទាំងពីរនោះ ទៅដាក់ក្នុង Parent រួមដែលនៅជិតពួកវាបំផុត។

### Key Concepts & Rules:

- លុបបំបាត់បញ្ហាទិន្នន័យស្ទួន និងមិនស៊ីសង្វាក់គ្នា (Out-of-sync bugs)។
- Parent រួមដើរតួជា **Single Source of Truth** សម្រាប់ siblings ទាំងអស់។
- Parent បញ្ជូន state ចុះក្រោមជា props និងបញ្ជូន updater functions សម្រាប់ឱ្យ siblings ធ្វើការកែប្រែតម្លៃ។

### Code Example: Lifting State Up Pattern

```jsx
export function CommonParent() {
  const [activeTab, setActiveTab] = useState('summary');

  return (
    <div>
      <TabList activeTab={activeTab} onTabChange={setActiveTab} />
      <TabContent activeTab={activeTab} />
    </div>
  );
}
```
