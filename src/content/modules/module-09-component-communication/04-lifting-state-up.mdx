# Lifting State Up

When two sibling components need to share or synchronize data, move the state out of both and into their closest common parent.

### Key Concepts & Rules:

- Eliminates out-of-sync duplicate state.
- Parent becomes single source of truth.

### Code Example: Lifting State Up Pattern

```tsx
export function CommonParent() {
  const [activeTab, setActiveTab] = useState('summary');

  return (
    <div>
      <TabList activeTab={activeTab} onTabChange={setActiveTab} />
      <TabContent activeTab={activeTab} />
    </div>
  );
}
```
