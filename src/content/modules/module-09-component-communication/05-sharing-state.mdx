# Sharing State

ការចែករំលែក State រវាង Sibling Components ត្រូវបានសម្រេចឡើងដោយការ hoisted state ទៅកាន់ Parent។ Sibling ទាំងពីរនឹងទទួលបានទិន្នន័យរួមនោះជា props ហើយរាល់ការកែប្រែតម្លៃដែលកើតចេញពី sibling ណាមួយ នឹងឆ្លុះបញ្ចាំងទៅកាន់ sibling ផ្សេងទៀតភ្លាមៗ។

### Key Concepts & Rules:

- ធានានូវភាពស៊ីសង្វាក់គ្នានៃទិន្នន័យរវាងផ្ទាំង UI ផ្សេងៗនៅលើអេក្រង់តែមួយ។
- Sibling ទីមួយដើរតួជា Controller (អ្នកផ្លាស់ប្តូរទិន្នន័យ) រីឯ Sibling ទីពីរដើរតួជា Consumer (អ្នកបង្ហាញលទ្ធផល)។
- រក្សាស្ថាបត្យកម្មកូដឱ្យមានលក្ខណៈ Predictable និងងាយស្រួល Debug។

### Code Example: Sibling State Sharing

```jsx
import React, { useState } from 'react';

// Sibling A: Input controller that triggers changes
function FilterInput({ query, onQueryChange }: { query: string; onQueryChange: (val: string) => void }) {
  return (
    <input
      type="text"
      value={query}
      onChange={(e) => onQueryChange(e.target.value)}
      placeholder="Type to filter modules..."
      className="w-full px-3 py-2 bg-slate-800 border border-slate-700 rounded-lg text-white text-sm"
    />
  );
}

// Sibling B: Consumer that displays filtered data
function FilterResults({ count }: { count: number }) {
  return (
    <p className="text-xs text-slate-400">
      Found <span className="text-blue-400 font-bold">{count}</span> matching results
    </p>
  );
}

// Common Parent: Holds and coordinates shared state
export function SiblingStateCoordinator() {
  const [query, setQuery] = useState('');
  const allModules = ['JSX Syntax', 'State & Hooks', 'Routing', 'Context API'];
  const filtered = allModules.filter(m => m.toLowerCase().includes(query.toLowerCase()));

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <FilterInput query={query} onQueryChange={setQuery} />
      <FilterResults count={filtered.length} />
    </div>
  );
}
```
