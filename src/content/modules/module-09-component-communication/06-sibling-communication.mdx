# Sibling Communication

React components are isolated. Sibling A cannot call functions or access state in Sibling B. They must communicate through their shared parent or a global store.

### Key Concepts & Rules:

- No direct peer-to-peer coupling.

### Code Example: Sibling Communication Architecture

```tsx
/*
             [Common Parent]  <── Holds state
             /             \
      [Sibling A]       [Sibling B]
     (Triggers update)   (Reflects update)
*/
```
