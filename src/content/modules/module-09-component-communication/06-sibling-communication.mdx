# Sibling Communication

នៅក្នុង React រាល់ Component ទាំងអស់ត្រូវបានបង្កើតឡើងក្នុងលក្ខណៈឯករាជ្យដាច់ដោយឡែកពីគ្នា (Isolated)។ Sibling A គ្មានសិទ្ធិ ឬមធ្យោបាយណាមួយដើម្បីចូលទៅកាន់ State ឬហៅ Functions នៅខាងក្នុង Sibling B ដោយផ្ទាល់ឡើយ (No Peer-to-Peer coupling)។

### Key Concepts & Rules:

- **គ្មានការតភ្ជាប់ផ្ទាល់ (No Direct Coupling)**៖ ការពារកុំឱ្យ components ជាប់ជំពាក់គ្នាខ្លាំង (tight coupling) ដែលនាំឱ្យពិបាកកែប្រែ។
- **ដំណោះស្រាយ**៖
  1. ប្រើ **Common Parent** (លើក state ឡើង) ប្រសិនបើ siblings នៅកៀកគ្នា។
  2. ប្រើ **React Context** ឬ **Zustand** ប្រសិនបើ components នៅឆ្ងាយពីគ្នាខ្លាំងក្នុង component tree។

### Code Example: Sibling Communication Architecture

```jsx
/*
             [Common Parent]  <── Holds state
             /             \
      [Sibling A]       [Sibling B]
     (Triggers update)   (Reflects update)
*/
```
