# Prop Drilling

Prop Drilling (ឬ Threading) គឺជាស្ថានភាពដែលអ្នកត្រូវបញ្ជូន Props ឆ្លងកាត់ components ជាច្រើនជាន់ចុះក្រោម គ្រាន់តែដើម្បីឱ្យ component កូនចៅនៅជ្រៅបំផុត (Leaf Component) អាចចូលទៅកាន់ទិន្នន័យនោះបាន។ បញ្ហានេះធ្វើឱ្យ components នៅកណ្តាលពោរពេញដោយ props ដែលមិនចាំបាច់ និងធ្វើឱ្យការ refactor កូដមានភាពស្មុគស្មាញ។

### Key Concepts & Rules:

- ធ្វើឱ្យ Component APIs មានភាពរញ៉េរញ៉ៃ (Pollutes component interfaces)។
- ដំណោះស្រាយមាន ៣ សំខាន់ៗ៖
  1. **Component Composition** (ប្រើប្រាស់ `children` prop)។
  2. **React Context API** (សម្រាប់ state កម្រិតមធ្យម ដូចជា Theme ឬ Auth)។
  3. **Global State Management** (ដូចជា Zustand សម្រាប់ complex app data)។
