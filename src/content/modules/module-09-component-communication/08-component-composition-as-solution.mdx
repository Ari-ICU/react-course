# Component Composition as Solution

ជាញឹកញាប់ អ្នកអាចលុបបំបាត់បញ្ហា Prop Drilling បានយ៉ាងងាយស្រួលដោយមិនចាំបាច់ប្រើប្រាស់ Context API ឬ State Management Library ឡើយ។ ដំណោះស្រាយនោះគឺ **Component Composition** ដោយគ្រាន់តែបញ្ជូន leaf component ចូលទៅជា `children` ឬ slots ផ្ទាល់តែម្តង។

### Key Concepts & Rules:

- Components នៅកណ្តាល (ដូចជា `<Sidebar>`) គ្រាន់តែ render `{children}` ដោយមិនបាច់ដឹងពី props របស់ child ឡើយ។
- Leaf Component (ដូចជា `<Avatar user={user} />`) ត្រូវបានបង្កើតឡើងនៅ Parent កំពូលផ្ទាល់ ដែលមាន access ទៅកាន់ `user` រួចជាស្រេច។
- ជួយកាត់បន្ថយ coupling និងធ្វើឱ្យ components នៅកណ្តាលមានភាព generic ខ្ពស់។

### Code Example: Composition Solving Prop Drilling

```jsx
import React, { ReactNode } from 'react';

// Leaf component rendered where data lives
function UserBadge({ username }: { username: string }) {
  return <span className="font-bold text-blue-400">@{username}</span>;
}

// Intermediary components simply render children without knowing about user!
function SidebarNav({ children }: { children: ReactNode }) {
  return <nav className="p-3 bg-slate-800 rounded-lg">{children}</nav>;
}

function DashboardLayout({ children }: { children: ReactNode }) {
  return <div className="space-y-4">{children}</div>;
}

// Root creates the UserBadge directly, eliminating all prop forwarding:
export function CompositionSolutionDemo() {
  const user = { username: 'chann_dara' };

  return (
    <DashboardLayout>
      <SidebarNav>
        {/* ✅ Directly composed: No prop drilling through intermediate components! */}
        <UserBadge username={user.username} />
      </SidebarNav>
    </DashboardLayout>
  );
}
```
