# Component Composition as Solution

ជាញឹកញាប់ អ្នកអាចលុបបំបាត់បញ្ហា Prop Drilling បានយ៉ាងងាយស្រួលដោយមិនចាំបាច់ប្រើប្រាស់ Context API ឬ State Management Library ឡើយ។ ដំណោះស្រាយនោះគឺ **Component Composition** ដោយគ្រាន់តែបញ្ជូន leaf component ចូលទៅជា `children` ឬ slots ផ្ទាល់តែម្តង។

### Key Concepts & Rules:

- Components នៅកណ្តាល (ដូចជា `<Sidebar>`) គ្រាន់តែ render `{children}` ដោយមិនបាច់ដឹងពី props របស់ child ឡើយ។
- Leaf Component (ដូចជា `<Avatar user={user} />`) ត្រូវបានបង្កើតឡើងនៅ Parent កំពូលផ្ទាល់ ដែលមាន access ទៅកាន់ `user` រួចជាស្រេច។
- ជួយកាត់បន្ថយ coupling និងធ្វើឱ្យ components នៅកណ្តាលមានភាព generic ខ្ពស់។

### Code Example: Composition Solving Prop Drilling

```jsx
// Instead of passing user through Sidebar:
// <Sidebar><Avatar user={user} /></Sidebar>
```
