# Component Composition as Solution

Often you can solve prop drilling simply by passing the leaf component directly via `children` or named slots.

### Key Concepts & Rules:

- Intermediary components only render `{children}`, unaware of specific props.

### Code Example: Composition Solving Prop Drilling

```jsx
// Instead of passing user through Sidebar:
// <Sidebar><Avatar user={user} /></Sidebar>
```
