# Designing Component APIs

ការរចនា Props របស់ Component ប្រៀបដូចជាការបង្កើត Public Library API មួយអ៊ីចឹង៖ អ្នកគួរតែរក្សាវាឱ្យសាមញ្ញបំផុត ផ្តល់តម្លៃ default សមរម្យ និងប្រើប្រាស់ TypeScript Type Definitions ឱ្យបានច្បាស់លាស់ដើម្បីឱ្យអ្នកដទៃងាយស្រួលហៅប្រើប្រាស់ និងការពារកំហុស។

### Key Concepts & Rules:

- ប្រើប្រាស់ **Discriminated Unions** ក្នុង TypeScript សម្រាប់លក្ខខណ្ឌដែលមិនអាចកើតមានទន្ទឹមគ្នា (Mutually Exclusive States)។
- កំណត់ឈ្មោះ Props ឱ្យច្បាស់លាស់ និងមានលក្ខណៈ Intuitive ស្របតាមក្បួន React conventions។
- ជៀសវាងការបង្កើត props ច្រើនហួសហេតុ (Boolean flag explosion) ដែលធ្វើឱ្យ component ពិបាកថែទាំ។

### Code Example: Discriminated Union Props

```jsx
import React from 'react';

// Mutually exclusive prop API design via TypeScript Discriminated Unions:
type AlertProps =
  | { variant: 'simple'; message: string }
  | { variant: 'actionable'; message: string; actionLabel: string; onAction: () => void };

export function BannerAlert(props: AlertProps) {
  return (
    <div className="p-4 bg-slate-900 border border-slate-800 rounded-xl flex items-center justify-between">
      <span className="text-slate-200 text-sm">{props.message}</span>

      {/* TypeScript guarantees onAction exists ONLY if variant is 'actionable' */}
      {props.variant === 'actionable' && (
        <button
          onClick={props.onAction}
          className="px-3 py-1 bg-blue-600 hover:bg-blue-700 text-white rounded text-xs font-semibold"
        >
          {props.actionLabel}
        </button>
      )}
    </div>
  );
}
```
