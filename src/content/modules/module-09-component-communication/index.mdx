# Module 09: Component Communication

Parent-child data passing, child-to-parent callbacks, lifting state up, sibling communication, and avoiding prop drilling.

## Module Syllabus (9 Lessons)

- **Lesson 01**: Parent to Child - *Downwards data flow via props.*
- **Lesson 02**: Child to Parent - *Upwards event notification via callback functions.*
- **Lesson 03**: Passing Functions - *Using callbacks for modular event delegation.*
- **Lesson 04**: Lifting State Up - *Moving state to the closest common ancestor of communicating siblings.*
- **Lesson 05**: Sharing State - *Synchronizing sibling views through hoisted state.*
- **Lesson 06**: Sibling Communication - *Why siblings cannot directly talk to each other in React.*
- **Lesson 07**: Prop Drilling - *The problem of passing props through intermediary components that don't need them.*
- **Lesson 08**: Component Composition as Solution - *Passing slotted elements down rather than raw props.*
- **Lesson 09**: Designing Component APIs - *Crafting ergonomic, intuitive props for long-term maintainability.*
