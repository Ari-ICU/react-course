# Module 09: Component Communication

ស្វែងយល់ស៊ីជម្រៅអំពីលំហូរទិន្នន័យពី Parent ទៅ Child, ការបញ្ជូន Callback Functions ពី Child ទៅ Parent, បច្ចេកទេស Lifting State Up, ការទំនាក់ទំនងរវាង Sibling Components, បញ្ហា Prop Drilling និងដំណោះស្រាយតាមរយៈ Component Composition។

## Module Syllabus (9 Lessons)

- **Lesson 01**: Parent to Child - *លំហូរទិន្នន័យចុះក្រោមតាមរយៈ Props ក្នុងប្រព័ន្ធ Unidirectional Data Flow។*
- **Lesson 02**: Child to Parent - *ការជូនដំណឹងពីសកម្មភាពឡើងលើទៅកាន់ Parent តាមរយៈ Callback Functions។*
- **Lesson 03**: Passing Functions - *ការប្រើប្រាស់ Event Callbacks ដើម្បីបំបែក UI rendering និង State logic ឱ្យដាច់ពីគ្នា។*
- **Lesson 04**: Lifting State Up - *ការលើក State ទៅកាន់ Ancestor Component រួមដែលនៅជិតបំផុតសម្រាប់ Sibling Components។*
- **Lesson 05**: Sharing State - *ការធ្វើសមកាលកម្មទិន្នន័យរវាង Sibling Components តាមរយៈ Hoisted State។*
- **Lesson 06**: Sibling Communication - *ហេតុផលដែល Sibling Components មិនអាចទំនាក់ទំនងគ្នាដោយផ្ទាល់ និងស្ថាបត្យកម្មដំណោះស្រាយ។*
- **Lesson 07**: Prop Drilling - *ស្វែងយល់អំពីបញ្ហា Prop Drilling និងផលប៉ះពាល់ដល់ការថែទាំកូដក្នុងកម្មវិធីធំៗ។*
- **Lesson 08**: Component Composition as Solution - *ការដោះស្រាយបញ្ហា Prop Drilling យ៉ាងមានប្រសិទ្ធភាពតាមរយៈ `children` prop និង Slotted Elements។*
- **Lesson 09**: Designing Component APIs - *ការរចនា Props ឱ្យមាន ergonomics, intuitive និង type-safe សម្រាប់រយៈពេលវែង។*
