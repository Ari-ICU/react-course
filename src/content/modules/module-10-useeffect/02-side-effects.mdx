# Side Effects

នៅក្នុងវិទ្យាសាស្ត្រកុំព្យូទ័រ **Side Effect** សំដៅលើរាល់ប្រតិបត្តិការណាដែលធ្វើការកែប្រែ ឬជះឥទ្ធិពលទៅលើអ្វីមួយដែលនៅក្រៅ scope នៃ function ដែលកំពុងដំណើរការ (ដូចជាការសរសេរចូល `localStorage`, ការហៅ API request, ការកំណត់ timers, ឬការកែប្រែ DOM ផ្ទាល់)។

### Key Concepts & Rules:

- React Render functions ត្រូវតែជា **Pure Functions** (ទទួល props/state រួច return JSX តែប៉ុណ្ណោះ គ្មាន side effects ឡើយ)។
- Side effects ត្រូវតែស្ថិតនៅក្នុងកន្លែងពីរគត់៖ **Event Handlers** (ឆ្លើយតបនឹងការចុចរបស់ user) ឬ **useEffect** (ដំណើរការពេល render រួច)។
- ការដាក់ side effects ក្នុង render body អាចបណ្តាលឱ្យកើត bugs ធ្ងន់ធ្ងរ និង re-render គ្មានទីបញ្ចប់។

### Code Example: Side Effect Placement

```jsx
import React, { useState, useEffect } from 'react';

export function SideEffectDemo() {
  const [clickCount, setClickCount] = useState(0);

  // ❌ Anti-pattern: Side effects inside render body mutate outside world unpredictably!
  // document.title = `Clicked ${clickCount} times`; // BAD during render

  // ✅ Correct: Side effect cleanly isolated inside useEffect after paint
  useEffect(() => {
    document.title = `Clicked ${clickCount} times`;
    
    // Side effect: Log analytics event
    console.log(`[Analytics] User clicked count: ${clickCount}`);
  }, [clickCount]);

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <h3 className="text-white font-bold">Side Effect Placement</h3>
      <p className="text-slate-300 text-sm">
        Document title updates cleanly in useEffect: <span className="text-blue-400 font-mono">{clickCount}</span>
      </p>
      <button
        onClick={() => setClickCount(prev => prev + 1)}
        className="px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white rounded-lg text-sm font-semibold"
      >
        Increment & Trigger Effect
      </button>
    </div>
  );
}
```
