# Side Effects

A side effect is any operation that affects something outside the scope of the currently executing function (e.g. timers, network requests, reading localStorage, setting window listeners).

### Key Concepts & Rules:

- Pure render functions must not execute side effects directly during render.

```jsx
// Side effects belong in useEffect or event handlers, NOT in render body!
```
