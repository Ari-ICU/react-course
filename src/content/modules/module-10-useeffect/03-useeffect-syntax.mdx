# useEffect Syntax

`useEffect(effectFunction, dependencyArray)`.

### Key Concepts & Rules:

- Dependency array controls when the effect re-runs.

### Code Example: useEffect Anatomy

```jsx
useEffect(() => {
  // Setup logic runs here
  return () => {
    // Optional cleanup logic runs here
  };
}, [/* dependencies */]);
```
