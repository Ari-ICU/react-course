# Dependency Array

Dependency Array គឺជាកត្តាកំណត់ថាតើ `useEffect` របស់អ្នកត្រូវដំណើរការនៅពេលណាខ្លះ។ មានជម្រើស ៣ សំខាន់ៗក្នុងការកំណត់ Dependency Array៖

### Key Concepts & Rules:

1. **គ្មាន Dependency Array** (`useEffect(fn)`)៖ ដំណើរការឡើងវិញបន្ទាប់ពី **រាល់ការ Render ទាំងអស់** (កម្រត្រូវបានប្រើណាស់ ព្រោះអាចប៉ះពាល់ដល់ performance)។
2. **Empty Array `[]`** (`useEffect(fn, [])`)៖ ដំណើរការ **តែម្តងគត់** នៅពេល Component Mount ដំបូង (ស្មើនឹង `componentDidMount`)។
3. **Populated Dependencies** (`useEffect(fn, [count, userId])`)៖ ដំណើរការពេល Mount និង **រាល់ពេលដែលតម្លៃក្នុង array ផ្លាស់ប្តូរ**។

### Code Example: Dependency Array Options

```jsx
import React, { useState, useEffect } from 'react';

export function DependencyMatrixDemo() {
  const [count, setCount] = useState(0);
  const [text, setText] = useState('');

  // 1. No dependency array: Runs after every single render (Warning: high cost!)
  useEffect(() => {
    console.log('[Render Cycle] Component rendered/re-rendered');
  });

  // 2. Empty array []: Runs once on initial mount only
  useEffect(() => {
    console.log('[Mount] Component initialized once');
  }, []);

  // 3. Populated dependencies [count]: Runs on mount + whenever count changes
  useEffect(() => {
    console.log(`[Count Changed] New count is: ${count}`);
  }, [count]); // Ignores changes to 'text'

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <div className="flex items-center gap-3">
        <button
          onClick={() => setCount(c => c + 1)}
          className="px-3 py-1.5 bg-blue-600 hover:bg-blue-700 text-white rounded text-sm"
        >
          Count: {count}
        </button>
        <input
          type="text"
          value={text}
          onChange={(e) => setText(e.target.value)}
          placeholder="Type here (triggers no-array effect)..."
          className="px-3 py-1.5 bg-slate-800 border border-slate-700 rounded text-white text-sm"
        />
      </div>
    </div>
  );
}
```
