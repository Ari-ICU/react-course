# Effects with State

នៅពេលដែលអ្នកដាក់អថេរ State ទៅក្នុង Dependency Array នោះ Effect នឹងដំណើរការឡើងវិញរាល់ពេលដែលតម្លៃនៃ State នោះផ្លាស់ប្តូរ។ វិធីសាស្ត្រនេះស័ក្តិសមបំផុតសម្រាប់ការបង្កើតមុខងារដូចជា Auto-save, LocalStorage Synchronization ឬការវិភាគទិន្នន័យ (Analytics tracking)។

### Key Concepts & Rules:

- Trigger សកម្មភាពខាងក្រៅដោយស្វ័យប្រវត្តិ នៅពេលដែល internal state ប្រែប្រួល។
- ប្រើរួមជាមួយ Cleanup function ដើម្បី clear timers ចាស់ៗ (Debounce pattern)។
- ប្រយ័ត្ន៖ កុំ update state ដដែលនោះនៅខាងក្នុង effect ដោយគ្មានលក្ខខណ្ឌបញ្ឈប់ ព្រោះវានឹងបង្កជា infinite loop!

### Code Example: Auto-save on State Change

```jsx
useEffect(() => {
  if (draftText) {
    const timer = setTimeout(() => saveDraft(draftText), 1000);
    return () => clearTimeout(timer);
  }
}, [draftText]);
```
