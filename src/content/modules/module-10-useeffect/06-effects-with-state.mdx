# Effects with State

Run effects whenever specific state variables transition.

### Key Concepts & Rules:

- Triggers actions like auto-saving drafts when content changes.

### Code Example: Auto-save on State Change

```jsx
useEffect(() => {
  if (draftText) {
    const timer = setTimeout(() => saveDraft(draftText), 1000);
    return () => clearTimeout(timer);
  }
}, [draftText]);
```
