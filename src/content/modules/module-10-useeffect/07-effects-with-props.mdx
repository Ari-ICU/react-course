# Effects with Props

នៅពេលដែល Parent Component បញ្ជូនតម្លៃ Props ថ្មីចុះមក (ឧទាហរណ៍៖ ការផ្លាស់ប្តូរ ID នៃធាតុដែលត្រូវបង្ហាញ) Child Component អាចប្រើ `useEffect` ដោយដាក់ Prop នោះជា dependency ដើម្បីធ្វើសមកាលកម្មទិន្នន័យ ឬទាញយកព័ត៌មានលម្អិតថ្មីពី Server។

### Key Concepts & Rules:

- ប្រើប្រាស់តម្លៃ Prop ជា dependency ដើម្បីឆ្លើយតបទៅនឹងការផ្លាស់ប្តូរពី Parent។
- រៀបចំកូដឱ្យត្រៀមខ្លួនជានិច្ចចំពោះករណីដែល Prop អាចផ្លាស់ប្តូរតម្លៃញឹកញាប់។
- សម្អាតទិន្នន័យចាស់ ឬ cancel requests មុនពេលទាញយកទិន្នន័យសម្រាប់ Prop ថ្មី។

### Code Example: Reacting to Prop Changes

```jsx
import React, { useState, useEffect } from 'react';

interface ModuleDetailProps {
  moduleId: string;
}

export function ModuleDetailViewer({ moduleId }: ModuleDetailProps) {
  const [moduleData, setModuleData] = useState<string | null>(null);
  const [isLoading, setIsLoading] = useState(false);

  useEffect(() => {
    let isCurrent = true;
    setIsLoading(true);

    // Reacting to moduleId prop change: fetch details for the new ID
    const timer = setTimeout(() => {
      if (isCurrent) {
        setModuleData(`Syllabus and lessons for module: ${moduleId}`);
        setIsLoading(false);
      }
    }, 400);

    // Cleanup prevents race conditions when moduleId changes rapidly
    return () => {
      isCurrent = false;
      clearTimeout(timer);
    };
  }, [moduleId]); // Re-runs whenever the parent passes a new moduleId

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-2">
      <h4 className="text-white font-bold">Module ID: {moduleId}</h4>
      <p className="text-slate-300 text-sm">
        {isLoading ? 'Loading content...' : moduleData}
      </p>
    </div>
  );
}
```
