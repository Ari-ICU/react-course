# Effects with Props

Update local state or external subscriptions when prop IDs change.

### Key Concepts & Rules:

- Use prop values as dependencies to react to route parameter changes.

### Code Example: Reacting to Prop Changes

```tsx
useEffect(() => {
  fetchModuleDetails(moduleId);
}, [moduleId]);
```
