# Cleanup Functions

ប្រសិនបើ Effect របស់អ្នកបង្កើត subscription, interval, ឬ DOM event listener អ្នកត្រូវតែ return **Cleanup Function** មួយចេញពី Effect នោះ។ React នឹងដំណើរការ cleanup function នេះមុនពេល effect រត់ម្តងទៀត និងនៅពេលដែល Component ត្រូវបាន unmount ចេញពី DOM។

### Key Concepts & Rules:

- សំខាន់បំផុតក្នុងការការពារ **Memory Leaks** នៅក្នុងកម្មវិធី web។
- ចាំបាច់ត្រូវប្រើសម្រាប់ `clearInterval`, `clearTimeout`, `removeEventListener`, និងការ disconnect WebSocket connections។
- ជួយធានាថាកម្មវិធីដំណើរការបានស្អាតបាត និងមិនស៊ីធនធាន RAM របស់ browser ដោយឥតប្រយោជន៍។

### Code Example: Timer Cleanup Function

```jsx
useEffect(() => {
  const interval = setInterval(() => {
    setSeconds(s => s + 1);
  }, 1000);

  // Cleanup: Clears interval when unmounted
  return () => clearInterval(interval);
}, []);
```
