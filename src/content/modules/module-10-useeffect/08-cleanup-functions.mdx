# Cleanup Functions

Return a cleanup function from your effect. React runs this cleanup function before re-running the effect and when the component unmounts.

### Key Concepts & Rules:

- Crucial for `addEventListener`, `setInterval`, WebSocket connections, and aborting fetch requests.

### Code Example: Timer Cleanup Function

```jsx
useEffect(() => {
  const interval = setInterval(() => {
    setSeconds(s => s + 1);
  }, 1000);

  // Cleanup: Clears interval when unmounted
  return () => clearInterval(interval);
}, []);
```
