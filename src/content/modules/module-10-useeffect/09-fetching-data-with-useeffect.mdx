# Fetching Data with useEffect

When fetching data inside `useEffect`, fast user clicks can create race conditions where an older slow response overwrites a newer fast response. Use `AbortController` to cancel stale requests.

### Key Concepts & Rules:

- Use `AbortController` to abort ongoing HTTP requests on unmount or dependency change.

### Code Example: Safe Data Fetching with AbortController

```jsx
useEffect(() => {
  const controller = new AbortController();
  setIsLoading(true);

  fetch(`/api/topics/${topicId}`, { signal: controller.signal })
    .then(res => res.json())
    .then(data => {
      setTopic(data);
      setIsLoading(false);
    })
    .catch(err => {
      if (err.name !== 'AbortError') setError(err.message);
    });

  return () => controller.abort(); // Cancel if topicId changes!
}, [topicId]);
```
