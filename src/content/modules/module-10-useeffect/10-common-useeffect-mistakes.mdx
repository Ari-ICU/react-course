# Common useEffect Mistakes

ការប្រើប្រាស់ `useEffect` មិនបានត្រឹមត្រូវ គឺជាប្រភពដ៏ធំមួយនៃ bugs នៅក្នុងកម្មវិធី React។ កំហុសដែលកើតឡើងញឹកញាប់បំផុតរួមមានការបង្កើត Infinite Loops, ការបាត់បង់ dependencies, និងអន្ទាក់នៃ Object References។

### Key Concepts & Rules:

- **Infinite Loop Trap**៖ ការហៅ `setState` នៅខាងក្នុង effect ដោយមិនបានកំណត់ dependency array ឱ្យបានត្រឹមត្រូវ ឬដាក់ state នោះក្នុង dependency ខ្លួនឯង។
- **Object/Function Reference Trap**៖ ជៀសវាងការដាក់ objects ឬ functions ដែលមិនទាន់ memoized ទៅក្នុង dependencies។ ចូរប្រើ primitive values (strings, numbers, booleans) ឬប្រើ `useCallback` / `useMemo`។
- គោរពតាម ESLint rule `react-hooks/exhaustive-deps` ជានិច្ច។

### Code Example: Infinite Loop Example

```jsx
import React, { useState, useEffect } from 'react';

export function TimerCorrectionDemo() {
  const [seconds, setSeconds] = useState(0);

  // ❌ 1. PITFALL: Triggers infinite re-render loop!
  // useEffect(() => {
  //   setSeconds(seconds + 1); // Mutates state -> re-renders -> effect runs again!
  // }, [seconds]);

  // ✅ 2. FIX: Use functional update with empty dependency array []
  useEffect(() => {
    const timer = setInterval(() => {
      // Functional updater reads latest state without depending on 'seconds'
      setSeconds(prev => prev + 1);
    }, 1000);

    return () => clearInterval(timer); // Clean up interval on unmount
  }, []); // Safe: Empty array runs interval setup only once!

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-2">
      <h4 className="text-white font-bold">Elapsed Seconds: {seconds}</h4>
      <p className="text-xs text-slate-400">
        Using functional updates eliminates the infinite re-render loop hazard.
      </p>
    </div>
  );
}
```
