# When NOT to use useEffect

នៅក្នុង React សម័យទំនើប ក្រុមការងារស្នូលរបស់ React (React Core Team) បានផ្តល់ការណែនាំយ៉ាងច្បាស់លាស់អំពីករណីដែល **មិនគួរប្រើប្រាស់** `useEffect`៖
1. **កុំប្រើសម្រាប់គណនា Derived Data**៖ គណនាតម្លៃនោះដោយផ្ទាល់នៅពេល render។
2. **កុំប្រើសម្រាប់គ្រប់គ្រង User Events**៖ ចាត់ចែង logic នោះដោយផ្ទាល់នៅខាងក្នុង `onClick` ឬ `onSubmit` handlers។
3. **កុំប្រើសម្រាប់ Reset State ពេល Prop ប្តូរ**៖ ប្រើប្រាស់ `key` prop លើ component ដើម្បី reset វិញ។

### Key Concepts & Rules:

- ការគណនាដោយផ្ទាល់ពេល render ជួយជៀសវាងការ re-render ពីរបីដង (flashes of content)។
- សម្រាប់ការទាញយកទិន្នន័យពី Server ក្នុងកម្មវិធីធំៗ គួរប្រើ libraries ដូចជា **TanStack Query** (React Query) ឬ Next.js Data Fetching ជំនួសការសរសេរ `useEffect` ដោយដៃ។

### Code Example: Avoiding Redundant Effects

```jsx
// ❌ Bad: Redundant effect for derived data
/*
useEffect(() => {
  setFullName(`${firstName} ${lastName}`);
}, [firstName, lastName]);
*/

// ✅ Good: Compute directly during render!
const fullName = `${firstName} ${lastName}`;
```
