# Module 10: useEffect

Side effects, dependency array rules, cleanup functions, data fetching, race conditions, and when NOT to use useEffect.

## Module Syllabus (11 Lessons)

- **Lesson 01**: What is useEffect? - *Hook for synchronizing components with external systems.*
- **Lesson 02**: Side Effects - *What qualifies as a side effect in React.*
- **Lesson 03**: useEffect Syntax - *The effect callback and dependency array parameters.*
- **Lesson 04**: Dependency Array - *No array vs empty array vs populated dependencies.*
- **Lesson 05**: Running Effects - *The execution timeline: render, DOM paint, then effect execution.*
- **Lesson 06**: Effects with State - *Reacting to state transitions.*
- **Lesson 07**: Effects with Props - *Synchronizing when parent attributes update.*
- **Lesson 08**: Cleanup Functions - *Preventing memory leaks, clearing timers, and removing event listeners.*
- **Lesson 09**: Fetching Data with useEffect - *Network requests and race condition handling with AbortController.*
- **Lesson 10**: Common useEffect Mistakes - *Infinite loops, missing dependencies, and object reference traps.*
- **Lesson 11**: When NOT to use useEffect - *Modern React guidelines: avoid effects for derived data and user events.*
