# Module 10: useEffect

ស្វែងយល់ស៊ីជម្រៅអំពី useEffect Hook, Side Effects, ច្បាប់នៃ Dependency Array, Cleanup Functions, ការទាញយកទិន្នន័យ (Data Fetching), Race Conditions ជាមួយ AbortController, កំហុសទូទៅ និងពេលណាដែលមិនគួរប្រើ useEffect។

## Module Syllabus (11 Lessons)

- **Lesson 01**: What is useEffect? - *Hook សម្រាប់ធ្វើសមកាលកម្ម Component ទៅកាន់ External Systems ខាងក្រៅ។*
- **Lesson 02**: Side Effects - *អ្វីទៅដែលត្រូវបានចាត់ទុកជា Side Effect នៅក្នុងកម្មវិធី React។*
- **Lesson 03**: useEffect Syntax - *រចនាសម្ព័ន្ធ Syntax នៃ Effect Callback និងប៉ារ៉ាម៉ែត្រ Dependency Array។*
- **Lesson 04**: Dependency Array - *ការប្រៀបធៀប No Array, Empty Array `[]`, និង Populated Dependencies `[a, b]`។*
- **Lesson 05**: Running Effects - *បន្ទាត់ពេលវេលានៃការដំណើរការ៖ Render, DOM Paint រួចទើប Effect Execution។*
- **Lesson 06**: Effects with State - *ការដំណើរការ Effect ឆ្លើយតបទៅនឹងការប្រែប្រួលនៃ State។*
- **Lesson 07**: Effects with Props - *ការធ្វើសមកាលកម្មទិន្នន័យនៅពេលដែល Props ពី Parent ផ្លាស់ប្តូរ។*
- **Lesson 08**: Cleanup Functions - *ការការពារ Memory Leaks, ការសម្អាត Timers និងការដោះចេញនូវ Event Listeners។*
- **Lesson 09**: Fetching Data with useEffect - *ការហៅ API និងការដោះស្រាយបញ្ហា Race Conditions ដោយប្រើ AbortController។*
- **Lesson 10**: Common useEffect Mistakes - *កំហុសទូទៅដូចជា Infinite Loops, Missing Dependencies និង Object Reference Traps។*
- **Lesson 11**: When NOT to use useEffect - *គោលការណ៍ណែនាំ React ទំនើប៖ ជៀសវាងការប្រើ Effect សម្រាប់ Derived State និង User Events។*
