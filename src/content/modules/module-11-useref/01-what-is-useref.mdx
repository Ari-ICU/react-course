# What is useRef?

Hook `useRef` ផ្តល់ត្រឡប់មកវិញនូវ JavaScript Object ធម្មតាមួយដែលមាន property តែមួយគត់គឺ `{ current: initialValue }`។ ចំណុចពិសេសនៃ `useRef` គឺថារាល់ការកែប្រែតម្លៃលើ `.current` **នឹងមិន trigger ឱ្យមានការ re-render UI ឡើយ**។ វាត្រូវបានប្រើប្រាស់ជាទូទៅបំផុតសម្រាប់ភ្ជាប់ទៅកាន់ DOM Elements ដោយផ្ទាល់ និងរក្សាទុក Timer IDs។

### Key Concepts & Rules:

- រក្សាតម្លៃទុកឆ្លងកាត់ការ re-render ទាំងអស់ដូច State ដែរ ប៉ុន្តែការកែប្រែវាមិនបង្កឱ្យ UI ធ្វើការ re-render នោះទេ។
- ជាឧបករណ៍ចម្បងក្នុងការធ្វើ DOM Manipulation នៅក្នុង React។
- តម្លៃក្នុង `.current` អាចផ្លាស់ប្តូរបានដោយសេរី (Mutable)។

### Code Example: useRef Declaration

```jsx
import React, { useState, useRef } from 'react';

export function RenderTracker() {
  const [inputText, setInputText] = useState('');
  
  // useRef holds mutable value across renders without causing re-renders
  const renderCountRef = useRef(1);
  renderCountRef.current++; // Mutated during render lifecycle for measurement

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <input
        type="text"
        value={inputText}
        onChange={(e) => setInputText(e.target.value)}
        placeholder="Type to trigger re-renders..."
        className="w-full px-3 py-2 bg-slate-800 border border-slate-700 rounded text-white text-sm"
      />
      <div className="text-xs font-mono text-emerald-400">
        Component has rendered: <span className="font-bold">{renderCountRef.current}</span> times
      </div>
    </div>
  );
}
```
