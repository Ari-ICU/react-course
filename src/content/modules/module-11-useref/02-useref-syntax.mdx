# useRef Syntax

នៅពេលប្រើប្រាស់ `useRef` សម្រាប់ភ្ជាប់ទៅកាន់ DOM Element អ្នកគួរតែ initialize តម្លៃដំបូងជា `null`៖ `const inputRef = useRef<HTMLInputElement>(null)`។ នៅពេលដែល component ត្រូវបាន mount ទៅលើអេក្រង់រួចរាល់ React នឹងបញ្ចូល DOM node ជាក់ស្តែងទៅក្នុង `inputRef.current` ដោយស្វ័យប្រវត្តិ។

### Key Concepts & Rules:

- នៅក្នុង TypeScript ត្រូវកំណត់ Type Parameter ឱ្យត្រូវគ្នានឹង HTML element ដូចជា `HTMLInputElement`, `HTMLDivElement`, ឬ `HTMLVideoElement`។
- ភ្ជាប់ ref ទៅកាន់ JSX element តាមរយៈ attribute `ref={inputRef}`។
- នៅពេល unmount React នឹង reset `.current` ឱ្យទៅជា `null` វិញ។

### Code Example: useRef Syntax with TypeScript

```jsx
import React, { useRef } from 'react';

export function AutoFocusSearch() {
  // Explicitly type the ref with HTMLInputElement and initialize with null
  const inputRef = useRef<HTMLInputElement>(null);

  const handleFocus = () => {
    // Safely access current DOM element properties and methods
    inputRef.current?.focus();
  };

  return (
    <div className="p-5 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <div className="flex gap-2">
        <input
          ref={inputRef}
          type="text"
          placeholder="Search course library..."
          className="flex-1 px-3 py-2 bg-slate-800 border border-slate-700 rounded-lg text-white text-sm focus:outline-blue-500"
        />
        <button
          onClick={handleFocus}
          className="px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white rounded-lg text-sm font-semibold"
        >
          Focus Input
        </button>
      </div>
    </div>
  );
}
```
