# useRef Syntax

For DOM refs, initialize with `null`: `const inputRef = useRef<HTMLInputElement>(null)`. React automatically populates `.current` with the DOM node once mounted.

### Key Concepts & Rules:

- Type parameter matches the HTML element: `HTMLInputElement`, `HTMLDivElement`.

### Code Example: useRef Syntax with TypeScript

```jsx
const inputRef = useRef<HTMLInputElement>(null);
return <input ref={inputRef} type="text" />;
```
