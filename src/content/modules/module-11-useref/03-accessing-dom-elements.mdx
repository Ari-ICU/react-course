# Accessing DOM Elements

តាមរយៈ `useRef` អ្នកអាចហៅប្រើប្រាស់ native browser DOM methods ដោយផ្ទាល់បាន ដូចជា `.focus()`, `.scrollIntoView()`, ឬវាស់ទំហំ dimensions នៃ element តាមរយៈ `.getBoundingClientRect()` ដោយមិនចាំបាច់ប្រើ `document.querySelector` ឡើយ។

### Key Concepts & Rules:

- តែងតែពិនិត្យមើលវត្តមានរបស់ DOM node ជាមុន៖ `if (ref.current)` ឬប្រើ `ref.current?.method()`។
- ស័ក្តិសមបំផុតសម្រាប់ auto-scrolling ក្នុង chat windows ឬ container lists។
- ប្រើសម្រាប់តែ imperatively controls ប៉ុណ្ណោះ ជៀសវាងការប្រើ ref ដើម្បីកែប្រែ DOM markup ដោយផ្ទាល់។

### Code Example: DOM Scroll into View via Ref

```jsx
export function ScrollToBottom() {
  const bottomRef = useRef<HTMLDivElement>(null);

  const scrollToBottom = () => {
    bottomRef.current?.scrollIntoView({ behavior: 'smooth' });
  };

  return (
    <div>
      <button onClick={scrollToBottom}>Scroll Down</button>
      <div style={{ height: 1000 }} />
      <div ref={bottomRef} />
    </div>
  );
}
```
