# Focus Input

ករណីប្រើប្រាស់ដ៏ពេញនិយមបំផុតមួយនៃ `useRef` គឺការបញ្ជាឱ្យ cursor ចូលទៅកាន់ Input Field ដោយស្វ័យប្រវត្តិ (Programmatic Focus)។ ឧទាហរណ៍៖ នៅពេលដែល Modal បើកឡើង ឬនៅពេលដែល user ចុចប៊ូតុងស្វែងរក យើងចង់ឱ្យ input ទទួល focus ភ្លាមៗដោយមិនចាំបាច់ឱ្យ user យក mouse ទៅចុច។

### Key Concepts & Rules:

- ហៅ `inputRef.current?.focus()` នៅខាងក្នុង `useEffect` (ពេល mount) ឬនៅខាងក្នុង event handler។
- ជួយលើកកម្ពស់ Accessibility និងល្បឿននៃការបំពេញទិន្នន័យ។
- អាចប្រើ `.select()` ដើម្បី highlight text ទាំងអស់នៅក្នុង input ផងដែរ។

### Code Example: Programmatic Input Focus

```jsx
export function AutoFocusSearch() {
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    inputRef.current?.focus();
  }, []);

  return <input ref={inputRef} placeholder="Search topics..." className="border p-2" />;
}
```
