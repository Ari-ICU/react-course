# useRef vs useState

ការយល់ដឹងអំពីភាពខុសគ្នារវាង `useRef` និង `useState` គឺមានសារៈសំខាន់ខ្លាំងណាស់ក្នុងការរៀបចំ State Architecture៖
- ប្រសិនបើការផ្លាស់ប្តូរតម្លៃទាមទារឱ្យ UI ធ្វើបច្ចុប្បន្នភាពលើអេក្រង់ -> ប្រើ **`useState`**។
- ប្រសិនបើការផ្លាស់ប្តូរតម្លៃគ្រាន់តែជាទិន្នន័យផ្ទៃក្នុងដែលមិនត្រូវការ re-render UI -> ប្រើ **`useRef`**។

### Key Concepts & Rules:

- **useState** -> គ្រប់គ្រង Visual UI Rendering និង Reactivity។
- **useRef** -> គ្រប់គ្រង Internal Data Storage, DOM Element References និង Timers។

### Code Example: useRef vs useState Decision Guide

```jsx
/*
| តម្រូវការ | Hook ដែលត្រូវជ្រើសរើស |
|-----------------------------------|-----------------------|
| ត្រូវការ re-render UI ពេលតម្លៃប្តូរ | useState |
| ចង់ភ្ជាប់ទៅកាន់ DOM Element | useRef |
| រក្សាទុក Timer ID / Socket | useRef |
| តម្លៃ Input ក្នុង Form | useState (controlled) |
*/
```
