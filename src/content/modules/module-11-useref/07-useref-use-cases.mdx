# useRef Use Cases

Used extensively with `<video>`, `<audio>`, HTML5 `<canvas>`, and third-party imperative libraries (e.g. Chart.js, Leaflet).

### Key Concepts & Rules:

- Bridges declarative React with imperative external browser APIs.

### Code Example: Controlling HTML5 Video with useRef

```tsx
export function VideoPlayer({ src }: { src: string }) {
  const videoRef = useRef<HTMLVideoElement>(null);

  return (
    <div>
      <video ref={videoRef} src={src} />
      <button onClick={() => videoRef.current?.play()}>Play</button>
      <button onClick={() => videoRef.current?.pause()}>Pause</button>
    </div>
  );
}
```
