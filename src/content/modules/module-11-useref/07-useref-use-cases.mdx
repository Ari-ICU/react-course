# useRef Use Cases

`useRef` ត្រូវបានប្រើប្រាស់យ៉ាងទូលំទូលាយនៅក្នុងស្ថានភាពជាក់ស្តែងជាច្រើន ជាពិសេសនៅពេលដែលយើងត្រូវធ្វើការជាមួយ HTML5 Media Elements ដូចជា `<video>` និង `<audio>`, HTML5 `<canvas>`, ឬ Third-party Libraries ណាដែលតម្រូវឱ្យគ្រប់គ្រង DOM ដោយផ្ទាល់ (ដូចជា Chart.js, Leaflet, Mapbox)។

### Key Concepts & Rules:

- ដើរតួជាស្ពានតភ្ជាប់រវាង Declarative React និង Imperative Browser APIs។
- ប្រើសម្រាប់បញ្ជា play/pause, volume, ឬ seek ពេលវេលានៅលើ Video player។
- ប្រើដើម្បីទាញយក Canvas 2D/WebGL Context សម្រាប់គូរក្រាហ្វិក។

### Code Example: Controlling HTML5 Video with useRef

```jsx
export function VideoPlayer({ src }: { src: string }) {
  const videoRef = useRef<HTMLVideoElement>(null);

  return (
    <div>
      <video ref={videoRef} src={src} />
      <button onClick={() => videoRef.current?.play()}>Play</button>
      <button onClick={() => videoRef.current?.pause()}>Pause</button>
    </div>
  );
}
```
