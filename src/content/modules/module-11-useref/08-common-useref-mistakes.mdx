# Common useRef Mistakes

កំហុសឆ្គងដ៏ធ្ងន់ធ្ងរបំផុតនៅពេលប្រើប្រាស់ `useRef` គឺការអាន ឬកែប្រែតម្លៃ `ref.current` នៅចំពេលដែល Component កំពុងធ្វើការ Render JSX។ សកម្មភាពនេះបំពានលើច្បាប់ Component Purity របស់ React និងអាចបណ្តាលឱ្យ UI បង្ហាញទិន្នន័យខុសប្រក្រតី។

### Key Concepts & Rules:

- **កុំកែប្រែ Ref ពេល Render**៖ ការសរសេរ `ref.current = 123` ក្នុង component body ធ្វើឱ្យ output នៃ render មិនអាចទស្សន៍ទាយទុកជាមុនបាន (Non-deterministic)។
- ត្រូវអាន ឬកែប្រែ `ref.current` តែនៅខាងក្នុង **Event Handlers** ឬ **`useEffect`** ប៉ុណ្ណោះ។
- ប្រសិនបើអ្នកត្រូវការប្រើប្រាស់តម្លៃនោះសម្រាប់ render JSX ចូរប្រើ `useState` ជំនួសវិញ។

### Code Example: Do Not Mutate Refs During Render

```jsx
// ❌ Impure: Writing to ref during render
/*
function Bad() {
  myRef.current = 123; // Don't do this during render!
  return <div>{myRef.current}</div>;
}
*/
```
