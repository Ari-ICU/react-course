# Module 11: useRef

Persistent mutable values without triggering re-renders, DOM element access, focusing inputs, and measuring DOM nodes.

## Module Syllabus (8 Lessons)

- **Lesson 01**: What is useRef? - *A hook that stores a mutable value that survives across renders without causing re-renders.*
- **Lesson 02**: useRef Syntax - *Declaring refs with TypeScript types for DOM nodes.*
- **Lesson 03**: Accessing DOM Elements - *Interacting directly with native HTML DOM elements.*
- **Lesson 04**: Focus Input - *Programmatically focusing an input when modals open or search triggers.*
- **Lesson 05**: Storing Mutable Values - *Keeping timer IDs and previous state without re-render overhead.*
- **Lesson 06**: useRef vs useState - *When to choose mutable ref vs reactive state.*
- **Lesson 07**: useRef Use Cases - *Media players, measuring widths, canvas drawing, and tracking previous state.*
- **Lesson 08**: Common useRef Mistakes - *Reading or writing ref.current during rendering.*
