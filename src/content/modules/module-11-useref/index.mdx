# Module 11: useRef

ស្វែងយល់ស៊ីជម្រៅអំពី useRef Hook, ការរក្សាទុកតម្លៃ mutable ដោយមិនបង្កឱ្យមានការ re-render, ការចូលទៅកាន់ DOM elements ដោយផ្ទាល់, ការ focus inputs, ការប្រៀបធៀប useRef vs useState និងកំហុសទូទៅ។

## Module Syllabus (8 Lessons)

- **Lesson 01**: What is useRef? - *Hook សម្រាប់ផ្ទុកតម្លៃដែលអាចកែប្រែបាន (Mutable Value) ដោយមិន trigger ឱ្យមានការ re-render UI ឡើយ។*
- **Lesson 02**: useRef Syntax - *រចនាសម្ព័ន្ធ Syntax និងការកំណត់ TypeScript Types សម្រាប់ HTML DOM Nodes។*
- **Lesson 03**: Accessing DOM Elements - *ការភ្ជាប់ និងធ្វើអន្តរកម្មដោយផ្ទាល់ជាមួយ Native HTML DOM Elements។*
- **Lesson 04**: Focus Input - *ការបញ្ជាឱ្យ cursor focus លើ input field ដោយស្វ័យប្រវត្តិតាមរយៈកូដ (Programmatic Focus)។*
- **Lesson 05**: Storing Mutable Values - *ការរក្សាទុក Timer IDs, Interval Handles និង Previous State ដោយគ្មាន overhead នៃ re-rendering។*
- **Lesson 06**: useRef vs useState - *ការណែនាំអំពីពេលវេលាដែលត្រូវជ្រើសរើស Mutable Ref ឬ Reactive State។*
- **Lesson 07**: useRef Use Cases - *ករណីប្រើប្រាស់ជាក់ស្តែងជាមួយ Media Players, Canvas Drawing និង Third-party DOM Libraries។*
- **Lesson 08**: Common useRef Mistakes - *ការជៀសវាងការអាន ឬកែប្រែ `ref.current` អំឡុងពេល Render Phase។*
