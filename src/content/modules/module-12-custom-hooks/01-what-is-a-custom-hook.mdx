# What is a Custom Hook?

A custom hook is a standard JavaScript function whose name starts with `use` and can call other React hooks (`useState`, `useEffect`, `useRef`). Custom hooks allow sharing stateful logic between components without duplicating code.

### Key Concepts & Rules:

- Must begin with `use` (e.g., `useDebounce`, `useLocalStorage`).
- Shares stateful logic, NOT shared state (each caller gets an independent state instance).

### Code Example: Simple useToggle Custom Hook

```jsx
// Basic Custom Hook:
export function useToggle(initialValue = false): [boolean, () => void] {
  const [value, setValue] = useState(initialValue);
  const toggle = () => setValue(v => !v);
  return [value, toggle];
}
```
