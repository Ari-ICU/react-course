# Why Custom Hooks?

Extracting complex effects and state workflows into custom hooks keeps your UI components clean, declarative, and focused solely on layout.

### Key Concepts & Rules:

- Eliminates copy-paste code across pages.
- Decouples business logic from rendering.

### Code Example: Using Custom Hooks in Components

```jsx
// Component remains pure and concise:
export function SettingsView() {
  const [isDarkMode, toggleTheme] = useToggle(true);
  const [isNotificationsEnabled, toggleNotifications] = useToggle(false);

  return (
    <div>
      <button onClick={toggleTheme}>Dark Mode: {isDarkMode ? 'ON' : 'OFF'}</button>
      <button onClick={toggleNotifications}>Alerts: {isNotificationsEnabled ? 'ON' : 'OFF'}</button>
    </div>
  );
}
```
