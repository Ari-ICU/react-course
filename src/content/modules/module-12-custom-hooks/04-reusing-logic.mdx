# Reusing Logic

ចំណុចសំខាន់ដែលត្រូវចងចាំគឺថា ការហៅ Custom Hook មួយនៅក្នុង Components ពីរផ្សេងគ្នា នឹងបង្កើត State Instances ពីរដាច់ដោយឡែកពីគ្នាទាំងស្រុង។ Custom Hooks ជួយយើងក្នុងការចែករំលែករូបមន្តនៃការគណនា និងឥរិយាបថ (Stateful Logic) មិនមែនជាការចែករំលែកទិន្នន័យ State រួមគ្នានោះឡើយ។

### Key Concepts & Rules:

- រាល់ការហៅ Hook ម្តងៗ គឺស្មើនឹងការបង្កើត state និង effects ថ្មីមួយសម្រាប់តែ component នោះ។
- ប្រសិនបើអ្នកចង់ចែករំលែក **ទិន្នន័យ State តែមួយគត់** ឆ្លងកាត់ Components ជាច្រើន ចូរប្រើ **React Context** ឬ **Zustand** ជំនួសវិញ (ដែលនឹងត្រូវសិក្សានៅ Module 16 និង Module 17)។
- ជួយឱ្យ components នីមួយៗរក្សាភាពឯករាជ្យ និងគ្មានផលប៉ះពាល់ដល់គ្នាទៅវិញទៅមក (No Side Coupling)។

### Code Example: Isolated Hook State Instances

```jsx
import React, { useState } from 'react';

// 1. Reusable Custom Hook (Encapsulates logic)
function useToggle(initialValue = false): [boolean, () => void] {
  const [value, setValue] = useState(initialValue);
  const toggle = () => setValue(prev => !prev);
  return [value, toggle];
}

// 2. Component A: Uses hook for dark mode toggle
export function ThemeToggle() {
  const [isDark, toggleDark] = useToggle(false);
  return (
    <button onClick={toggleDark} className="px-3 py-1 bg-slate-800 text-white rounded text-sm">
      Theme: {isDark ? '🌙 Dark' : '☀️ Light'}
    </button>
  );
}

// 3. Component B: Uses the same hook for modal visibility
// Notice: Component B has its OWN independent state that does not affect Component A!
export function PreviewModal() {
  const [isOpen, toggleModal] = useToggle(false);
  return (
    <div>
      <button onClick={toggleModal} className="px-3 py-1 bg-blue-600 text-white rounded text-sm">
        {isOpen ? 'Close Preview' : 'Open Preview'}
      </button>
      {isOpen && <div className="p-3 bg-slate-800 text-slate-300 mt-2 rounded">Modal Content</div>}
    </div>
  );
}
```
