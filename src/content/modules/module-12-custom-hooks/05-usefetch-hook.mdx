# useFetch Hook

`useFetch` គឺជាគំរូ Custom Hook ដ៏ពេញនិយមបំផុតមួយ ដែលធ្វើការប្រមូលផ្តុំ lifecycle ទាំងមូលនៃការហៅ network request រួមមាន៖ ការរក្សាទុកទិន្នន័យ `data`, ស្ថានភាពកំពុងទាញយក `isLoading`, សារប្រាប់កំហុស `error`, និងយន្តការ cleanup ការពារ memory leaks។

### Key Concepts & Rules:

- Return ចេញជា object `{ data, isLoading, error }` ដែលមានភាពងាយស្រួលក្នុងការយកទៅ render លើ UI។
- ប្រើប្រាស់ boolean flag `ignore` ឬ `AbortController` ក្នុង cleanup function ដើម្បីចៀសវាង race conditions។
- គាំទ្រ TypeScript Generics `<T>` ដើម្បីធានាថាទិន្នន័យដែល return មកមាន Type Safety ត្រឹមត្រូវ។

### Code Example: Production useFetch Custom Hook

```jsx
export function useFetch<T>(url: string) {
  const [data, setData] = useState<T | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let ignore = false;
    setIsLoading(true);

    fetch(url)
      .then(res => res.json())
      .then(result => {
        if (!ignore) {
          setData(result);
          setIsLoading(false);
        }
      })
      .catch(err => {
        if (!ignore) {
          setError(err.message);
          setIsLoading(false);
        }
      });

    return () => { ignore = true; };
  }, [url]);

  return { data, isLoading, error };
}
```
