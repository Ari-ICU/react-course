# useDebounce Hook

Prevents making an API request on every keystroke by delaying the updated value until the user pauses typing for specified milliseconds.

### Key Concepts & Rules:

- Essential for search query inputs and resize handlers.

### Code Example: useDebounce Custom Hook

```jsx
export function useDebounce<T>(value: T, delay: number = 300): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => clearTimeout(handler);
  }, [value, delay]);

  return debouncedValue;
}
```
