# useDebounce Hook

`useDebounce` គឺជា Custom Hook ដ៏ចាំបាច់សម្រាប់ search inputs និង filter forms។ វាជួយទប់ស្កាត់ការហៅ API រាល់ពេលចុចអក្សរម្តងៗ (keystroke) ដោយពន្យារពេលរហូតដល់អ្នកប្រើប្រាស់ផ្អាកវាយអក្សរតាមចំនួន milliseconds ដែលបានកំណត់ (ឧទាហរណ៍៖ 300ms ឬ 500ms)។

### Key Concepts & Rules:

- បង្កើត timer តាមរយៈ `setTimeout` និងសម្អាត timer វិញតាមរយៈ `clearTimeout` ក្នុង cleanup function។
- កាត់បន្ថយបន្ទុក Server (Server Load) និងសន្សំសំចៃ Network Bandwidth យ៉ាងច្រើន។
- ផ្តល់នូវបទពិសោធន៍រលូន និងមិនធ្វើឱ្យ UI កន្ត្រាក់អំឡុងពេលវាយបញ្ចូលទិន្នន័យ។

### Code Example: useDebounce Custom Hook

```jsx
export function useDebounce<T>(value: T, delay: number = 300): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => clearTimeout(handler);
  }, [value, delay]);

  return debouncedValue;
}
```
