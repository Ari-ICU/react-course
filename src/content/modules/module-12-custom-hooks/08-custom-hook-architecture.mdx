# Custom Hook Architecture

នៅក្នុងគម្រោងធំៗ អ្នកអាចផ្គុំ Custom Hooks តូចៗបញ្ចូលគ្នាដើម្បីបង្កើតជា Hook កម្រិតខ្ពស់ (Composable Pipeline) ដូចជា `useUser` ហៅប្រើ `useFetch` ហើយ `useFetch` ហៅប្រើ `useLocalStorage` ជាដើម។ ការរៀបចំ Folder ឱ្យមានរបៀបរៀបរយគឺមានសារៈសំខាន់ខ្លាំងណាស់សម្រាប់ភាពងាយស្រួលក្នុងការស្វែងរក និងថែទាំ។

### Key Concepts & Rules:

- **Global Hooks** (`src/hooks/`)៖ សម្រាប់ hooks ទូទៅដែលប្រើឆ្លងកាត់ project ទាំងមូល (ដូចជា `useDebounce`, `useLocalStorage`)។
- **Feature Hooks** (`src/features/*/hooks/`)៖ សម្រាប់ hooks ដែលទាក់ទងនឹង business domain ជាក់លាក់។
- លើកកម្ពស់គោលការណ៍ Single Responsibility Principle លើ hook នីមួយៗ។

### Code Example: Hooks Folder Architecture

```jsx
src/
├── hooks/
│   ├── useLocalStorage.ts
│   ├── useDebounce.ts
│   └── useMediaQuery.ts
└── features/students/hooks/
    └── useStudentFilters.ts
```
