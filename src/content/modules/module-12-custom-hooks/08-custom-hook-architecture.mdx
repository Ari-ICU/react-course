# Custom Hook Architecture

Compose custom hooks from smaller custom hooks (e.g. `useUser` uses `useFetch` which uses `useLocalStorage`).

### Key Concepts & Rules:

- Colocate domain hooks in feature folders; put generic hooks in `@/hooks`.

### Code Example: Hooks Folder Architecture

```jsx
src/
├── hooks/
│   ├── useLocalStorage.ts
│   ├── useDebounce.ts
│   └── useMediaQuery.ts
└── features/students/hooks/
    └── useStudentFilters.ts
```
