# Custom Hook Best Practices

Use `as const` on tuple returns or explicit TypeScript return types so consumers get accurate tuple types rather than union arrays.

### Key Concepts & Rules:

- Add `as const` to tuple returns for instant type inference.

### Code Example: Tuple Return with as const

```jsx
// Using "as const" for tuple inference:
export function useCounter(initial = 0) {
  const [count, setCount] = useState(initial);
  const increment = () => setCount(c => c + 1);
  return [count, increment] as const;
}
```
