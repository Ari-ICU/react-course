# Module 12: Custom Hooks

ស្វែងយល់ស៊ីជម្រៅអំពីការបង្កើត Reusable Custom Hooks, ការទាញយក Business Logic ចេញពី UI, ការកសាង useFetch, useLocalStorage, useDebounce, ស្ថាបត្យកម្ម Hooks និងគោលការណ៍ Best Practices ក្នុង TypeScript។

## Module Syllabus (9 Lessons)

- **Lesson 01**: What is a Custom Hook? - *JavaScript Functions ដែលចាប់ផ្តើមដោយពាក្យ 'use' និងប្រមូលផ្តុំ React Hooks ផ្សេងៗបញ្ចូលគ្នា។*
- **Lesson 02**: Why Custom Hooks? - *អត្ថប្រយោជន៍នៃការ reuse កូដ, ការធ្វើឱ្យ UI component ស្រឡះស្អាត និងភាពងាយស្រួលក្នុងការធ្វើ Unit Test។*
- **Lesson 03**: Creating Custom Hooks - *ច្បាប់នៃការបង្កើត Hook, ក្បួនដាក់ឈ្មោះ និងទម្រង់នៃការ return តម្លៃ (Tuples vs Objects)។*
- **Lesson 04**: Reusing Logic - *ការចែករំលែកឥរិយាបថ (Behavior) ដោយរក្សា State Instance ដាច់ដោយឡែកពីគ្នា។*
- **Lesson 05**: useFetch Hook - *ការបង្កើត Custom Hook សម្រាប់គ្រប់គ្រង HTTP Requests, Loading State និង Error Handling។*
- **Lesson 06**: useLocalStorage Hook - *ការរក្សាទុក State ទៅក្នុង Browser LocalStorage ដោយស្វ័យប្រវត្តិតាមរយៈ JSON serialization។*
- **Lesson 07**: useDebounce Hook - *ការពន្យារពេល State updates សម្រាប់ការស្វែងរក (Search Inputs) ដើម្បីកាត់បន្ថយ API calls។*
- **Lesson 08**: Custom Hook Architecture - *ការរៀបចំ Directory រចនាសម្ព័ន្ធ Folder និងការផ្គុំ Composable Hook Pipelines។*
- **Lesson 09**: Custom Hook Best Practices - *ការប្រើប្រាស់ `as const` សម្រាប់ Type Inference ត្រឹមត្រូវ និងការរក្សា Stable Callbacks ជាមួយ useCallback។*
