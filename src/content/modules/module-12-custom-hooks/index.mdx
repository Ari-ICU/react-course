# Module 12: Custom Hooks

Creating reusable hooks, extracting logic, useFetch, useLocalStorage, useDebounce, and hook architecture.

## Module Syllabus (9 Lessons)

- **Lesson 01**: What is a Custom Hook? - *JavaScript functions starting with 'use' that encapsulate other hooks.*
- **Lesson 02**: Why Custom Hooks? - *Code reuse, component decluttering, and testable domain logic.*
- **Lesson 03**: Creating Custom Hooks - *Rules, naming conventions, and returning values.*
- **Lesson 04**: Reusing Logic - *Sharing behavior without duplicating state instances.*
- **Lesson 05**: useFetch Hook - *Extracting HTTP requests, loading states, and error handling.*
- **Lesson 06**: useLocalStorage Hook - *Persisting state to browser storage with automatic JSON serialization.*
- **Lesson 07**: useDebounce Hook - *Delaying rapid state updates for search inputs.*
- **Lesson 08**: Custom Hook Architecture - *Organizing hooks directory and composable hook pipelines.*
- **Lesson 09**: Custom Hook Best Practices - *Ensuring stable callbacks with useCallback and accurate TypeScript return types.*
