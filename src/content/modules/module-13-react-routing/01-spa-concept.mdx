# SPA Concept

In an SPA, the browser downloads a single HTML file and JavaScript bundle. When the user navigates to a new URL, client-side JavaScript intercepts the navigation and updates the DOM dynamically without requesting a new HTML page from the server.

### Key Concepts & Rules:

- Instant navigation transitions without white screen flashes.
- State persists in memory across route changes.

### Code Example: SPA Mental Model

```tsx
// Traditional Multi-Page App: Server returns full HTML page per URL.
// Single Page App (SPA): Client-side JavaScript swaps view components on URL change.
```
