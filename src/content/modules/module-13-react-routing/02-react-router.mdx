# React Router

React Router synchronizes the UI with the URL in the browser address bar. It provides components and hooks to match URL paths and render corresponding views.

### Key Concepts & Rules:

- Version 6+ uses nested routes, data loaders, and elements.

### Code Example: Installing React Router

```jsx
npm install react-router-dom
```
