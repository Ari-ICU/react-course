# React Router

**React Router** គឺជាបណ្ណាល័យស្តង់ដារដ៏ពេញនិយមបំផុតសម្រាប់គ្រប់គ្រង Routing នៅក្នុងកម្មវិធី React SPA។ វាធ្វើការផ្គូផ្គង UI Components ទៅនឹង URL ជាក់លាក់នៅលើ Browser Address Bar និងផ្តល់នូវ Components និង Hooks ជាច្រើនដើម្បីរៀបចំរចនាសម្ព័ន្ធទំព័រ។

### Key Concepts & Rules:

- ធ្វើសមកាលកម្ម UI ជាមួយនឹង Browser URL តាមទម្រង់ Declarative។
- ចាប់ពី Version 6 ឡើងទៅ React Router គាំទ្រ Nested Routes, Data Loaders, Action Handlers និង Layout Outlets យ៉ាងរលូន។
- ប្រើ package `react-router-dom` សម្រាប់ web applications។

### Code Example: Installing React Router

```bash
npm install react-router-dom
```
