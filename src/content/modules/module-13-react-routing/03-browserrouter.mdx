# BrowserRouter

`<BrowserRouter>` គឺជា Router Provider ស្នូលដែលត្រូវរុំព័ទ្ធពីលើកម្មវិធី React ទាំងមូល។ វាប្រើប្រាស់ **HTML5 History API** (ដូចជា `pushState`, `replaceState` និង `popstate` event) ដើម្បីរក្សា UI របស់អ្នកឱ្យស៊ីសង្វាក់គ្នាជាមួយនឹង URL នៅក្នុង address bar។

### Key Concepts & Rules:

- ដាក់ `<BrowserRouter>` នៅចំណុចកំពូលបង្អស់ (Root Level) នៃ React App។
- ផ្តល់នូវ Routing Context ដល់ Child Components ទាំងអស់ ដើម្បីឱ្យពួកវាអាចប្រើ `<Link>`, `useNavigate()`, ឬ `useParams()` បាន។
- នៅលើ production server អ្នកត្រូវ configure fallback rewrite ទៅកាន់ `index.html` សម្រាប់ client-side routes ទាំងអស់។

### Code Example: BrowserRouter Provider

```jsx
import { BrowserRouter } from 'react-router-dom';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);
```
