# BrowserRouter

`<BrowserRouter>` uses the HTML5 history API (`pushState`, `replaceState`, and `popstate` event) to keep your UI in sync with the URL.

### Key Concepts & Rules:

- Place `<BrowserRouter>` at the root of your application.

### Code Example: BrowserRouter Provider

```tsx
import { BrowserRouter } from 'react-router-dom';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);
```
