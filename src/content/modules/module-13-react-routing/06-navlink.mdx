# NavLink

A special version of `<Link>` that knows whether it is currently active. It passes an `isActive` boolean to its `className` function for easy active styling.

### Key Concepts & Rules:

- Makes active tab highlights declarative.

### Code Example: Active Styling with NavLink

```tsx
import { NavLink } from 'react-router-dom';

<NavLink
  to="/curriculum"
  className={({ isActive }) =>
    cn(
      "px-3 py-2 rounded-md text-sm font-medium",
      isActive ? "bg-slate-800 text-white" : "text-slate-400 hover:text-white"
    )
  }
>
  Curriculum
</NavLink>
```
