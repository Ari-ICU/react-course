# NavLink

`<NavLink>` គឺជាទម្រង់ពិសេសមួយនៃ `<Link>` ដែលមានសមត្ថភាពដឹងថាតើ URL បច្ចុប្បន្នកំពុងត្រូវគ្នានឹងតំណភ្ជាប់របស់វា (Active State) ឬអត់។ វាបញ្ជូន boolean parameter `{ isActive }` ទៅក្នុង `className` ឬ `style` callback function ដែលជួយឱ្យការរចនា navigation bar, tabs, ឬ sidebar menu មានភាពងាយស្រួលបំផុត។

### Key Concepts & Rules:

- ប្រើសម្រាប់ Navigation Bars, Sidebars, និង Tab Menus។
- `className={({ isActive }) => isActive ? 'active-class' : 'inactive-class'}`។
- គាំទ្រ accessibility (a11y) ដោយបន្ថែម `aria-current="page"` លើ active link ដោយស្វ័យប្រវត្តិ។

### Code Example: Active Styling with NavLink

```jsx
import { NavLink } from 'react-router-dom';

<NavLink
  to="/curriculum"
  className={({ isActive }) =>
    cn(
      "px-3 py-2 rounded-md text-sm font-medium",
      isActive ? "bg-slate-800 text-white" : "text-slate-400 hover:text-white"
    )
  }
>
  Curriculum
</NavLink>
```
