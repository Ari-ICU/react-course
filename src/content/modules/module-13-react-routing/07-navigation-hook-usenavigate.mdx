# Navigation Hook (useNavigate)

Hook `useNavigate` ផ្តល់ត្រឡប់មកវិញនូវ navigation function ដែលអនុញ្ញាតឱ្យអ្នកបញ្ជាប្តូរទំព័រតាមរយៈកូដ JavaScript (Programmatic Navigation) ដូចជាការ redirect ទៅកាន់ Dashboard បន្ទាប់ពី submit form ជោគជ័យ ឬការ redirect ទៅ Login បន្ទាប់ពី user ចុច Logout។

### Key Concepts & Rules:

- ប្រើ `navigate('/path')` ដើម្បីទៅកាន់ទំព័រថ្មី។
- ប្រើ `navigate(-1)` ដើម្បីត្រឡប់ក្រោយ (Go Back) ឬ `navigate(1)` ដើម្បីទៅមុខ (Go Forward) ដូច browser buttons។
- ជម្រើស `{ replace: true }` នឹងជំនួស URL ចាស់ក្នុង history stack (ការពារ back-button loop)។

### Code Example: Programmatic Navigation with useNavigate

```jsx
import { useNavigate } from 'react-router-dom';

export function LoginForm() {
  const navigate = useNavigate();

  const handleLoginSuccess = () => {
    // Redirect to dashboard without back-button loop:
    navigate('/dashboard', { replace: true });
  };
}
```
