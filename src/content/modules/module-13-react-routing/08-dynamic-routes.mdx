# Dynamic Routes

Dynamic Routes អនុញ្ញាតឱ្យអ្នកកំណត់ pattern នៃ URL ដែលមានតម្លៃប្រែប្រួល dynamic ដោយប្រើសញ្ញាពីរចុច (`:`) នៅពីមុខឈ្មោះ parameter ដូចជា `/modules/:moduleId` ឬ `/products/:id`។ វិធីសាស្ត្រនេះជួយឱ្យ Component តែមួយអាចទទួលរ៉ាប់រងការបង្ហាញទំព័រលម្អិតនៃទិន្នន័យរាប់ពាន់ records បានយ៉ាងរលូន។

### Key Concepts & Rules:

- កំណត់ Dynamic segment ដោយប្រើបុព្វបទ `:` ដូចជា `:moduleId`។
- អនុញ្ញាតឱ្យ component តែមួយដើរតួជា template សម្រាប់ URLs រាប់ពាន់ផ្សេងគ្នា។
- តម្លៃជាក់ស្តែងនៃ parameter នឹងត្រូវទាញយកតាមរយៈ `useParams()` hook។

### Code Example: Dynamic Route Parameter Definition

```jsx
import React from 'react';
import { Routes, Route, useParams, Link } from 'react-router-dom';

// 1. Component reading the dynamic parameter from URL
function ModuleDetailView() {
  // useParams extracts ":moduleId" from current URL path
  const { moduleId } = useParams<{ moduleId: string }>();

  return (
    <div className="p-6 bg-slate-900 border border-slate-800 rounded-xl space-y-3">
      <h2 className="text-xl font-bold text-white">Viewing Module: {moduleId}</h2>
      <p className="text-sm text-slate-400">Extracting params enables dynamic lesson loading.</p>
      <Link to="/modules" className="text-blue-400 text-sm hover:underline">
        ← Back to All Modules
      </Link>
    </div>
  );
}

// 2. Route Configuration using colon ":" for parameter placeholder
export function ModuleAppRoutes() {
  return (
    <Routes>
      <Route path="/modules/:moduleId" element={<ModuleDetailView />} />
    </Routes>
  );
}
```
