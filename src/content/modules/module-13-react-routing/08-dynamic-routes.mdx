# Dynamic Routes

Define dynamic paths with a colon prefix: `/modules/:moduleId/topics/:topicId`.

### Key Concepts & Rules:

- Allows single component to handle thousands of dynamic URLs.

### Code Example: Dynamic Route Parameter Definition

```tsx
<Route path="/modules/:moduleId" element={<ModuleDetailView />} />
```
