# Layout Routes

ប្រសិនបើអ្នកចង់រុំព័ទ្ធ Routes មួយក្រុមនៅក្នុង Layout តែមួយ ដោយមិនចង់បន្ថែម prefix ទៅក្នុង URL ឡើយ អ្នកអាចលុប attribute `path` ចេញពី parent `<Route>` បាន។ បច្ចេកទេសនេះហៅថា **Pathless Layout Routes**។

### Key Concepts & Rules:

- Parent Route គ្រាន់តែកំណត់ `element={<Layout />}` ដោយគ្មាន `path` attribute។
- អនុញ្ញាតឱ្យ routes ដូចជា `/login` និង `/register` ចែករំលែក `AuthLayout` ជាមួយគ្នាដោយមិនចាំបាច់ក្លាយជា `/auth/login` ឡើយ។
- ជួយឱ្យ URL Structure មានភាពខ្លី និងស្រស់ស្អាត។

### Code Example: Pathless Layout Route

```jsx
<Route element={<AuthLayout />}>
  <Route path="/login" element={<LoginPage />} />
  <Route path="/register" element={<RegisterPage />} />
</Route>
```
