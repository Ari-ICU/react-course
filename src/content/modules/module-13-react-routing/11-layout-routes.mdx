# Layout Routes

Omit the `path` prop on the parent Route to wrap routes in a layout without modifying the URL path.

### Key Concepts & Rules:

- Pathless layout routes cleanly group public vs authenticated layouts.

### Code Example: Pathless Layout Route

```tsx
<Route element={<AuthLayout />}>
  <Route path="/login" element={<LoginPage />} />
  <Route path="/register" element={<RegisterPage />} />
</Route>
```
