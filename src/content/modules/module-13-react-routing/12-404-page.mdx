# 404 Page

ដើម្បីគ្រប់គ្រងករណីដែលអ្នកប្រើប្រាស់វាយ URL ខុស ឬចូលទៅកាន់តំណភ្ជាប់ដែលមិនមាននៅក្នុងកម្មវិធី អ្នកត្រូវតែបង្កើត Catch-all Route ដោយប្រើសញ្ញាផ្កាយ (`path="*"`) នៅខាងចុងបង្អស់នៃ `<Routes>` list។

### Key Concepts & Rules:

- `path="*"` នឹងចាប់យកគ្រប់ URL ណាដែលមិនត្រូវគ្នានឹង routes ខាងលើទាំងអស់។
- តែងតែផ្តល់នូវការរចនាទំព័រ 404 ប្រកបដោយភាពរួសរាយ រួមជាមួយនឹងប៊ូតុងត្រឡប់ទៅកាន់ទំព័រដើមវិញ (Home Link)។
- ជៀសវាងការទុកឱ្យទំព័រទទេស្អាតពេល user វាយ URL ខុស។

### Code Example: Catch-all 404 Route

```jsx
import React from 'react';
import { Routes, Route, Link } from 'react-router-dom';

// 1. Engaging 404 Fallback Component
function NotFoundView() {
  return (
    <div className="text-center py-16 space-y-4">
      <h1 className="text-6xl font-black text-rose-500">404</h1>
      <h2 className="text-2xl font-bold text-white">Lesson or Page Not Found</h2>
      <p className="text-slate-400 max-w-md mx-auto">
        The route you navigated to does not exist in this course.
      </p>
      <Link
        to="/"
        className="inline-block px-5 py-2.5 bg-blue-600 hover:bg-blue-700 text-white rounded-xl font-semibold text-sm transition-colors"
      >
        Return to Home
      </Link>
    </div>
  );
}

// 2. Wildcard Route placed at the very end of <Routes>
export function AppRouter() {
  return (
    <Routes>
      <Route path="/" element={<h2>Home Page</h2>} />
      {/* Catch-all matching any undefined path */}
      <Route path="*" element={<NotFoundView />} />
    </Routes>
  );
}
```
