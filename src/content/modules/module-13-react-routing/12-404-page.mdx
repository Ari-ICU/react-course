# 404 Page

Use `<Route path="*" element={<NotFoundPage />} />` at the very end of your route list to catch any unmatched URLs.

### Key Concepts & Rules:

- Always provide a helpful 404 page with a link back to home.

### Code Example: Catch-all 404 Route

```tsx
<Route path="*" element={<NotFoundView />} />
```
