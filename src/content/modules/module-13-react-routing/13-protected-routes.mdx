# Protected Routes

Protected Route (ឬ Route Guard) គឺជា Component Wrapper ដែលធ្វើការត្រួតពិនិត្យ Authentication State របស់អ្នកប្រើប្រាស់៖ ប្រសិនបើ user បាន Login រួចរាល់ វានឹងអនុញ្ញាតឱ្យ render `<Outlet />`; ប្រសិនបើមិនទាន់ Login ទេ វានឹង redirect ទៅកាន់ទំព័រ `/login` ភ្លាមៗ។

### Key Concepts & Rules:

- ប្រើប្រាស់ component `<Navigate to="/login" replace />` សម្រាប់ការ redirect ដោយស្វ័យប្រវត្តិ។
- ភ្ជាប់ `state={{ from: location }}` ដើម្បីចងចាំទំព័រដើមដែល user បានព្យាយាមចូល។
- អាចអនុវត្តបន្ថែមសម្រាប់ Role-based Authorization (ដូចជា Admin-only routes)។

### Code Example: Protected Route Gate

```jsx
import { Navigate, Outlet, useLocation } from 'react-router-dom';

export function ProtectedRoute({ isAuthenticated }: { isAuthenticated: boolean }) {
  const location = useLocation();

  if (!isAuthenticated) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  return <Outlet />;
}
```
