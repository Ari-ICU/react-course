# Query Parameters (useSearchParams)

`useSearchParams` behaves like `useState`, but stores state directly in the URL query string, making URLs shareable and bookmarkable.

### Key Concepts & Rules:

- Synchronizes table filters with browser history.

### Code Example: Query Strings with useSearchParams

```tsx
import { useSearchParams } from 'react-router-dom';

export function SearchFilter() {
  const [searchParams, setSearchParams] = useSearchParams();
  const query = searchParams.get('q') || '';

  const handleSearch = (newQuery: string) => {
    setSearchParams({ q: newQuery });
  };

  return <input value={query} onChange={(e) => handleSearch(e.target.value)} />;
}
```
