# Route Architecture

Store all route path strings in a central `ROUTES` constant (`ROUTES.PROJECTS`, `ROUTES.CURRICULUM`) to prevent broken link typos across large codebases.

### Key Concepts & Rules:

- Centralized route configuration improves refactoring speed.

### Code Example: Centralized Route Constants

```jsx
export const ROUTES = {
  HOME: '/',
  CURRICULUM: '/curriculum',
  PROJECTS: '/projects',
  PROJECT_DETAIL: (id: string) => `/projects/${id}`,
} as const;
```
