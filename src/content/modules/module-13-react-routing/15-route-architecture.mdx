# Route Architecture

នៅក្នុងកម្មវិធីខ្នាតធំ ការសរសេរ Path string ដោយផ្ទាល់ (Hardcoding strings) នៅតាម components នានា អាចនាំឱ្យកើតមាន Broken Links ដោយសារតែការវាយអក្សរខុស ឬការពិបាកពេលផ្លាស់ប្តូរ URL structure។ ការប្រមូលផ្តុំ Paths ទាំងអស់ឱ្យស្ថិតនៅក្នុង object constant `ROUTES` តែមួយ គឺជា Best Practice ដ៏សំខាន់។

### Key Concepts & Rules:

- បង្កើត `ROUTES` constant object ដោយបន្ថែម `as const`។
- គាំទ្រ dynamic route helpers ដូចជា `ROUTES.PROJECT_DETAIL(id)`។
- ជួយឱ្យការ refactor ផ្លាស់ប្តូរ URL paths អាចធ្វើឡើងនៅកន្លែងតែមួយដោយសុវត្ថិភាព។

### Code Example: Centralized Route Constants

```jsx
export const ROUTES = {
  HOME: '/',
  CURRICULUM: '/curriculum',
  PROJECTS: '/projects',
  PROJECT_DETAIL: (id: string) => `/projects/${id}`,
} as const;
```
