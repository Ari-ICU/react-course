# React Router Best Practices

Lazy-load route pages so users only download the JavaScript for the specific page they are currently viewing.

### Key Concepts & Rules:

- Wrap lazy routes in `<Suspense fallback={<LoadingSkeleton />}>`.

### Code Example: Lazy-loaded Route with Suspense

```tsx
import React, { Suspense } from 'react';

const ProjectsPage = React.lazy(() => import('./pages/ProjectsPage'));

<Route 
  path="/projects" 
  element={
    <Suspense fallback={<PageSkeleton />}>
      <ProjectsPage />
    </Suspense>
  } 
/>
```
