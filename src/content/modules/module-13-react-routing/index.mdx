# Module 13: React Routing

ស្វែងយល់ស៊ីជម្រៅអំពីស្ថាបត្យកម្ម Single Page Application (SPA), React Router v6+, BrowserRouter, Routes, Route, Link, NavLink, Dynamic Routes, Nested Layouts, Protected Routes, useSearchParams និង Code-splitting។

## Module Syllabus (16 Lessons)

- **Lesson 01**: SPA Concept - *របៀបដែល Single Page Applications បង្ហាញអេក្រង់ច្រើនដោយមិនបាច់ reload ទំព័រ browser។*
- **Lesson 02**: React Router - *បណ្ណាល័យស្តង់ដារសម្រាប់គ្រប់គ្រង declarative client-side routing ក្នុង React SPAs។*
- **Lesson 03**: BrowserRouter - *ការ wrap កម្មវិធីដើម្បីភ្ជាប់ជាមួយ HTML5 Browser History API។*
- **Lesson 04**: Routes and Route - *ការកំណត់លក្ខខណ្ឌផ្គូផ្គង URL Path និង Target Components ដែលត្រូវ render។*
- **Lesson 05**: Link - *ការធ្វើដំណើរឆ្លងកាត់ទំព័រ (Client-side Navigation) ដោយគ្មាន page refresh។*
- **Lesson 06**: NavLink - *ការកំណត់ Style លើ Active Navigation Links សម្រាប់ headers និង sidebars។*
- **Lesson 07**: Navigation Hook (useNavigate) - *ការបញ្ជា redirect ទំព័រតាមរយៈកូដ (Programmatic Navigation) ក្នុង handlers ឬ effects។*
- **Lesson 08**: Dynamic Routes - *ការចាប់យក dynamic URL paths ដោយប្រើ parameters ដូចជា `:id` ឬ `:moduleId`។*
- **Lesson 09**: Route Parameters (useParams) - *ការទាញយក dynamic parameters ចេញពី URL path តាមរយៈ `useParams` hook។*
- **Lesson 10**: Nested Routes - *ការរៀបចំ sub-routes ដែលចែករំលែក layout រួមគ្នាដោយប្រើប្រាស់ `<Outlet />`។*
- **Lesson 11**: Layout Routes - *ការប្រមូលផ្តុំ routes ក្រោម layout រួមដោយមិនចាំបាច់បន្ថែម URL path prefix (Pathless Routes)។*
- **Lesson 12**: 404 Page - *ការបង្កើត Catch-all Wildcard Route (`*`) សម្រាប់បង្ហាញទំព័រ Not Found។*
- **Lesson 13**: Protected Routes - *ការការពារទំព័រឯកជនសម្រាប់តែ Authenticated Users និងការ redirect ភ្ញៀវទៅកាន់ login។*
- **Lesson 14**: Query Parameters (useSearchParams) - *ការអាន និងកែប្រែ URL query strings ដូចជា `?sort=desc&page=2`។*
- **Lesson 15**: Route Architecture - *ការប្រមូលផ្តុំ Route Definitions និង Route Path Constants ឱ្យមានរបៀបរៀបរយ។*
- **Lesson 16**: React Router Best Practices - *ការធ្វើ Code-splitting លើ Routes ដោយប្រើប្រាស់ `React.lazy` និង `Suspense`។*
