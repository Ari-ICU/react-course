# Module 13: React Routing

Single Page Application architecture, React Router v6+, Routes, Route, Link, NavLink, dynamic routes, nested layouts, and protected routes.

## Module Syllabus (16 Lessons)

- **Lesson 01**: SPA Concept - *How Single Page Applications render multiple screens without browser refreshes.*
- **Lesson 02**: React Router - *The standard declarative routing library for React SPAs.*
- **Lesson 03**: BrowserRouter - *Wrapping your app to connect with the browser History API.*
- **Lesson 04**: Routes and Route - *Defining URL matching rules and target components.*
- **Lesson 05**: Link - *Client-side navigation without page refresh.*
- **Lesson 06**: NavLink - *Active link styling for navigation bars and menus.*
- **Lesson 07**: Navigation Hook (useNavigate) - *Programmatic redirects inside handlers or effects.*
- **Lesson 08**: Dynamic Routes - *Capturing variable URL paths using parameters like :id.*
- **Lesson 09**: Route Parameters (useParams) - *Extracting dynamic parameters from URL path.*
- **Lesson 10**: Nested Routes - *Sub-routes sharing layout frames using <Outlet />.*
- **Lesson 11**: Layout Routes - *Grouping routes under shared layouts without adding URL path prefixes.*
- **Lesson 12**: 404 Page - *Catch-all wildcard routes (*).*
- **Lesson 13**: Protected Routes - *Restricting access to authenticated users and redirecting guests.*
- **Lesson 14**: Query Parameters (useSearchParams) - *Reading and updating URL search queries like ?sort=desc&page=2.*
- **Lesson 15**: Route Architecture - *Centralizing route definitions, route constants, and loaders.*
- **Lesson 16**: React Router Best Practices - *Code-splitting routes with React.lazy and Suspense.*
