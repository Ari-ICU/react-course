# React + REST API

React applications communicate with backend servers over HTTP using JSON payloads. The frontend is decoupled from the backend technology (Node, Python, Go, PHP Laravel).

### Key Concepts & Rules:

- Stateless communication via JSON.
- Frontend only consumes API contracts.
