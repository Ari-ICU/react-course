# Fetching API Data

Modern browsers have native `fetch()`, but Axios or TanStack Query simplify error handling, request cancellation, and response body JSON parsing.

### Key Concepts & Rules:

- Native fetch does not reject promises on HTTP 404/500 status codes!

### Code Example: Native fetch() Error Checking

```jsx
// Native fetch requires manual ok check:
const response = await fetch('/api/products');
if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
const data = await response.json();
```
