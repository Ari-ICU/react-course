# GET Request

Used to fetch data without side effects on the server.

### Key Concepts & Rules:

- Idempotent and safe HTTP method.

### Code Example: Axios GET Request

```tsx
const fetchStudents = async () => {
  const res = await axios.get('/api/students');
  return res.data;
};
```
