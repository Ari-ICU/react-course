# POST Request

Used for submitting forms, creating tasks, or authenticating users.

### Key Concepts & Rules:

- Transmits data in request body.

### Code Example: Axios POST Request

```tsx
const createStudent = async (newStudent: StudentInput) => {
  const res = await axios.post('/api/students', newStudent);
  return res.data;
};
```
