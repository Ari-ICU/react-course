# PUT Request

Replaces the entire entity at `/api/resources/:id`.

### Key Concepts & Rules:

- Idempotent update replacing all fields.

### Code Example: Axios PUT Request

```jsx
await axios.put(`/api/students/${id}`, fullStudentObject);
```
