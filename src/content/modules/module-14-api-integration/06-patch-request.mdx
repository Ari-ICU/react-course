# PATCH Request

Updates only the fields sent in the request body (e.g. toggle task status).

### Key Concepts & Rules:

- Saves bandwidth by sending only changed properties.

### Code Example: Axios PATCH Request

```tsx
await axios.patch(`/api/todos/${id}`, { completed: true });
```
