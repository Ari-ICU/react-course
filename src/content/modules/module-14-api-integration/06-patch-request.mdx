# PATCH Request

ខុសប្លែកពី `PUT`, HTTP PATCH ត្រូវបានប្រើប្រាស់សម្រាប់ធ្វើបច្ចុប្បន្នភាពតែវាលទិន្នន័យជាក់លាក់ណាមួយ (Partial Update) ដោយមិនប៉ះពាល់ដល់ Field ផ្សេងទៀតដែលមិនបានបញ្ជាក់នៅក្នុង Request Body ឡើយ។

### Key Concepts & Rules:

- សន្សំសំចៃ Bandwidth បណ្តាញ ដោយផ្ញើទៅតែ Fields ដែលមានការផ្លាស់ប្តូរ។
- ស័ក្តិសមបំផុតសម្រាប់ Inline Editing, Switch toggles, ឬ Quick status updates។
- មិនតម្រូវឱ្យបញ្ជូន Object ពេញលេញនោះឡើយ។

### Code Example: Axios PATCH Request

```jsx
import axios from 'axios';

const toggleTodoStatus = async (id: string, isCompleted: boolean) => {
  // ផ្ញើតែ field 'completed' ទៅកាន់ Server ប៉ុណ្ណោះ
  const res = await axios.patch(`/api/todos/${id}`, { 
    completed: isCompleted 
  });
  return res.data;
};
```
