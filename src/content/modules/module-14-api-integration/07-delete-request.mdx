# DELETE Request

Sends HTTP DELETE to purge a record from the database.

### Key Concepts & Rules:

- Check response status 200/204 to confirm deletion.

### Code Example: Axios DELETE Request

```tsx
await axios.delete(`/api/todos/${id}`);
```
