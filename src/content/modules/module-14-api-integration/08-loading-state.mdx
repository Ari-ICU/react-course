# Loading State

Set `isLoading(true)` before the request and `isLoading(false)` in `finally`.

### Key Concepts & Rules:

- Always use `finally` to ensure loading spinners disappear on error.

### Code Example: In-Flight Loading Lifecycle

```jsx
try {
  setIsLoading(true);
  const data = await fetchStudents();
  setStudents(data);
} catch (err) {
  setError('Failed to load students');
} finally {
  setIsLoading(false);
}
```
