# Error Handling

Extract error messages from `error.response?.data?.message` to give users actionable feedback.

### Key Concepts & Rules:

- Differentiate network failures from 400 validation errors.

### Code Example: Parsing API Error Responses

```tsx
catch (error: any) {
  const message = error.response?.data?.message || error.message || 'Unknown network error';
  toast.error(message);
}
```
