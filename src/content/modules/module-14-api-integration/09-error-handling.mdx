# Error Handling

បញ្ហាបណ្តាញ (Network failures), ការបញ្ចូលទិន្នន័យមិនត្រឹមត្រូវ (422 Validation errors), ឬបញ្ហាខាង Server (500 Server error) សុទ្ធតែអាចកើតឡើងបានគ្រប់ពេលវេលា។ ការគ្រប់គ្រង Error ឱ្យបានត្រឹមត្រូវជួយការពារកុំឱ្យកម្មវិធី Crash និងផ្តល់សារជូនដំណឹងច្បាស់លាស់ដល់ User។

### Key Concepts & Rules:

- បែងចែកឱ្យដាច់រវាងបញ្ហាដាច់បណ្តាញ (No Internet) និងកំហុសឆ្លើយតបពី Server (HTTP Status 4xx / 5xx)។
- ស្រង់យកសារ Error ដែល Server បញ្ជូនមកតាមរយៈ `error.response?.data?.message`។
- ផ្តល់នូវប៊ូតុង Retry ដើម្បីឱ្យ User អាចចុចសាកល្បងម្តងទៀតបាន។

### Code Example: Parsing API Error Responses

```jsx
import axios from 'axios';

try {
  await axios.post('/api/register', formData);
} catch (error: any) {
  if (axios.isAxiosError(error)) {
    // ស្រង់យកសារ Error ដែល Backend បានកំណត់
    const message = error.response?.data?.message || 'ការចុះឈ្មោះមិនបានសម្រេច';
    showToast(message, 'error');
  } else {
    showToast('មានបញ្ហាមិនរំពឹងទុកបានកើតឡើង', 'error');
  }
}
```
