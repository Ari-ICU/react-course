# API Service Layer

ដើម្បីកុំឱ្យ UI Components មានភាពស្មុគស្មាញ និងពោរពេញដោយកូដ HTTP endpoints អ្នកគួរតែអនុវត្ត **Service Layer Pattern**។ វិធីសាស្ត្រនេះប្រមូលផ្តុំរាល់ API Calls ទាំងអស់ទៅក្នុងម៉ូឌុលដាច់ដោយឡែក (ដូចជា `studentService.ts`, `authService.ts`)។

### Key Concepts & Rules:

- បំបែកការងាររវាង UI Presentation និង Data Fetching Logic។
- បង្កើត Type-safe API methods ជាមួយ TypeScript។
- ងាយស្រួលក្នុងការធ្វើ Mock ទិន្នន័យនៅពេលសរសេរ Unit Test។

### Code Example: Dedicated Service Layer Pattern

```jsx
// src/services/studentService.ts
import { apiClient } from './apiClient';
import { Student, CreateStudentInput } from '@/types';

export const studentService = {
  getAll: async (): Promise<Student[]> => {
    const res = await apiClient.get<Student[]>('/students');
    return res.data;
  },
  
  getById: async (id: string): Promise<Student> => {
    const res = await apiClient.get<Student>(`/students/${id}`);
    return res.data;
  },
  
  create: async (payload: CreateStudentInput): Promise<Student> => {
    const res = await apiClient.post<Student>('/students', payload);
    return res.data;
  },
  
  delete: async (id: string): Promise<void> => {
    await apiClient.delete(`/students/${id}`);
  },
};
```
