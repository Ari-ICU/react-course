# Axios Instance Configuration

Create a centralized Axios instance with default headers and base URL.

### Key Concepts & Rules:

- Single place to configure authorization headers.

### Code Example: Axios Centralized Instance

```tsx
import axios from 'axios';

export const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'https://api.reactcourse.dev/v1',
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});
```
