# Response Interceptors

Catch 401 Unauthorized responses globally to refresh access tokens or redirect to login.

### Key Concepts & Rules:

- Centralizes session expiration handling.

### Code Example: Response Error Interceptor

```jsx
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // Trigger token refresh or logout
      window.location.href = '/login?expired=true';
    }
    return Promise.reject(error);
  }
);
```
