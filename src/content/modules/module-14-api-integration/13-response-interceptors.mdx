# Response Interceptors

Response Interceptors អនុញ្ញាតឱ្យអ្នកត្រួតពិនិត្យ និងកែច្នៃលទ្ធផល Response ដែលទទួលបានពី Server មុនពេលវាត្រូវបានបញ្ជូនទៅកាន់ប្លុក `.then()` ឬ `try/catch` របស់ Component។ វាស័ក្តិសមបំផុតសម្រាប់ការដោះស្រាយវិបត្តិ Session ផុតកំណត់ (401 Unauthorized) ឬការកត់ត្រា Log សកល។

### Key Concepts & Rules:

- ស្ទាក់ចាប់កំហុស 401 ដើម្បីធ្វើការ Logout ឬស្នើសុំ Refresh Token ថ្មីដោយស្វ័យប្រវត្តិ។
- អាចបំប្លែងទម្រង់ Response Data ឱ្យស្រួលប្រើប្រាស់មុនពេលបញ្ជូនទៅ UI។
- ត្រូវតែហៅ `Promise.reject(error)` ដើម្បីឱ្យប្លុក `catch` របស់ Caller នៅតែអាចចាប់ Error បានដដែល។

### Code Example: Response Error Interceptor

```jsx
// src/lib/apiClient.ts
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // សម្អាត Auth Token ដែលផុតកំណត់
      localStorage.removeItem('access_token');
      // បញ្ជូន User ទៅកាន់ទំព័រចូលប្រើប្រាស់
      window.location.href = '/login?expired=true';
    }
    
    return Promise.reject(error);
  }
);
```
