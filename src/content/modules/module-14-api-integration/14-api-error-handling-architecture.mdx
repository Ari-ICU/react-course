# API Error Handling Architecture

Map raw HTTP error codes to strongly typed domain errors.

### Key Concepts & Rules:

- Provides clean typed error models for UI components.

### Code Example: Strongly Typed ApiError Model

```tsx
export interface ApiError {
  statusCode: number;
  message: string;
  fieldErrors?: Record<string, string[]>;
}
```
