# Module 14: API Integration

REST API communication, Axios, HTTP methods, service layers, interceptors, and robust network error handling.

## Module Syllabus (15 Lessons)

- **Lesson 01**: React + REST API - *How frontend React applications interface with backend services.*
- **Lesson 02**: Fetching API Data - *Native fetch() API vs external HTTP client libraries.*
- **Lesson 03**: GET Request - *Retrieving records from backend endpoints.*
- **Lesson 04**: POST Request - *Creating new resources with JSON payload.*
- **Lesson 05**: PUT Request - *Full replacement update of an existing resource.*
- **Lesson 06**: PATCH Request - *Partial update of specific modified fields.*
- **Lesson 07**: DELETE Request - *Removing a resource by identifier.*
- **Lesson 08**: Loading State - *Tracking in-flight network requests.*
- **Lesson 09**: Error Handling - *Parsing server error responses and displaying helpful messages.*
- **Lesson 10**: API Service Layer - *Abstracting HTTP calls out of UI components.*
- **Lesson 11**: Axios Instance Configuration - *Configuring base URLs, timeouts, and headers.*
- **Lesson 12**: Request Interceptors - *Automatically attaching Bearer tokens to outgoing requests.*
- **Lesson 13**: Response Interceptors - *Handling global errors and automatic 401 token refresh.*
- **Lesson 14**: API Error Handling Architecture - *Unified error models and retry policies.*
- **Lesson 15**: Environment Variables for APIs - *Configuring dev vs staging vs production endpoints safely.*
