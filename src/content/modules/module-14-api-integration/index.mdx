# Module 14: API Integration

ការតភ្ជាប់កម្មវិធី React ជាមួយ REST API, ការប្រើប្រាស់ Axios, HTTP methods (GET, POST, PUT, PATCH, DELETE), service layers, interceptors, និងការគ្រប់គ្រង Network Errors ប្រកបដោយប្រសិទ្ធភាព។

## Module Syllabus (15 Lessons)

- **Lesson 01**: React + REST API - *ស្វែងយល់អំពីរបៀបដែល Frontend React ធ្វើការទំនាក់ទំនងជាមួយ Backend Services តាមរយៈ REST API។*
- **Lesson 02**: Fetching API Data - *ការប្រៀបធៀបរវាង Browser Native fetch() API និង External HTTP Client Libraries ដូចជា Axios។*
- **Lesson 03**: GET Request - *ការទាញយកទិន្នន័យ (Retrieve Data) ពី Backend API Endpoints មកបង្ហាញលើ UI។*
- **Lesson 04**: POST Request - *ការផ្ញើទិន្នន័យបង្កើត Resource ថ្មីនៅលើ Server តាមរយៈ Request Body ជាទម្រង់ JSON។*
- **Lesson 05**: PUT Request - *ការធ្វើបច្ចុប្បន្នភាពទិន្នន័យទាំងមូល (Full Resource Replacement) នៃ Resource ណាមួយ។*
- **Lesson 06**: PATCH Request - *ការធ្វើបច្ចុប្បន្នភាពតែចំណែកជាក់លាក់ណាមួយនៃទិន្នន័យ (Partial Update)។*
- **Lesson 07**: DELETE Request - *ការលុបទិន្នន័យ Resource ចេញពី Server ដោយបញ្ជាក់ពី Unique Identifier (ID)។*
- **Lesson 08**: Loading State - *ការគ្រប់គ្រង និងតាមដានស្ថានភាពកំពុងទាញយកទិន្នន័យ (In-flight Requests) ដើម្បីបង្ហាញ Spinner ឬ Skeleton UI។*
- **Lesson 09**: Error Handling - *ការចាប់យក និងបំប្លែង Server Error Responses មកជាសារជូនដំណឹងដែលងាយស្រួលយល់ដល់អ្នកប្រើប្រាស់។*
- **Lesson 10**: API Service Layer - *ការបំបែកកូដ HTTP Calls ចេញពី UI Components ទៅកាន់ Dedicated Service Layer ឱ្យមានរបៀបរៀបរយ។*
- **Lesson 11**: Axios Instance Configuration - *ការបង្កើត និងកំណត់រចនាសម្ព័ន្ធ Axios Instance តែមួយសម្រាប់គម្រោង (Base URL, Timeouts, Headers)។*
- **Lesson 12**: Request Interceptors - *ការភ្ជាប់ Authentication Bearer Tokens ទៅក្នុង Request Headers ដោយស្វ័យប្រវត្តិកំណត់មុនពេល Request ចេញទៅ។*
- **Lesson 13**: Response Interceptors - *ការគ្រប់គ្រង Global Errors និងដំណើរការ Automatic Token Refresh នៅពេលជួប Status Code 401 Unauthorized។*
- **Lesson 14**: API Error Handling Architecture - *ការរៀបចំរចនាសម្ព័ន្ធដោះស្រាយកំហុសកម្រិតស្ថាបត្យកម្ម (Unified Error Models និង Retry Policies)។*
- **Lesson 15**: Environment Variables for APIs - *ការប្រើប្រាស់ Environment Variables ដើម្បីគ្រប់គ្រង API Endpoints សម្រាប់ Development, Staging, និង Production ដោយសុវត្ថិភាព។*
