# TanStack Query Introduction

TanStack Query (ពីមុនហៅថា React Query) គឺជាបណ្ណាល័យស្តង់ដារឧស្សាហកម្មសម្រាប់ការទាញយក (Fetching), Caching, ធ្វើសមកាលកម្ម (Synchronizing), និងធ្វើបច្ចុប្បន្នភាព Server State នៅក្នុងកម្មវិធី React។ វាជួយដោះស្រាយបញ្ហាស្មុគស្មាញជាច្រើនដូចជា Window Focus Refetching, Network Reconnect Refetching, និង Query Deduplication។

### Key Concepts & Rules:

- លុបបំបាត់ការសរសេរ `useEffect` + `useState` ដ៏ដដែលៗសម្រាប់ Data Fetching។
- មានប្រព័ន្ធ Caching ដ៏ឆ្លាតវៃ និង Garbage Collection ដោយស្វ័យប្រវត្តិ។
- គាំទ្រការ Refresh ទិន្នន័យដោយស្វ័យប្រវត្តិនៅពេល User ត្រឡប់មកកាន់ផ្ទាំង Browser វិញ (Window Focus)។

### Code Example: TanStack Query Quickstart Setup

```jsx
// 1. Install TanStack Query:
// npm install @tanstack/react-query @tanstack/react-query-devtools

import React from 'react';
import { QueryClient, QueryClientProvider, useQuery } from '@tanstack/react-query';

const queryClient = new QueryClient();

function CourseLessonList() {
  // Declarative query handles loading, errors, caching, and retries automatically!
  const { data, isLoading, isError, error } = useQuery({
    queryKey: ['lessons'],
    queryFn: async () => {
      const res = await fetch('/api/lessons');
      if (!res.ok) throw new Error('Network error');
      return res.json();
    },
  });

  if (isLoading) return <div>Loading cached data...</div>;
  if (isError) return <div>Failed to load: {error.message}</div>;

  return <div>Lessons loaded: {data.length} items</div>;
}

export function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <CourseLessonList />
    </QueryClientProvider>
  );
}
```
