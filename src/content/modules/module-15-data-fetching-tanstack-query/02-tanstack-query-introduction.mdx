# TanStack Query Introduction

TanStack Query handles caching, background synchronization, deduping identical requests, retries on failure, and window focus refetching out of the box.

### Key Concepts & Rules:

- Eliminates 90% of boilerplate `useEffect` fetching code.
- Automatic caching and garbage collection.

### Code Example: Installing TanStack Query v5

```tsx
npm install @tanstack/react-query @tanstack/react-query-devtools
```
