# useQuery Hook

Hook `useQuery` គឺជាឧបករណ៍ស្នូលនៃ TanStack Query ដែលប្រើប្រាស់សម្រាប់ទាញយកទិន្នន័យ (Fetch Data)។ វាត្រូវការ options ចម្បងពីរគឺ `queryKey` (កូនសោសម្គាល់ cache នៃទិន្នន័យ) និង `queryFn` (អនុគមន៍ដែល return Promise ដូចជា axios call)។

### Key Concepts & Rules:

- ផ្តល់នូវ State ពេញលេញរួមមាន `{ data, isLoading, isError, error, refetch }`។
- ធ្វើការ Caching ទិន្នន័យដោយស្វ័យប្រវត្តិតាមរយៈ `queryKey`។
- ប្រសិនបើមាន component ច្រើនហៅ `useQuery` ជាមួយ key ដូចគ្នាក្នុងពេលតែមួយ វានឹងធ្វើ network request តែម្តងគត់ (Automatic Deduplication)។

### Code Example: Basic useQuery Hook

```jsx
import { useQuery } from '@tanstack/react-query';
import { studentService } from '@/services/studentService';

export function StudentList() {
  const { 
    data: students, 
    isLoading, 
    isError, 
    error 
  } = useQuery({
    queryKey: ['students'],
    queryFn: studentService.getAll,
  });

  if (isLoading) return <p>កំពុងទាញយកទិន្នន័យ...</p>;
  if (isError) return <p className="text-red-500">{error.message}</p>;

  return (
    <ul>
      {students?.map((student) => (
        <li key={student.id}>{student.name} - GPA: {student.gpa}</li>
      ))}
    </ul>
  );
}
```
