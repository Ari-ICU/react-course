# Loading and Error States

`isPending` indicates initial load with no cached data; `isFetching` indicates background revalidation even if cached data is already visible.

### Key Concepts & Rules:

- Display subtle background fetching spinners while showing cached data.

### Code Example: isPending vs isFetching

```tsx
const { data, isPending, isFetching } = useQuery(...);
// isPending: True on first fetch (show skeleton)
// isFetching: True during background refresh (show subtle top indicator)
```
