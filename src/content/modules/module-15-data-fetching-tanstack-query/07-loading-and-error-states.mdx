# Loading and Error States

នៅក្នុង TanStack Query v5 ស្ថានភាពនៃការទាញយកទិន្នន័យត្រូវបានបែងចែកយ៉ាងលម្អិត។ ការយល់ដឹងពីភាពខុសគ្នារវាង `isPending` និង `isFetching` ជួយឱ្យអ្នកអាចបង្កើត UI ដែលមានភាពរលូន និងមិនរំខានដល់អ្នកប្រើប្រាស់។

### Key Concepts & Rules:

- `isPending`: `true` នៅពេល Query ពុំទាន់មានទិន្នន័យក្នុង Cache នៅឡើយ (កំពុងផ្ទុកដំបូង - បង្ហាញ Skeleton UI)។
- `isFetching`: `true` រាល់ពេលដែលមាន Network Request កំពុងដំណើរការ ទោះបីជាមានទិន្នន័យចាស់បង្ហាញនៅលើអេក្រង់រួចហើយក៏ដោយ (ស័ក្តិសមសម្រាប់របារ Spinner តូចនៅខាងលើ)។
- `isError` & `error`: មានតម្លៃនៅពេលដែល Promise ជួបបរាជ័យ (Reject)។

### Code Example: isPending vs isFetching

```jsx
const { data, isPending, isFetching, isError } = useQuery({
  queryKey: ['dashboardStats'],
  queryFn: fetchStats,
});

// 1. Initial Load: ពុំទាន់មានទិន្នន័យបង្ហាញឡើយ
if (isPending) return <DashboardSkeleton />;

// 2. Error: មានបញ្ហាបណ្តាញ
if (isError) return <ErrorBanner />;

return (
  <div>
    {/* 3. បង្ហាញសញ្ញាសម្គាល់តូចមួយនៅពេល Background Fetching កំពុងដំណើរការ */}
    {isFetching && <span className="text-xs text-blue-500">កំពុងធ្វើសមកាលកម្ម...</span>}
    <StatsGrid stats={data} />
  </div>
);
```
