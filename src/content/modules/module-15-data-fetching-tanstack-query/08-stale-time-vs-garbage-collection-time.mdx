# Stale Time vs Garbage Collection Time

`staleTime` determines how long data is considered fresh before needing a background refresh. `gcTime` determines how long inactive data stays in memory before being evicted.

### Key Concepts & Rules:

- Default `staleTime` is 0 (data immediately considered stale).
- Set `staleTime: 60_000` for data that changes infrequently.

### Code Example: staleTime and gcTime Configuration

```jsx
const { data } = useQuery({
  queryKey: ['systemConfig'],
  queryFn: fetchConfig,
  staleTime: 1000 * 60 * 30, // 30 minutes
  gcTime: 1000 * 60 * 60,    // 1 hour
});
```
