# Stale Time vs Garbage Collection Time

ការគ្រប់គ្រង Memory និង Cache នៅក្នុង TanStack Query ពឹងផ្អែកលើគំនិតស្នូលពីរគឺ `staleTime` និង `gcTime` (Garbage Collection Time - កាលពីមុនហៅថា `cacheTime`)។ ការកំណត់តម្លៃទាំងពីរនេះឱ្យបានត្រឹមត្រូវជួយកាត់បន្ថយ Network Requests ឥតប្រយោជន៍។

### Key Concepts & Rules:

- **`staleTime`**: រយៈពេល (គិតជា milliseconds) ដែលទិន្នន័យត្រូវបានចាត់ទុកថា "នៅថ្មីស្រស់ (Fresh)"។ ដរាបណាទិន្នន័យនៅ Fresh នោះ TanStack Query នឹងមិនធ្វើការស្នើសុំ Network Request ឡើយ។ តម្លៃលំនាំដើមគឺ `0`។
- **`gcTime`**: រយៈពេលដែលទិន្នន័យដែលគ្មាន Component ណាមួយកំពុងប្រើប្រាស់ (Inactive) អាចបន្តស្ថិតនៅក្នុង RAM មុនពេលត្រូវលុបចោល។ តម្លៃលំនាំដើមគឺ 5 នាទី (`300_000` ms)។

### Code Example: staleTime and gcTime Configuration

```jsx
const { data } = useQuery({
  queryKey: ['systemConfig'],
  queryFn: fetchSystemConfig,
  staleTime: 1000 * 60 * 10, // ទិន្នន័យនៅ Fresh រយៈពេល 10 នាទី (មិនបាច់ fetch ឡើងវិញទេ)
  gcTime: 1000 * 60 * 60,    // រក្សាទុកក្នុង Cache RAM រយៈពេល 1 ម៉ោងមុននឹងលុបចោល
});
```
