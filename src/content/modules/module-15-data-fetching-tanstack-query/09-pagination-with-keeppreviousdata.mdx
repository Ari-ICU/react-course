# Pagination with keepPreviousData

Using `placeholderData: keepPreviousData` keeps the old page visible while the next page fetches in the background, preventing layout jumps.

### Key Concepts & Rules:

- Eliminates jarring layout shifts during table pagination.

### Code Example: Smooth Pagination with keepPreviousData

```jsx
import { keepPreviousData, useQuery } from '@tanstack/react-query';

const { data: pageData, isPlaceholderData } = useQuery({
  queryKey: ['students', page],
  queryFn: () => studentService.getPage(page),
  placeholderData: keepPreviousData,
});
```
