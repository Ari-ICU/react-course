# Infinite Queries (useInfiniteQuery)

Manages paginated data as an array of pages, providing `fetchNextPage` and `hasNextPage` flags.

### Key Concepts & Rules:

- Pairs with intersection observer for infinite scroll.

### Code Example: useInfiniteQuery Hook

```jsx
const { data, fetchNextPage, hasNextPage } = useInfiniteQuery({
  queryKey: ['feed'],
  queryFn: ({ pageParam = 1 }) => fetchFeed(pageParam),
  getNextPageParam: (lastPage) => lastPage.nextPage,
  initialPageParam: 1,
});
```
