# Optimistic Updates

Optimistic Update គឺជាបច្ចេកទេសកម្រិតខ្ពស់ដែលធ្វើការ Update UI ភ្លាមៗបន្ទាប់ពី User ចុចប៊ូតុង (ដូចជាចុច Like បេះដូង ឬគូសធីក Task បញ្ចប់) ដោយសន្មតជាមុនថា Server នឹងដំណើរការជោគជ័យ។ ប្រសិនបើ Server បរាជ័យដោយសារដាច់ Network វានឹងធ្វើការ Rollback ទិន្នន័យចាស់ត្រឡប់មកវិញភ្លាម។

### Key Concepts & Rules:

- បោះបង់ Outgoing Queries ចោលជាមួយ `cancelQueries` ក្នុង `onMutate` ដើម្បីកុំឱ្យទិន្នន័យចាស់ជាន់គ្នា។
- រក្សាទុក Snapshot នៃទិន្នន័យចាស់ (`previousData`) មុនពេល update cache។
- ប្រើ `setQueryData` ដើម្បីកែប្រែ Cache ភ្លាមៗ។
- ក្នុងករណី `onError` ត្រូវ Rollback Cache ដោយប្រើ Snapshot ចាស់។
- ក្នុង `onSettled` ត្រូវ `invalidateQueries` ដើម្បីឱ្យទិន្នន័យត្រឹមត្រូវ 100% ជាមួយ Database។

### Code Example: Complete Optimistic Update Pattern

```jsx
import { useMutation, useQueryClient } from '@tanstack/react-query';

const toggleTodoMutation = useMutation({
  mutationFn: todoService.toggleComplete,
  onMutate: async (todoId: string) => {
    // 1. បោះបង់ Queries ដែលកំពុងរត់
    await queryClient.cancelQueries({ queryKey: ['todos'] });

    // 2. រក្សាទុក Snapshot ចាស់សម្រាប់ Rollback
    const previousTodos = queryClient.getQueryData<Todo[]>(['todos']);

    // 3. Update Cache ក្នុងមូលដ្ឋានភ្លាមៗ (Optimistic Update)
    queryClient.setQueryData<Todo[]>(['todos'], (old = []) =>
      old.map(t => t.id === todoId ? { ...t, completed: !t.completed } : t)
    );

    return { previousTodos }; // ផ្ញើទៅ onError តាមរយៈ Context
  },
  onError: (err, todoId, context) => {
    // 4. Rollback ត្រឡប់មកទិន្នន័យដើមវិញពេល Server បរាជ័យ
    if (context?.previousTodos) {
      queryClient.setQueryData(['todos'], context.previousTodos);
    }
  },
  onSettled: () => {
    // 5. Sync ទិន្នន័យចុងក្រោយជាមួយ Server
    queryClient.invalidateQueries({ queryKey: ['todos'] });
  },
});
```
