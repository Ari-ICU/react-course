# Query Invalidation

Marking queries as invalid causes them to refetch if they are currently active on screen.

### Key Concepts & Rules:

- Use exact or prefix matching.

### Code Example: Invalidating Query Cache

```tsx
queryClient.invalidateQueries({ queryKey: ['todos'] });
```
