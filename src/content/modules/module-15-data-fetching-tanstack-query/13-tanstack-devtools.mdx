# TanStack DevTools

The TanStack Query Devtools floating panel displays all cached queries, their data, fetch state, and provides buttons to trigger manual refetch or cache clearing.

### Key Concepts & Rules:

- Included in dev builds only; stripped in production.

### Code Example: Integrating ReactQueryDevtools

```jsx
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';

<QueryClientProvider client={queryClient}>
  <App />
  <ReactQueryDevtools initialIsOpen={false} />
</QueryClientProvider>
```
