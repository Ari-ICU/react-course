# Module 15: Data Fetching (TanStack Query)

ការប្រៀបធៀប Server State និង Client State, TanStack Query v5, Queries, Mutations, Query Keys, ប្រព័ន្ធ Caching, Pagination, និង Optimistic Updates។

## Module Syllabus (13 Lessons)

- **Lesson 01**: Server State vs Client State - *មូលហេតុដែលទិន្នន័យ Server State ត្រូវតែគ្រប់គ្រងខុសប្លែកទាំងស្រុងពី UI Client State។*
- **Lesson 02**: TanStack Query Introduction - *ស្វែងយល់ពីបណ្ណាល័យគ្រប់គ្រង Asynchronous Server State ដ៏មានឥទ្ធិពលបំផុតសម្រាប់ React (ពីមុនហៅថា React Query)។*
- **Lesson 03**: QueryClientProvider - *ការដំឡើង និងកំណត់រចនាសម្ព័ន្ធ QueryClient នៅ Root នៃកម្មវិធី React។*
- **Lesson 04**: useQuery Hook - *ការទាញយក និង Subscribe ទៅកាន់ Server State តាមរយៈ Hook useQuery។*
- **Lesson 05**: Query Keys - *ការប្រើប្រាស់ Hierarchical Arrays ជាសោរសម្គាល់ (Keys) សម្រាប់ Caching និង Refetching ទិន្នន័យ។*
- **Lesson 06**: useMutation Hook - *ការបង្កើត កែប្រែ និងលុបទិន្នន័យនៅលើ Server ជាមួយ Side Effects តាមរយៈ useMutation។*
- **Lesson 07**: Loading and Error States - *ការស្វែងយល់ពីភាពខុសគ្នារវាង Status Flags: isPending, isFetching, isError, និង isSuccess។*
- **Lesson 08**: Stale Time vs Garbage Collection Time - *ការកំណត់ និងគ្រប់គ្រងអាយុកាល Cache តាមរយៈ staleTime និង gcTime។*
- **Lesson 09**: Pagination with keepPreviousData - *ការធ្វើ Pagination នៅលើតារាងទិន្នន័យដោយរលូន គ្មានការព្រិចភ្នែក (Flickering) ដោយប្រើ keepPreviousData។*
- **Lesson 10**: Infinite Queries (useInfiniteQuery) - *ការបង្កើតមុខងារ 'Load More' និងប្រព័ន្ធរំកិលទំព័រគ្មានដែនកំណត់ (Infinite Scroll) ជាមួយ useInfiniteQuery។*
- **Lesson 11**: Optimistic Updates - *ការធ្វើបច្ចុប្បន្នភាព UI ភ្លាមៗមុនពេល Server ឆ្លើយតបបញ្ជាក់ និងការ Rollback ត្រឡប់មកវិញប្រសិនបើមានកំហុស។*
- **Lesson 12**: Query Invalidation - *ការលុប Cache ចាស់ចោល និងបង្ខំឱ្យ Refetch ទិន្នន័យថ្មីចំគោលដៅបន្ទាប់ពី Mutation។*
- **Lesson 13**: TanStack DevTools - *ការប្រើប្រាស់ផ្ទាំង TanStack DevTools ដើម្បីពិនិត្យមើល Cache State, Stale Queries, និង Mutations។*
