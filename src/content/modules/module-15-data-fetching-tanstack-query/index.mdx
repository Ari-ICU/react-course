# Module 15: Data Fetching (TanStack Query)

Server state vs client state, TanStack Query v5, queries, mutations, query keys, caching, pagination, and optimistic updates.

## Module Syllabus (13 Lessons)

- **Lesson 01**: Server State vs Client State - *Why server data must be treated differently than UI state.*
- **Lesson 02**: TanStack Query Introduction - *The asynchronous state management powerhouse for React (formerly React Query).*
- **Lesson 03**: QueryClientProvider - *Setting up the query client at application root.*
- **Lesson 04**: useQuery Hook - *Fetching and subscribing to server state.*
- **Lesson 05**: Query Keys - *Hierarchical arrays that uniquely identify and cache queries.*
- **Lesson 06**: useMutation Hook - *Creating, updating, and deleting server data with side effects.*
- **Lesson 07**: Loading and Error States - *Granular status flags: isPending, isFetching, isError, isSuccess.*
- **Lesson 08**: Stale Time vs Garbage Collection Time - *Fine-tuning cache lifetime with staleTime and gcTime.*
- **Lesson 09**: Pagination with keepPreviousData - *Seamless table pagination without page flickering.*
- **Lesson 10**: Infinite Queries (useInfiniteQuery) - *Building 'Load More' buttons and infinite scroll feeds.*
- **Lesson 11**: Optimistic Updates - *Instantly updating the UI before server confirmation.*
- **Lesson 12**: Query Invalidation - *Targeted cache busting after mutations.*
- **Lesson 13**: TanStack DevTools - *Visualizing query cache, stale states, and mutations.*
