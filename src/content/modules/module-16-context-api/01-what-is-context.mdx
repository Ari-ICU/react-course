# What is Context?

នៅក្នុង React ជាទូទៅទិន្នន័យត្រូវបានបញ្ជូនពីលើចុះក្រោម (Top-down) ពី Parent ទៅកាន់ Child តាមរយៈ Props។ ប៉ុន្តែនៅពេលដែលកម្មវិធីកាន់តែធំ មានទិន្នន័យមួយចំនួនដែលត្រូវការប្រើប្រាស់នៅស្ទើរតែគ្រប់ទីកន្លែង (ដូចជា ព័ត៌មានអ្នកប្រើប្រាស់ដែលបាន Login, ការកំណត់ Theme ងងឹត/ភ្លឺ)។ **Context API** ផ្តល់នូវវិធីសាស្ត្រក្នុងការបញ្ជូនទិន្នន័យចូលទៅកាន់ Component Tree ទាំងមូលដោយផ្ទាល់ ដោយមិនចាំបាច់ឆ្លងកាត់ Props នៅគ្រប់ជាន់ថ្នាក់ឡើយ។

### Key Concepts & Rules:

- ភ្ជាប់មកជាមួយ React រួចជាស្រេច (Built-in) ដោយមិនចាំបាច់ដំឡើងបណ្ណាល័យខាងក្រៅឡើយ។
- ស័ក្តិសមបំផុតសម្រាប់ទិន្នន័យសកលដែលមានការផ្លាស់ប្តូរតិចតួច (Low-frequency updates)។
- ជួយដោះស្រាយបញ្ហា Prop Drilling យ៉ាងមានប្រសិទ្ធភាព។

### Code Example: ThemeContext Definition & Consumption

```jsx
import React, { createContext, useContext, useState } from 'react';

// 1. Create the Context object
const ThemeContext = createContext<{ theme: string; toggleTheme: () => void }>({
  theme: 'dark',
  toggleTheme: () => {},
});

// 2. Deep Leaf Component consumes context directly without prop drilling
function ThemeStatus() {
  const { theme, toggleTheme } = useContext(ThemeContext);
  return (
    <button onClick={toggleTheme} className="px-3 py-1.5 bg-slate-800 text-white rounded text-sm">
      Active Theme: {theme} (Click to Toggle)
    </button>
  );
}

// 3. Provider Component wraps child hierarchy
export function ContextDemoApp() {
  const [theme, setTheme] = useState('dark');
  const toggleTheme = () => setTheme(t => t === 'dark' ? 'light' : 'dark');

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      <div className="p-6 bg-slate-900 border border-slate-800 rounded-xl">
        <ThemeStatus />
      </div>
    </ThemeContext.Provider>
  );
}
```
