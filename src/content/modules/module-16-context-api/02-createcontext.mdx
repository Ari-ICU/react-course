# createContext

ដើម្បីបង្កើត Context ថ្មីមួយ យើងត្រូវប្រើប្រាស់អនុគមន៍ `createContext(defaultValue)`។ អនុគមន៍នេះនឹង return នូវ Context Object មួយដែលមានផ្ទុកទាំង Provider Component និង Consumer សម្រាប់ប្រើប្រាស់នៅក្នុង Component Tree។

### Key Concepts & Rules:

- កំណត់ TypeScript Interface សម្រាប់ទម្រង់នៃ Context Data ដើម្បីទទួលបាន Type Safety។
- តម្លៃ Default Value ដើរតួជា Fallback នៅពេលដែល Component ត្រូវបាន Render នៅក្រៅ Context Provider (មានប្រយោជន៍ខ្លាំងសម្រាប់ការធ្វើ Unit Test)។
- ដាក់ឈ្មោះ Context ដោយសរសេរអក្សរធំនៅខាងដើម ដូចជា `ThemeContext`, `AuthContext`។

### Code Example: Declaring Context with TypeScript

```jsx
import { createContext } from 'react';

// 1. កំណត់រចនាសម្ព័ន្ធ Interface នៃ Context
export interface ThemeContextType {
  theme: 'light' | 'dark';
  toggleTheme: () => void;
}

// 2. បង្កើត Context ដោយកំណត់ defaultValue ឬ undefined
export const ThemeContext = createContext<ThemeContextType | undefined>(undefined);
```
