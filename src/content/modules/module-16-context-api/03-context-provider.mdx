# Context Provider

រាល់ Context Object នីមួយៗតែងតែភ្ជាប់មកជាមួយនូវ Component មួយឈ្មោះថា `<Context.Provider>`។ Provider នេះទទួលយក prop មួយឈ្មោះថា `value` ដែលជាទិន្នន័យ ឬអនុគមន៍ដែលអ្នកចង់ចែករំលែកទៅកាន់ Child Components ទាំងអស់ដែលស្ថិតនៅខាងក្នុងវា។

### Key Concepts & Rules:

- រាល់ Child Component ទាំងអស់ដែលនៅក្រោម Provider អាចទាញយកទិន្នន័យ `value` បានគ្រប់ពេលវេលា។
- នៅពេលដែលតម្លៃ `value` ផ្លាស់ប្តូរ រាល់ Consumer Components ទាំងអស់ដែលកំពុងប្រើប្រាស់ Context នោះនឹង Re-render ដោយស្វ័យប្រវត្តិ។
- គួរតែបង្កើត Wrapper Component ដូចជា `ThemeProvider` ដើម្បីគ្រប់គ្រង State ផ្ទៃក្នុង។

### Code Example: Custom Context Provider Component

```jsx
import React, { useState } from 'react';
import { ThemeContext } from './ThemeContext';

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<'light' | 'dark'>('dark');

  const toggleTheme = () => {
    setTheme(prev => (prev === 'dark' ? 'light' : 'dark'));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      <div className={`app-container ${theme}`}>
        {children}
      </div>
    </ThemeContext.Provider>
  );
}
```
