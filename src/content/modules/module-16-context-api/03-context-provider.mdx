# Context Provider

Every Context object comes with a Provider React component that accepts a `value` prop to be consumed by descendant components.

### Key Concepts & Rules:

- All consumers re-render whenever the Provider's `value` prop changes.

### Code Example: Custom Context Provider Component

```jsx
export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<'light' | 'dark'>('dark');
  const toggleTheme = () => setTheme(t => t === 'dark' ? 'light' : 'dark');

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      <div className={theme}>{children}</div>
    </ThemeContext.Provider>
  );
}
```
