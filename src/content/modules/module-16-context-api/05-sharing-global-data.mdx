# Sharing Global Data

Allows distant child components to read and update shared state.

### Key Concepts & Rules:

- Ideal for app-wide settings that rarely change.

### Code Example: Consuming Context in Child

```tsx
export function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return <button onClick={toggleTheme}>Active Theme: {theme}</button>;
}
```
