# Avoiding Prop Drilling

Context completely eliminates passing props through intermediary components that don't need them.

### Key Concepts & Rules:

- Leaf nodes access context directly.

### Code Example: Eliminating Prop Drilling with Context

```tsx
// Intermediary components don't touch auth props!
<AuthProvider>
  <AppLayout>
    <Sidebar />
    <MainContent>
      <UserAvatar /> {/* Consumes useAuth() directly */}
    </MainContent>
  </AppLayout>
</AuthProvider>
```
