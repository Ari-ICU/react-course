# Avoiding Prop Drilling

បញ្ហា **Prop Drilling** កើតឡើងនៅពេលដែលអ្នកត្រូវបញ្ជូន Prop ឆ្លងកាត់ Components កណ្តាលជាច្រើនជាន់ (ឧទាហរណ៍៖ `App` -> `Layout` -> `Sidebar` -> `UserMenu` -> `Avatar`) ទោះបីជា Components កណ្តាលទាំងនោះមិនត្រូវការប្រើប្រាស់ Prop នោះទាល់តែសោះក៏ដោយ។ Context API ជួយលុបបំបាត់បញ្ហានេះចោលទាំងស្រុង។

### Key Concepts & Rules:

- Component កណ្តាលមិនចាំបាច់ដឹងអំពី Props ដែលខ្លួនមិនប្រើឡើយ។
- សន្សំសំចៃពេលវេលាក្នុងការ Refactor នៅពេល Component hierarchy ផ្លាស់ប្តូរ។
- Component ចុងក្រោយ (Leaf Component) អាចទាញយក Context ដោយផ្ទាល់។

### Code Example: Eliminating Prop Drilling with Context

```jsx
// ❌ បែប Prop Drilling (ពិបាកថែទាំ):
// <App user={user}> -> <Layout user={user}> -> <Header user={user}> -> <Avatar user={user} />

// ✅ បែប Context API (ស្អាត និងមានរបៀប):
export function AppLayout() {
  return (
    <AuthProvider>
      <Header />
      <Sidebar />
      <MainContent>
        {/* UserAvatar ហៅ useAuth() ដោយផ្ទាល់ មិនបាច់ pass props ឆ្លងកាត់ Header/Sidebar ឡើយ */}
        <UserAvatar />
      </MainContent>
    </AuthProvider>
  );
}
```
