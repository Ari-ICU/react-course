# Context Best Practices

ដើម្បីកុំឱ្យកម្មវិធីរបស់អ្នកជួបបញ្ហា Performance ឬពិបាកថែទាំ អ្នកគួរតែអនុវត្តតាមគោលការណ៍ណែនាំស្តង់ដារនៅពេលប្រើប្រាស់ Context API៖

### Key Concepts & Rules:

1. **Colocate Providers**: កុំដាក់ Provider ទាំងអស់នៅ Root App ឡើយ។ ប្រសិនបើ State ប្រើតែក្នុង Modal ឬ Dashboard សូមដាក់ Provider នៅត្រឹម Component នោះ។
2. **Custom Hook Wrapping**: បង្កើត Custom Hook ជានិច្ច (ដូចជា `useAuth()`) ដើម្បីផ្តល់ការ Error Checking ពេលភ្លេចរុំ Provider។
3. **Split Contexts**: បំបែក Context តាម Domain មុខងារ កុំច្របាច់បញ្ចូលគ្នា។
4. **Local State First**: បើទិន្នន័យប្រើតែក្នុង Component តែមួយ ចូរប្រើ `useState` កុំប្រើ Context ដោយមិនចាំបាច់។

### Code Example: Localized Provider Placement

```jsx
// ឧទាហរណ៍៖ MultiStepFormProvider ត្រូវការតែក្នុងទំព័រ Checkout ប៉ុណ្ណោះ
export function CheckoutPage() {
  return (
    <CheckoutFormProvider>
      <StepIndicator />
      <StepContent />
      <StepNavigation />
    </CheckoutFormProvider>
  );
}
// មិនចាំបាច់ដាក់ CheckoutFormProvider នៅ Root App ឡើយ!
```
