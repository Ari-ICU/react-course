# Context Limitations

Context lacks fine-grained selectors and middleware. When state updates frequently, external libraries with selector subscriptions provide vastly superior performance.

### Key Concepts & Rules:

- Context = Dependency Injection tool; Zustand = State Management tool.

### Code Example: Context vs External State Library

```jsx
/*
Use Context for: Low-frequency, broad data (Theme, Auth, Language).
Use Zustand for: High-frequency, complex, or modular state (Cart, Filters, Media Player).
*/
```
