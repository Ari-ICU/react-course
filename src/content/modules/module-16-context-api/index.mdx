# Module 16: Context API

ស្វែងយល់ពីយន្តការ Context API របស់ React, ការប្រើប្រាស់ createContext, Provider, useContext, ការលុបបំបាត់ Prop Drilling, Authentication Context, Theme Context, និងចំណុចកម្រិតនៃការប្រើប្រាស់ (Limitations)។

## Module Syllabus (11 Lessons)

- **Lesson 01**: What is Context? - *យន្តការស្នូលរបស់ React សម្រាប់បញ្ជូនទិន្នន័យទៅកាន់គ្រប់ Components ទាំងអស់នៅក្នុង Tree ដោយមិនចាំបាច់ឆ្លងកាត់ Props។*
- **Lesson 02**: createContext - *ការបង្កើត Context Object ជាមួយនឹងតម្លៃលំនាំដើម (Default Fallback Value)។*
- **Lesson 03**: Context Provider - *ការផ្គត់ផ្គង់ទិន្នន័យទៅកាន់ Child Components តាមរយៈ <Context.Provider value={...}>។*
- **Lesson 04**: useContext - *ការទាញយកទិន្នន័យពី Context មកប្រើប្រាស់នៅក្នុង Functional Components យ៉ាងងាយស្រួល។*
- **Lesson 05**: Sharing Global Data - *ការចែករំលែកការកំណត់ (Settings), Preferences, និង Configurations ទៅកាន់គ្រប់ផ្នែកទាំងអស់នៃកម្មវិធី។*
- **Lesson 06**: Authentication Context - *ការរៀបចំប្រព័ន្ធគ្រប់គ្រង Session ការពារ Login/Logout និង User Profile សកលជាមួយ AuthContext។*
- **Lesson 07**: Avoiding Prop Drilling - *ការប្រៀបធៀបរវាងបញ្ហា Prop Drilling និងដំណោះស្រាយតាមរយៈ Context API។*
- **Lesson 08**: Context Performance Pitfall - *បញ្ហា Re-render នៃគ្រប់ Consumers ទាំងអស់នៅពេលដែលតម្លៃ Context ណាមួយផ្លាស់ប្តូរ។*
- **Lesson 09**: Memoizing Context Values - *ការការពារកុំឱ្យ Consumer Re-render ដោយឥតប្រយោជន៍តាមរយៈ useMemo និង useCallback។*
- **Lesson 10**: Context Best Practices - *គោលការណ៍ល្អបំផុតសម្រាប់ការរចនា Provider ឱ្យមានរបៀប និងការបែងចែក Context តាមមុខងារ។*
- **Lesson 11**: Context Limitations - *ហេតុផលដែលកម្មវិធីខ្នាតធំជ្រើសរើសប្តូរពី Context ទៅកាន់ State Management Libraries ដូចជា Zustand ឬ Redux។*
