# Module 16: Context API

Context API mechanics, createContext, Provider, useContext, avoiding prop drilling, authentication context, theme context, and limitations.

## Module Syllabus (11 Lessons)

- **Lesson 01**: What is Context? - *React's native mechanism for broadcasting data across the component tree.*
- **Lesson 02**: createContext - *Instantiating a context object with fallback defaults.*
- **Lesson 03**: Context Provider - *Supplying values to the subtree using <Context.Provider value={...}>.*
- **Lesson 04**: useContext - *Consuming context in functional components.*
- **Lesson 05**: Sharing Global Data - *Broadcasting settings, preferences, and configurations.*
- **Lesson 06**: Authentication Context - *Full authentication session context pattern.*
- **Lesson 07**: Avoiding Prop Drilling - *Comparing prop drilling vs context solutions.*
- **Lesson 08**: Context Performance Pitfall - *Every consumer re-renders on any value update.*
- **Lesson 09**: Memoizing Context Values - *Preventing unnecessary consumer re-renders with useMemo.*
- **Lesson 10**: Context Best Practices - *Rules for safe context consumption and clean provider architectures.*
- **Lesson 11**: Context Limitations - *Why large apps transition from Context to Zustand or Redux.*
