# Client State vs Server State

នៅក្នុងស្ថាបត្យកម្មទំនើបនៃកម្មវិធី React ការបែងចែកភារកិច្ចរវាង Server State និង Client State គឺជាគន្លឹះដ៏សំខាន់។ យើងប្រគល់ការងារគ្រប់គ្រង Cache ទិន្នន័យដែលទាញយកពី Backend ទៅកាន់ TanStack Query រីឯទិន្នន័យ Client State សុទ្ធសាធ (ដូចជា កន្ត្រកទំនិញ Shopping Cart, ផ្ទាំង Modal/Drawer, Audio Player, Theme) ត្រូវបានប្រគល់ឱ្យ Zustand គ្រប់គ្រង។

### Key Concepts & Rules:

- **TanStack Query**: គ្រប់គ្រង Asynchronous Server Data (Products, User Profile, Posts)។
- **Zustand**: គ្រប់គ្រង Synchronous Client UI State (Cart items, Modal visibility, Dark mode)។
- មិនត្រូវចម្លង ឬ Sync ទិន្នន័យ Server ចូលទៅក្នុង Zustand Store ដោយមិនចាំបាច់ឡើយ។

### Code Example: Modern Separation of State Responsibilities

```jsx
import React from 'react';
import { useQuery } from '@tanstack/react-query';
import { create } from 'zustand';

// 1. Client UI State: Managed synchronously via Zustand (No loading spinners needed)
interface UIState {
  isCartDrawerOpen: boolean;
  toggleCartDrawer: () => void;
}
export const useUIStore = create<UIState>((set) => ({
  isCartDrawerOpen: false,
  toggleCartDrawer: () => set((state) => ({ isCartDrawerOpen: !state.isCartDrawerOpen })),
}));

// 2. Component coordinating Server State & Client State
export function StorefrontHeader() {
  // Server State: Cached, background refreshed, handles network state
  const { data: user } = useQuery({
    queryKey: ['authUser'],
    queryFn: async () => ({ name: 'Sophea', role: 'Developer' }),
  });

  // Client UI State: Fast, local interface interaction
  const { isCartDrawerOpen, toggleCartDrawer } = useUIStore();

  return (
    <header className="p-4 bg-slate-900 border border-slate-800 rounded-xl flex justify-between">
      <span className="text-white">Logged in as: {user?.name || 'Guest'}</span>
      <button onClick={toggleCartDrawer} className="px-3 py-1 bg-blue-600 text-white rounded text-sm">
        Cart ({isCartDrawerOpen ? 'Open' : 'Closed'})
      </button>
    </header>
  );
}
```
