# When to Use Context vs Zustand

Use Context for static/low-frequency data. Use Zustand when you need fine-grained selector subscriptions that only re-render components when specific chosen properties change.

### Key Concepts & Rules:

- Zustand requires NO Provider wrapping; access stores anywhere!

### Code Example: Installing Zustand

```jsx
npm install zustand
```
