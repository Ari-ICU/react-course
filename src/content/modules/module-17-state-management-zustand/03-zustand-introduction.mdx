# Zustand Introduction

Zustand (ពាក្យអាល្លឺម៉ង់មានន័យថា "State / ស្ថានភាព") គឺជាបណ្ណាល័យគ្រប់គ្រង State ដ៏ពេញនិយមបំផុតនាពេលបច្ចុប្បន្ន។ វាត្រូវបានបង្កើតឡើងដោយផ្អែកលើគោលការណ៍ Flux ដ៏សាមញ្ញ ប៉ុន្តែលុបបំបាត់ចោលនូវភាពស្មុគស្មាញ (Boilerplate) របស់ Redux ទាំងស្រុង។

### Key Concepts & Rules:

- បង្កើត Store ដោយផ្ទាល់តាមរយៈ Hook តែមួយគត់គឺ `create()`។
- គ្មានការប្រើប្រាស់ Reducer, Action Types, ឬ Dispatchers ស្មុគស្មាញឡើយ។
- គាំទ្រ TypeScript ពេញលេញ និងមានសមត្ថភាព Re-render យ៉ាងរហ័សបំផុត។

### Code Example: Basic Zustand Store

```jsx
import { create } from 'zustand';

interface CounterState {
  count: number;
  increment: () => void;
  reset: () => void;
}

export const useCounterStore = create<CounterState>((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));
```
