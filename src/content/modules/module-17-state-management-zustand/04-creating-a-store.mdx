# Creating a Store

In Zustand, state and actions are colocated inside the store definition. The `set` function merges state updates shallowly.

### Key Concepts & Rules:

- `set()` automatically merges state at the top level.

### Code Example: Colocating State and Actions

```jsx
export const useUIStore = create<UIState>((set) => ({
  isSidebarOpen: false,
  activeModal: null,
  toggleSidebar: () => set(state => ({ isSidebarOpen: !state.isSidebarOpen })),
  openModal: (modalName) => set({ activeModal: modalName }),
  closeModal: () => set({ activeModal: null }),
}));
```
