# Reading Store State

Components invoke the store hook: `const isSidebarOpen = useUIStore(state => state.isSidebarOpen)`.

### Key Concepts & Rules:

- Always pass a selector to avoid subscribing to the entire store.

### Code Example: Consuming Zustand Store

```tsx
export function SidebarToggle() {
  const isSidebarOpen = useUIStore((state) => state.isSidebarOpen);
  const toggleSidebar = useUIStore((state) => state.toggleSidebar);

  return <button onClick={toggleSidebar}>{isSidebarOpen ? 'Close' : 'Open'}</button>;
}
```
