# Selectors & Performance

អត្ថប្រយោជន៍ធំបំផុតមួយរបស់ Zustand លើ Context API គឺសមត្ថភាព **Fine-grained Subscriptions**។ នៅពេលអ្នកប្រើប្រាស់ Selector Function ដូចជា `state => state.isSidebarOpen` Component នោះនឹង Re-render តែមួយគត់នៅពេលដែលតម្លៃ `isSidebarOpen` ផ្លាស់ប្តូរ! ប្រសិនបើ Property ផ្សេងទៀតក្នុង Store ផ្លាស់ប្តូរ Component នេះនឹងមិន Re-render ឡើយ។

### Key Concepts & Rules:

- Component នឹង Re-render តែនៅពេលដែលលទ្ធផលនៃ Selector ផ្លាស់ប្តូរ (Strict Equality `===`)។
- អាចគណនា Derived Data ក្នុង Selector បាន (ឧទាហរណ៍៖ `state => state.items.length`)។
- ចៀសវាងការ return Object ថ្មីក្នុង Selector បើគ្មាន Custom Equality Check (ដូចជា `useShallow`)។

### Code Example: Selector Subscription Pattern

```jsx
import { useCartStore } from '@/store/useCartStore';

export function CartBadge() {
  // ✅ ល្អបំផុត៖ Subscribe តែលើចំនួនសរុបនៃទំនិញ
  // ប្រសិនបើឈ្មោះទំនិញ ឬតម្លៃកែប្រែ Badge នេះនឹងមិន Re-render ឡើយ
  const itemCount = useCartStore((state) => state.items.length);

  return <span className="badge">{itemCount}</span>;
}

// ❌ មិនល្អ៖ Subscribe ទៅកាន់ Store ទាំងមូល
// const store = useCartStore(); // នឹង Re-render រាល់ពេល Store មានការប្រែប្រួលណាមួយ!
```
