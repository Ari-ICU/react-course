# Selectors & Performance

By selecting only `state.isSidebarOpen`, the component will NOT re-render if `activeModal` changes elsewhere in the store. This provides immense performance gains over Context.

### Key Concepts & Rules:

- Components re-render ONLY when their selected slice changes.

### Code Example: Selector Subscription Pattern

```jsx
// ✅ Optimal: Subscribes ONLY to 'itemsCount':
const count = useCartStore(state => state.items.length);

// ❌ Suboptimal: Subscribes to ENTIRE store object:
// const store = useCartStore(); // Re-renders on ANY change in store!
```
