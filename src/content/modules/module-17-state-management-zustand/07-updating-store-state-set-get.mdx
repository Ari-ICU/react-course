# Updating Store State (set & get)

The `get()` function allows reading other state properties inside an action without subscribing.

### Key Concepts & Rules:

- Use `get()` to read current values during async flows.

### Code Example: Using set and get in Actions

```tsx
export const useCartStore = create<CartState>((set, get) => ({
  items: [],
  addItem: (item) => {
    const currentItems = get().items;
    const existing = currentItems.find(i => i.id === item.id);
    if (existing) {
      set({
        items: currentItems.map(i => i.id === item.id ? { ...i, qty: i.qty + 1 } : i)
      });
    } else {
      set({ items: [...currentItems, { ...item, qty: 1 }] });
    }
  },
}));
```
