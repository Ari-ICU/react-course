# Accessing State Outside Components

គុណសម្បត្តិដ៏អស្ចារ្យមួយរបស់ Zustand គឺសមត្ថភាពក្នុងការអាន និងកែប្រែ State នៅខាងក្រៅ React Component Tree (Vanilla JavaScript)។ នេះអនុញ្ញាតឱ្យអ្នកអាចទាញយក Auth Token ឬហៅ Action Logout ដោយផ្ទាល់នៅក្នុង Axios Interceptor ឬ Router Guards ដោយមិនបាច់បារម្ភពីរឿង Hook Rules ឡើយ។

### Key Concepts & Rules:

- ប្រើ `useStore.getState()` ដើម្បីអាន State បច្ចុប្បន្ននៅក្រៅ React។
- ប្រើ `useStore.setState()` ដើម្បីកែប្រែ State ដោយផ្ទាល់ពីគ្រប់ទីកន្លែង។
- ប្រើ `useStore.subscribe()` ដើម្បីតាមដានការផ្លាស់ប្តូរនៅក្រៅ React។

### Code Example: Zustand Outside React Components

```jsx
// src/lib/apiClient.ts (ឯកសារ Vanilla TypeScript គ្មាន React Component ឡើយ)
import axios from 'axios';
import { useAuthStore } from '@/store/useAuthStore';

export const apiClient = axios.create({ baseURL: '/api' });

apiClient.interceptors.request.use((config) => {
  // 1. អាន Token ដោយផ្ទាល់ពី Zustand Store នៅក្រៅ React:
  const token = useAuthStore.getState().token;
  
  if (token && config.headers) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  
  return config;
});

apiClient.interceptors.response.use(
  (res) => res,
  (error) => {
    if (error.response?.status === 401) {
      // 2. ហៅ Action logout ពី Zustand Store ដោយផ្ទាល់:
      useAuthStore.getState().logout();
    }
    return Promise.reject(error);
  }
);
```
