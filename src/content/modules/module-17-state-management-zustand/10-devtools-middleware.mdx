# DevTools Middleware

Wrap your store in `devtools()` to inspect time-travel state changes in Redux DevTools.

### Key Concepts & Rules:

- Named actions appear in DevTools timeline.

### Code Example: Zustand DevTools Middleware

```tsx
import { devtools } from 'zustand/middleware';

export const useStore = create<MyState>()(
  devtools((set) => ({
    // actions...
  }))
);
```
