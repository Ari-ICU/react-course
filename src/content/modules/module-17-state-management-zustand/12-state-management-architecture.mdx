# State Management Architecture

នៅក្នុងកម្មវិធីខ្នាតធំ (Enterprise Scale) ការរៀបចំ Directory និងការបែងចែក Store ឱ្យមានរបៀបរៀបរយគឺជារឿងចាំបាច់។ យុទ្ធសាស្ត្រល្អបំផុតគឺការបង្កើត **Domain-based Modular Stores** ដោយបែងចែក State ទៅតាមមុខងារនីមួយៗ ជាជាងការច្របាច់បញ្ចូលគ្នាក្នុង Store យក្សតែមួយ។

### Key Concepts & Rules:

- រៀបចំ Folder `src/store/` ដោយបែងចែកជាឯកសារ Store ដាច់ដោយឡែកពីគ្នា។
- ប្រើប្រាស់ TypeScript Interfaces យ៉ាងច្បាស់លាស់សម្រាប់ Store នីមួយៗ។
- ងាយស្រួលក្នុងការធ្វើ Refactor និងកាត់បន្ថយទំហំ Bundle តាមរយៈ Tree-shaking។

### Code Example: Modular Store Architecture

```jsx
src/store/
├── useAuthStore.ts           // គ្រប់គ្រង Auth Token, Session, User Profile
├── useCartStore.ts           // គ្រប់គ្រង Cart Items, Checkout, Totals
├── useUIStore.ts             // គ្រប់គ្រង Modals, Sidebar, Theme
└── useNotificationStore.ts   // គ្រប់គ្រង Toast Messages, In-app Alerts
```
