# State Management Architecture

Divide stores by domain: `useCartStore`, `useAuthStore`, `useUIStore`. Avoid creating a giant single monolithic store.

### Key Concepts & Rules:

- Modular domain stores keep logic cleanly isolated.

### Code Example: Modular Store Architecture

```tsx
src/store/
├── useAuthStore.ts
├── useCartStore.ts
├── useUIStore.ts
└── useCourseProgressStore.ts
```
