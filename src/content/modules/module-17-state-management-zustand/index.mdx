# Module 17: State Management (Zustand)

ស្វែងយល់ពី Zustand State Management, ការបង្កើត Stores, ការអានតម្លៃ State, Actions, Selectors ការពារ Re-render, Persist Middleware, និងស្ថាបត្យកម្មគ្រប់គ្រង State កម្រិត Enterprise។

## Module Syllabus (12 Lessons)

- **Lesson 01**: Client State vs Server State - *ការកំណត់តួនាទីរបស់ Zustand ឱ្យដំណើរការទន្ទឹមគ្នាជាមួយ TanStack Query យ៉ាងស៊ីចង្វាក់។*
- **Lesson 02**: When to Use Context vs Zustand - *ការជ្រើសរើសឧបករណ៍ត្រឹមត្រូវរវាង Context API និង Zustand អាស្រ័យលើទំហំ និងភាពញឹកញាប់នៃការ Update State។*
- **Lesson 03**: Zustand Introduction - *ស្វែងយល់ពី Zustand ដែលជាបណ្ណាល័យគ្រប់គ្រង State ដ៏តូច លឿន និងងាយស្រួលបំផុតសម្រាប់ React។*
- **Lesson 04**: Creating a Store - *ការកំណត់អថេរ State និង Updater Actions នៅខាងក្នុងអនុគមន៍ create() តែមួយ។*
- **Lesson 05**: Reading Store State - *ការទាញយកតម្លៃ State មកប្រើប្រាស់នៅក្នុង Functional Components តាមរយៈ Selector Hook។*
- **Lesson 06**: Selectors & Performance - *ការការពារការ Re-render ដោយឥតប្រយោជន៍តាមរយៈ Fine-grained Selectors នៅក្នុង Zustand។*
- **Lesson 07**: Updating Store State (set & get) - *ការប្រើប្រាស់ set() និង get() សម្រាប់ការផ្លាស់ប្តូរ និងគណនាស្ថានភាព State ដ៏ស្មុគស្មាញ។*
- **Lesson 08**: Persisting State (persist middleware) - *ការរក្សាទុកទិន្នន័យ State ទៅក្នុង localStorage ដោយស្វ័យប្រវត្តិតាមរយៈ persist middleware។*
- **Lesson 09**: Accessing State Outside Components - *ការអាន និងកែប្រែទិន្នន័យ Zustand Store នៅក្រៅ React Components ដូចជាក្នុង Axios Interceptors ឬ Pure Utilities។*
- **Lesson 10**: DevTools Middleware - *ការតភ្ជាប់ Zustand Store ជាមួយ Redux DevTools Extension ក្នុង Browser សម្រាប់ធ្វើ Time-travel Debugging។*
- **Lesson 11**: Zustand + React 19 - *ការគាំទ្រ Concurrent Rendering និងការប្រើប្រាស់ useSyncExternalStore ដើម្បីធានាសុវត្ថិភាព 100% ក្នុង React 18 និង 19។*
- **Lesson 12**: State Management Architecture - *ការរៀបចំរចនាសម្ព័ន្ធ Stores ជាច្រើនទៅតាម Domain មុខងារនៅក្នុងគម្រោងខ្នាតធំ (Large-scale Apps)។*
