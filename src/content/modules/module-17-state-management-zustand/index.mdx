# Module 17: State Management (Zustand)

Zustand introduction, creating stores, reading state, actions, selectors, persist middleware, and enterprise state architecture.

## Module Syllabus (12 Lessons)

- **Lesson 01**: Client State vs Server State - *Defining the role of Zustand alongside TanStack Query.*
- **Lesson 02**: When to Use Context vs Zustand - *Choosing the right tool for state scope and update frequency.*
- **Lesson 03**: Zustand Introduction - *Small, fast, scalable bearbones state management.*
- **Lesson 04**: Creating a Store - *Defining state variables and updater actions inside create().*
- **Lesson 05**: Reading Store State - *Accessing values inside functional components.*
- **Lesson 06**: Selectors & Performance - *Preventing unnecessary renders with fine-grained selectors.*
- **Lesson 07**: Updating Store State (set & get) - *Using set() and get() for complex state transitions.*
- **Lesson 08**: Persisting State (persist middleware) - *Saving store state to localStorage automatically.*
- **Lesson 09**: Accessing State Outside Components - *Reading and writing store data in vanilla JS, API interceptors, and utils.*
- **Lesson 10**: DevTools Middleware - *Integrating with Redux DevTools browser extension.*
- **Lesson 11**: Zustand + React 19 - *Concurrent rendering and useSyncExternalStore integration.*
- **Lesson 12**: State Management Architecture - *Organizing multiple stores in large applications.*
