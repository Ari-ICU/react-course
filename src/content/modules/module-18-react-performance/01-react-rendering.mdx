# React Rendering

នៅក្នុង React ពាក្យថា "Rendering" សំដៅលើដំណើរការដែល React ហៅអនុគមន៍ Component របស់អ្នក ដើម្បីទទួលបាន JSX Elements Tree ថ្មី។ Component មួយនឹង Re-render នៅពេល៖ ១) State របស់វាផ្លាស់ប្តូរ ២) Parent Component របស់វា Re-render ឬ ៣) Context ដែលវា Subscribe មានការកែប្រែតម្លៃ។

### Key Concepts & Rules:

- **Cascade Re-rendering**: នៅពេល Parent Re-render នោះរាល់ Child Components ទាំងអស់នឹង Re-render តាមដោយស្វ័យប្រវត្តិ ទោះបីជា Props របស់វាមិនផ្លាស់ប្តូរក៏ដោយ!
- ការ Render (គណនា Virtual DOM ក្នុង JS) ខុសប្លែកពី DOM Painting (គូរលើ Browser)។ React ធ្វើការ Diffing ហើយ update តែ Real DOM ណាដែលមានការប្រែប្រួលពិតប្រាកដប៉ុណ្ណោះ។
- Re-render ច្រើនដងមិនមែនតែងតែមានន័យថាយឺតនោះទេ ប៉ុន្តែវាអាចបង្កបញ្ហាប្រសិនបើ Child Component នោះមានការគណនាស្មុគស្មាញ។

### Code Example: Default Cascade Re-render Behavior

```jsx
import { useState } from 'react';

export function Parent() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <button onClick={() => setCount(c => c + 1)}>Count: {count}</button>
      {/* ExpensiveChild នឹង Re-render រាល់ពេលចុចប៊ូតុង ទោះបីគ្មាន props ក៏ដោយ! */}
      <ExpensiveChild />
    </div>
  );
}
```
