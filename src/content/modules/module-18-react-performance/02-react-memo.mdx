# React.memo

`React.memo` គឺជា Higher-Order Component (HOC) ដែលប្រើសម្រាប់រុំព័ទ្ធ Component របស់អ្នកដើម្បីធ្វើ Memoization។ ប្រសិនបើ Props ដែលបញ្ជូនមកកាន់ Component នោះមិនមានការផ្លាស់ប្តូរតម្លៃ (Shallow Comparison `Object.is`) React នឹងរំលងការហៅ Render លើ Component នោះទាំងស្រុង ដោយប្រើលទ្ធផល Render ចាស់។

### Key Concepts & Rules:

- ធ្វើការប្រៀបធៀប Props តាមរយៈ Shallow Equality Check (`Object.is`)។
- មិនអាចការពារ Re-render បានឡើយ ប្រសិនបើ Parent បញ្ជូន Object ឬ Function ថ្មីរាល់ render។
- ស័ក្តិសមបំផុតសម្រាប់ Heavy Components ដែលទទួល Props មិនសូវផ្លាស់ប្តូរ។

### Code Example: Memoizing Component with React.memo

```jsx
import React from 'react';

interface TableRowProps {
  item: { id: string; name: string; gpa: number };
}

// រុំជាមួយ React.memo ដើម្បីកុំឱ្យ re-render បើ prop 'item' មិនផ្លាស់ប្តូរ
export const ExpensiveTableRow = React.memo(function TableRow({ item }: TableRowProps) {
  // ការគណនា ឬ Render ស្មុគស្មាញ...
  return (
    <tr>
      <td>{item.name}</td>
      <td>{item.gpa}</td>
    </tr>
  );
});
```
