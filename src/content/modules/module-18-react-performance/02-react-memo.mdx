# React.memo

`React.memo` wraps a component function and memoizes its rendered output. If props are shallowly equal to the previous render, React skips calling the component function entirely.

### Key Concepts & Rules:

- Performs shallow equality check (`Object.is`) on every prop.
- Fails to prevent re-renders if you pass un-memoized object literals or inline functions as props!

### Code Example: Memoizing Component with React.memo

```jsx
import React from 'react';

export const ExpensiveTableRow = React.memo(function TableRow({ item }: { item: Student }) {
  // Only re-renders if 'item' reference changes!
  return <tr><td>{item.name}</td><td>{item.gpa}</td></tr>;
});
```
