# useCallback

នៅក្នុង JavaScript អនុគមន៍គឺជា Object ដូច្នេះរាល់ពេលដែល Component មួយ Re-render អនុគមន៍ដែលសរសេរខាងក្នុងនោះនឹងត្រូវបានបង្កើតជា Instance ថ្មីជានិច្ចក្នុង Memory។ Hook `useCallback` ជួយ Cache Function Definition ឱ្យនៅដដែលឆ្លងកាត់ការ Render ដរាបណា Dependencies មិនផ្លាស់ប្តូរ។

### Key Concepts & Rules:

- `useCallback(fn, deps)` មានសមមូលនឹង `useMemo(() => fn, deps)`។
- សំខាន់បំផុតនៅពេលបញ្ជូន Callback Functions ទៅកាន់ Child Components ដែលត្រូវបានរុំដោយ `React.memo`។
- គ្មានប្រយោជន៍ឡើយ ប្រសិនបើ Child Component មិនមែនជា Memoized Component!

### Code Example: useCallback with Functional Setter

```jsx
import { useState, useCallback } from 'react';

export function StudentManager() {
  const [students, setStudents] = useState<Student[]>([]);

  // រក្សា Function Reference ឱ្យនៅដដែលជាអចិន្ត្រៃយ៍ (empty deps [])
  const handleDelete = useCallback((id: string) => {
    setStudents((prev) => prev.filter((s) => s.id !== id));
  }, []);

  return <MemoizedStudentList onDelete={handleDelete} students={students} />;
}
```
