# Large List Optimization (Virtualization)

When rendering lists of 10,000+ items, creating 10,000 DOM elements crashes browser memory. Virtualization libraries (like `@tanstack/react-virtual`) render only the 15-20 rows currently visible in the scroll viewport.

### Key Concepts & Rules:

- Maintains 60fps scrolling on massive datasets.
- DOM contains only visible elements + small buffer.

### Code Example: Virtual List Concept

```tsx
// Virtualized windowing:
// Total rows: 50,000
// Rendered DOM elements: 20 visible + 5 buffer = 25 nodes total!
```
