# Large List Optimization (Virtualization)

នៅពេលដែលកម្មវិធីត្រូវបង្ហាញបញ្ជីទិន្នន័យរាប់ម៉ឺនជួរដេក (ដូចជា តារាងប្រតិបត្តិការធនាគារ ឬ Logs) ការ Render DOM Node ទាំងអស់ក្នុងពេលតែមួយនឹងធ្វើឱ្យ Browser ស៊ី Memory យ៉ាងខ្លាំង និងគាំង UI។ បច្ចេកទេស **List Virtualization (Windowing)** ដំណើរការដោយគណនា និង Render តែ ២០ ទៅ ៣០ ជួរដេកដែលកំពុងស្ថិតនៅក្នុង Viewport នៃ Scrollbar ប៉ុណ្ណោះ។

### Key Concepts & Rules:

- រក្សាល្បឿន 60 FPS ទោះបីជាមានទិន្នន័យ 100,000+ ជួរដេកក៏ដោយ។
- Real DOM ផ្ទុកតែ Nodes ដែល User មើលឃើញផ្ទាល់ភ្នែក បូកជាមួយ Buffer តូចមួយ។
- បណ្ណាល័យពេញនិយម៖ `@tanstack/react-virtual`, `react-window`។

### Code Example: Virtual List Concept

```jsx
// គោលការណ៍នៃ Virtual Windowing៖
// - ទិន្នន័យសរុបក្នុង JavaScript Array: 50,000 ធាតុ
// - កម្ពស់ Scroll Container សរុប: 2,000,000px (តាមរយៈ spacer div)
// - DOM Nodes ដែលបានបង្កើតពិតប្រាកដក្នុង HTML: ត្រឹមតែ 15 ទៅ 25 nodes ប៉ុណ្ណោះ!
```
