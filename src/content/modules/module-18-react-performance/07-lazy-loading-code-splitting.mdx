# Lazy Loading & Code Splitting

តាមលំនាំដើម Webpack ឬ Turbopack នឹងច្របាច់កូដទាំងអស់ទៅក្នុង Bundle តែមួយ។ នេះមានន័យថា User ត្រូវរង់ចាំទាញយកកូដផ្ទាំងគ្រប់គ្រង Admin, Charts, និង Rich Text Editors ទាំងអស់ ទោះបីពួកគេគ្រាន់តែចង់មើល Landing Page ក៏ដោយ។ **Code Splitting** អនុញ្ញាតឱ្យយើងបំបែក Bundle ទាំងនោះ និងទាញយកតែពេល User ត្រូវការ។

### Key Concepts & Rules:

- ប្រើ `React.lazy(() => import('./Component'))` សម្រាប់ Dynamic Imports។
- រុំព័ទ្ធ Lazy Component នៅក្នុង `<Suspense fallback={<LoadingSpinner />}>`។
- កាត់បន្ថយទំហំ Initial Bundle យ៉ាងច្រើន បង្កើនល្បឿនផ្ទុកទំព័រដំបូង។

### Code Example: On-demand Lazy Component Loading

```jsx
import React, { Suspense, useState } from 'react';

// ទាញយក JavaScript file តែនៅពេល Component នេះត្រូវបង្ហាញ
const HeavyAnalyticsChart = React.lazy(() => import('./HeavyAnalyticsChart'));

export function Dashboard() {
  const [showChart, setShowChart] = useState(false);

  return (
    <div>
      <button onClick={() => setShowChart(true)}>បង្ហាញក្រាហ្វិក</button>
      
      {showChart && (
        <Suspense fallback={<div className="h-64 animate-pulse bg-slate-800 rounded" />}>
          <HeavyAnalyticsChart />
        </Suspense>
      )}
    </div>
  );
}
```
