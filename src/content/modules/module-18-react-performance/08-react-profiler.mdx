# React Profiler

The React Profiler records render duration and flame graphs, showing exactly which component rendered, why it rendered, and how long it took.

### Key Concepts & Rules:

- Use 'Record why each component rendered while profiling' in DevTools settings.

### Code Example: React Profiler API

```jsx
// Use the Profiler component programmatically if needed:
import { Profiler } from 'react';

<Profiler id="CourseTable" onRender={(id, phase, actualDuration) => {
  console.log(`${id} [${phase}] took ${actualDuration}ms`);
}}>
  <CourseTable />
</Profiler>
```
