# Performance Best Practices

ដើម្បីធានាថាកម្មវិធី React របស់អ្នកដំណើរការបានរលូនក្នុងល្បឿន 60 FPS (Frames Per Second) នៅគ្រប់ឧបករណ៍ទាំងអស់ រួមទាំងទូរស័ព្ទកម្លាំងខ្សោយ អ្នកគួរតែអនុវត្តតាមបញ្ជីត្រួតពិនិត្យ (Checklist) ខាងក្រោម៖

### Key Concepts & Rules:

1. **វាស់វែងមុននឹង Optimize**: កុំទាយ! ត្រូវប្រើ Profiler ដើម្បីរកមូលហេតុពិតប្រាកដ។
2. **Colocate State**: ដាក់ State ឱ្យនៅជិតបំផុតទៅនឹងកន្លែងដែលវាត្រូវបានប្រើប្រាស់។
3. **កាត់បន្ថយ Layout Shifts**: ប្រើប្រាស់ Skeleton Placeholders និងកំណត់ទំហំទទឹង/កម្ពស់ជាក់លាក់សម្រាប់រូបភាព។
4. **ធ្វើតេស្តជាមួយ CPU Throttling**: តែងតែបើក 4x/6x CPU Slowdown ក្នុង Chrome DevTools ដើម្បីសាកល្បង។

### Code Example: Performance Golden Rules

```jsx
import React, { useState, ReactNode } from 'react';

// Expensive component tree that shouldn't re-render when user types in search input
function HeavyChartDisplay() {
  console.log('Heavy chart rendered (costly calculation)');
  return <div className="p-4 bg-slate-800 rounded-lg text-slate-300">Detailed Analytics Chart</div>;
}

// Optimization Rule: Move rapid state down into isolated leaf component
function LocalSearchInput() {
  const [query, setQuery] = useState('');
  return (
    <input
      type="text"
      value={query}
      onChange={(e) => setQuery(e.target.value)}
      placeholder="Type here without re-rendering chart..."
      className="px-3 py-1.5 bg-slate-800 border border-slate-700 rounded text-white text-sm"
    />
  );
}

// Optimization Rule: Pass expensive UI as children to avoid re-rendering
export function OptimizedDashboard({ children }: { children?: ReactNode }) {
  return (
    <div className="p-6 bg-slate-900 border border-slate-800 rounded-xl space-y-4">
      {/* 1. State changes inside LocalSearchInput stay inside LocalSearchInput */}
      <LocalSearchInput />

      {/* 2. Heavy content passed as prop/children never re-renders unnecessarily! */}
      {children || <HeavyChartDisplay />}
    </div>
  );
}
```
