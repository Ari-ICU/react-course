# Debouncing and Throttling

Debounce delays execution until silence; Throttle limits execution to at most once per time window.

### Key Concepts & Rules:

- Debounce: Search inputs; Throttle: Window scroll / resize.

### Code Example: Debounced API Handler

```jsx
// Debounced handler:
const debouncedSearch = useMemo(
  () => debounce((val: string) => api.search(val), 300),
  []
);
```
