# Web Vitals in React

Core Web Vitals measure real-world user experience. Cumulative Layout Shift (CLS) is prevented by skeleton dimensions; Interaction to Next Paint (INP) is improved by non-blocking transitions.

### Key Concepts & Rules:

- Use `startTransition` in React 18/19 for non-urgent UI updates.

### Code Example: startTransition for Responsive INP

```jsx
import { startTransition } from 'react';

// Non-urgent update won't block typing input:
startTransition(() => {
  setFilteredResults(heavyCalculation(query));
});
```
