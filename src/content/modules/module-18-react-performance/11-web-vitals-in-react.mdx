# Web Vitals in React

**Core Web Vitals** គឺជាស្តង់ដាររង្វាស់របស់ Google សម្រាប់វាស់ស្ទង់បទពិសោធន៍អ្នកប្រើប្រាស់ពិតប្រាកដ រួមមាន៖ **LCP** (Largest Contentful Paint - ល្បឿនបង្ហាញផ្ទាំងធំជាងគេ), **INP** (Interaction to Next Paint - ភាពរហ័សនៃការឆ្លើយតបពេលចុច), និង **CLS** (Cumulative Layout Shift - ភាពនឹងនរនៃទំព័រមិនរំកិលរញ៉េរញ៉ៃ)។

### Key Concepts & Rules:

- ការពារ **CLS**: កំណត់ Aspect Ratio និងវិមាត្រជាក់លាក់សម្រាប់រូបភាព និងប្រើប្រាស់ Skeleton Loaders។
- កែលម្អ **INP**: ប្រើប្រាស់ `startTransition` ឬ `useDeferredValue` ដើម្បីបំបែកកិច្ចការធ្ងន់ៗកុំឱ្យ Block Main Thread។
- កែលម្អ **LCP**: ធ្វើការ Optimize រូបភាព និងប្រើ Server Components / SSR។

### Code Example: startTransition for Responsive INP

```jsx
import { useState, useTransition } from 'react';

export function SearchFilter() {
  const [input, setInput] = useState('');
  const [results, setResults] = useState([]);
  const [isPending, startTransition] = useTransition();

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    // 1. បន្ទាន់៖ Update input ភ្លាមៗដើម្បីឱ្យ UI មិនគាំងពេលវាយអក្សរ
    setInput(e.target.value);

    // 2. មិនបន្ទាន់៖ ដំណើរការ Filter ធ្ងន់ៗក្នុង Transition
    startTransition(() => {
      setResults(heavyFilteringCalculation(e.target.value));
    });
  };

  return <input value={input} onChange={handleChange} />;
}
```
