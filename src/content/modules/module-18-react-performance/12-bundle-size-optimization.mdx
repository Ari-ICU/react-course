# Bundle Size Optimization

Import specific modules (`import { Check } from 'lucide-react'`) rather than entire library bundles. Use `@next/bundle-analyzer` to inspect production JS sizes.

### Key Concepts & Rules:

- Avoid importing massive monolithic libraries like moment.js.

### Code Example: Tree-shakable Module Imports

```tsx
// ❌ Bad: Imports entire package
// import * as Icons from 'lucide-react';

// ✅ Good: Tree-shakable named imports
import { Check, AlertCircle } from 'lucide-react';
```
