# Module 18: React Performance

យន្តការ React Rendering, ការ Profiling រកមើលបញ្ហា Re-render, React.memo, useMemo, useCallback, ការបង្កើនល្បឿន Large Lists តាមរយៈ Virtualization, Code Splitting, និង React Profiler។

## Module Syllabus (12 Lessons)

- **Lesson 01**: React Rendering - *ស្វែងយល់អំពីមូលហេតុ និងរបៀបដែល React ដំណើរការ Render លើ Components។*
- **Lesson 02**: React.memo - *ការរំលងការ Re-render នៃ Component ប្រសិនបើ Props មិនមានការផ្លាស់ប្តូរ (Shallow Equality)។*
- **Lesson 03**: useMemo - *ការ Cache លទ្ធផលនៃការគណនាដែលចំណាយកម្លាំងម៉ាស៊ីនច្រើន (Expensive Calculations)។*
- **Lesson 04**: useCallback - *ការ Cache អនុគមន៍ (Function Definitions) កុំឱ្យបង្កើតថ្មីរាល់ពេល Re-render។*
- **Lesson 05**: Preventing Unnecessary Renders - *បច្ចេកទេសស្ថាបត្យកម្មក្នុងការលុបបំបាត់ Re-render ដោយមិនចាំបាច់ប្រើ useMemo ឬ React.memo។*
- **Lesson 06**: Large List Optimization (Virtualization) - *ការបង្កើនល្បឿនបញ្ជីទិន្នន័យធំៗដោយ Render តែជួរដេក (Rows) ណាដែលកំពុងមើលឃើញលើអេក្រង់ប៉ុណ្ណោះ។*
- **Lesson 07**: Lazy Loading & Code Splitting - *ការបំបែក JavaScript Bundle ជាចំណែកតូចៗ និងទាញយកតែពេលត្រូវការ (On-demand) ដោយប្រើ React.lazy និង Suspense។*
- **Lesson 08**: React Profiler - *ការស្វែងរកចំណុចដែលដំណើរការយឺត (Slow Renders) តាមរយៈ React DevTools Profiler។*
- **Lesson 09**: Performance Best Practices - *គោលការណ៍ណែនាំ និងបញ្ជីត្រួតពិនិត្យ (Checklist) ដើម្បីរក្សា Frame Rate កម្រិត 60 FPS ក្នុងកម្មវិធី React។*
- **Lesson 10**: Debouncing and Throttling - *ការគ្រប់គ្រង និងកម្រិតភាពញឹកញាប់នៃការបញ្ឆេះ Events ដូចជា Search Input ឬ Window Scroll។*
- **Lesson 11**: Web Vitals in React - *ការវាស់វែង និងកែលម្អសូចនាករ Core Web Vitals (LCP, FID/INP, CLS) ក្នុងកម្មវិធី React។*
- **Lesson 12**: Bundle Size Optimization - *ការកាត់បន្ថយទំហំ JavaScript Bundle តាមរយៈ Tree-shaking និងការវិភាគ Bundle Chunks។*
