# Module 18: React Performance

React rendering mechanics, re-render profiling, React.memo, useMemo, useCallback, large list virtualization, code splitting, and React Profiler.

## Module Syllabus (12 Lessons)

- **Lesson 01**: React Rendering - *How and why React renders components.*
- **Lesson 02**: React.memo - *Skipping component re-renders when props are shallowly equal.*
- **Lesson 03**: useMemo - *Caching the result of expensive calculations.*
- **Lesson 04**: useCallback - *Caching function definitions between renders.*
- **Lesson 05**: Preventing Unnecessary Renders - *Architectural techniques that eliminate the need for memoization.*
- **Lesson 06**: Large List Optimization (Virtualization) - *Rendering only visible DOM rows using virtual windowing.*
- **Lesson 07**: Lazy Loading & Code Splitting - *Splitting bundle into on-demand chunks with React.lazy and Suspense.*
- **Lesson 08**: React Profiler - *Identifying slow renders and commit timelines in React DevTools.*
- **Lesson 09**: Performance Best Practices - *Checklist for maintaining 60fps React applications.*
- **Lesson 10**: Debouncing and Throttling - *Controlling high-frequency event execution.*
- **Lesson 11**: Web Vitals in React - *LCP, FID/INP, and CLS metrics.*
- **Lesson 12**: Bundle Size Optimization - *Analyzing bundle chunks and tree-shaking.*
