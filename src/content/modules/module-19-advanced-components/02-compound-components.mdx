# Compound Components

**Compound Components Pattern** គឺជាគំរូរចនាដ៏ពេញនិយមមួយដែលអនុញ្ញាតឱ្យ Components តូចៗជាច្រើនធ្វើការរួមគ្នាជាឯកភាពមួយ (ដូចជា `<select>` និង `<option>` ក្នុង HTML)។ ឧទាហរណ៍ជាក់ស្តែងគឺ `<Tabs>`, `<TabsList>`, `<TabsTrigger>`, និង `<TabsContent>` ដែលអាចចែករំលែក State ខាងក្នុង (Active Tab) ដោយស្វ័យប្រវត្តិតាមរយៈ React Context។

### Key Concepts & Rules:

- ផ្តល់នូវភាពបត់បែនខ្ពស់លើការរៀបចំ Layout និង Markup ដោយមិនកំណត់ទីតាំងស្លាក។
- លុបបំបាត់ការបញ្ជូន Props (Prop Drilling) ដ៏ស្មុគស្មាញរវាង Parent និង Children។
- ធ្វើឱ្យ API នៃ Component មានលក្ខណៈ Declarative និងងាយយល់ដូច native HTML។

### Code Example: Compound Component Pattern Usage

```jsx
// របៀបប្រើប្រាស់ Compound Tabs Component ដ៏ស្រស់ស្អាត និងបត់បែន៖
export function CourseTabs() {
  return (
    <Tabs defaultValue="overview">
      <TabsList>
        <TabsTrigger value="overview">សេចក្តីសង្ខេប</TabsTrigger>
        <TabsTrigger value="curriculum">មាតិកាមេរៀន</TabsTrigger>
        <TabsTrigger value="reviews">ការវាយតម្លៃ</TabsTrigger>
      </TabsList>

      <TabsContent value="overview">
        <p>ព័ត៌មានលម្អិតអំពីវគ្គសិក្សា React Masterclass...</p>
      </TabsContent>

      <TabsContent value="curriculum">
        <p>បញ្ជីមេរៀនទាំងអស់ចំនួន ២៧ ម៉ូឌុល...</p>
      </TabsContent>
    </Tabs>
  );
}
```
