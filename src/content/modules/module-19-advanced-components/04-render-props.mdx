# Render Props

**Render Prop** គឺជាបច្ចេកទេសមួយដែល Component មួយទទួលយកអនុគមន៍ (Function) មួយតាមរយៈ Prop (ឬជា Children) ដែលអនុគមន៍នោះ return នូវ React Element។ Component នឹងហៅអនុគមន៍នោះដោយបញ្ជូនទិន្នន័យ State ខាងក្នុងទៅឱ្យ ដែលអនុញ្ញាតឱ្យ Consumer មានសិទ្ធិសម្រេចចិត្តលើទម្រង់ UI ដែលត្រូវ Render។

### Key Concepts & Rules:

- Syntax: `<Component render={(data) => <UI data={data} />} />` ឬ `<Component>{(data) => <UI />}</Component>`។
- អនុញ្ញាតឱ្យបំបែក Data/Behavior Logic ចេញពី Presentation UI។
- នៅតែពេញនិយមខ្លាំងក្នុង Virtualized Lists និង Form Libraries (ដូចជា Formik/Downshift)។

### Code Example: Render Props Pattern

```jsx
import React, { useState } from 'react';

interface MouseTrackerProps {
  render: (pos: { x: number; y: number }) => React.ReactNode;
}

export function MouseTracker({ render }: MouseTrackerProps) {
  const [pos, setPos] = useState({ x: 0, y: 0 });

  return (
    <div 
      className="h-64 border border-dashed rounded p-4"
      onMouseMove={(e) => setPos({ x: e.clientX, y: e.clientY })}
    >
      {/* ហៅអនុគមន៍ render ដោយបញ្ជូន State ទៅឱ្យ Consumer */}
      {render(pos)}
    </div>
  );
}

// ការប្រើប្រាស់៖
// <MouseTracker render={({ x, y }) => <p>កូអរដោនេកណ្ដុរ៖ X: {x}, Y: {y}</p>} />
```
