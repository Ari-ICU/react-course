# Tabs Component

ការបង្កើត Tabs Component មិនត្រឹមតែជាការផ្លាស់ប្តូរ CSS ប៉ុណ្ណោះទេ ប៉ុន្តែត្រូវគោរពតាមស្តង់ដារ Accessibility (A11y)។ នេះរួមបញ្ចូលទាំងការកំណត់ ARIA Roles ឱ្យបានត្រឹមត្រូវ និងការគាំទ្រការផ្លាស់ប្តូរ Tab តាមរយៈគ្រាប់ចុចសញ្ញាព្រួញនៅលើ Keyboard។

### Key Concepts & Rules:

- **`role="tablist"`**: ដាក់លើ Wrapper នៃប៊ូតុង Tabs ទាំងអស់។
- **`role="tab"`**: ដាក់លើប៊ូតុង Tab នីមួយៗ រួមជាមួយ `aria-selected={isActive}`។
- **`role="tabpanel"`**: ដាក់លើផ្ទាំង Content ដែលត្រូវគ្នានឹង Tab នោះ។

### Code Example: Accessible Tab ARIA Attributes

```jsx
export function AccessibleTabs({ active, onSelect }: { active: string; onSelect: (id: string) => void }) {
  return (
    <div>
      <div role="tablist" aria-label="ការកំណត់គណនី" className="flex border-b border-slate-800">
        <button
          role="tab"
          id="tab-profile"
          aria-selected={active === 'profile'}
          aria-controls="panel-profile"
          onClick={() => onSelect('profile')}
          className={`px-4 py-2 text-sm font-semibold ${active === 'profile' ? 'text-blue-500 border-b-2 border-blue-500' : 'text-slate-400'}`}
        >
          ប្រវត្តិរូប
        </button>
      </div>
      
      <div role="tabpanel" id="panel-profile" aria-labelledby="tab-profile" hidden={active !== 'profile'} className="p-4">
        មាតិកានៃទំព័រប្រវត្តិរូប...
      </div>
    </div>
  );
}
```
