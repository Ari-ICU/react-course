# Tabs Component

Complies with accessibility standards: `role="tablist"`, `role="tab"`, `aria-selected`, and arrow key tab switching.

### Key Concepts & Rules:

- Keyboard left/right arrows switch active tab.

### Code Example: Accessible Tab ARIA Attributes

```jsx
<div role="tablist" className="flex border-b border-slate-800">
  <button role="tab" aria-selected={active === 'code'} onClick={() => setActive('code')}>
    Code
  </button>
</div>
```
