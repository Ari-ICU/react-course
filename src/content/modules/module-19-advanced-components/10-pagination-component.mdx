# Pagination Component

Displays `1, 2, ... 9, 10` pagination links and handles boundary clamping.

### Key Concepts & Rules:

- Calculates total pages from `totalItems` and `pageSize`.

### Code Example: Pagination Component

```tsx
export function Pagination({ current, total, onChange }: PaginationProps) {
  return (
    <div className="flex items-center gap-2">
      <button disabled={current <= 1} onClick={() => onChange(current - 1)}>Prev</button>
      <span>Page {current} of {total}</span>
      <button disabled={current >= total} onClick={() => onChange(current + 1)}>Next</button>
    </div>
  );
}
```
