# Toast Notification System

Display non-intrusive feedback toasts (Success, Error, Info) that stack and auto-dismiss after 4 seconds.

### Key Concepts & Rules:

- Managed via Zustand store or React Sonner.

### Code Example: Triggering Toasts

```tsx
toast.success('Project 01 completed successfully!');
```
