# Advanced Component Patterns

**Polymorphic Components** អនុញ្ញាតឱ្យ Component មួយអាច Render ខ្លួនឯងទៅជា HTML Elements ខុសៗគ្នា (ដូចជា Render ជា `<button>`, `<a>`, ឬ Next.js `<Link>`) ដោយប្រើប្រាស់ prop ឈ្មោះ `as` ឬ `asChild` (ពី Radix UI Slot) ខណៈពេលដែលរក្សានូវ Styling, Variants, និង Type Safety ទាំងអស់ដូចគ្នា។

### Key Concepts & Rules:

- **`as` prop**: អនុញ្ញាតឱ្យអ្នកប្រើប្រាស់ប្តូរ Tag ដូចជា `<Button as="a" href="...">`។
- **`asChild` pattern (Slot)**: បញ្ចូល Props និង ClassNames ចូលទៅក្នុង Child Element ផ្ទាល់ដោយមិនបង្កើត DOM Node បន្ថែម។
- ជួយជៀសវាងបញ្ហា Nested Interactive Elements (ដូចជាការដាក់ `<a>` នៅខាងក្នុង `<button>` ដែលជាកំហុស Invalid HTML)។

### Code Example: Polymorphic Component Concept

```jsx
import React, { ElementType, ComponentPropsWithoutRef } from 'react';

// Polymorphic component prop types supporting dynamic 'as' prop
type PolymorphicButtonProps<E extends ElementType> = {
  as?: E;
  children: React.ReactNode;
} & ComponentPropsWithoutRef<E>;

export function PolymorphicButton<E extends ElementType = 'button'>({
  as,
  children,
  className = '',
  ...restProps
}: PolymorphicButtonProps<E>) {
  // Dynamic tag creation: defaults to <button>, but can render as <a> or custom link
  const Component = as || 'button';

  return (
    <Component
      className={`px-4 py-2 bg-blue-600 hover:bg-blue-700 text-white rounded-lg text-sm font-semibold transition-colors ${className}`}
      {...restProps}
    >
      {children}
    </Component>
  );
}

// Usage examples:
export function PolymorphicDemo() {
  return (
    <div className="flex gap-3">
      {/* 1. Renders as native <button> */}
      <PolymorphicButton onClick={() => alert('Clicked!')}>
        Native Button
      </PolymorphicButton>

      {/* 2. Renders as HTML <a> tag with href, retaining identical styles! */}
      <PolymorphicButton as="a" href="https://react.dev" target="_blank">
        External Link
      </PolymorphicButton>
    </div>
  );
}
```
