# Module 19: Advanced Components

Reusable UI component architecture, compound components, render props, headless components, modal dialogs, dropdowns, and data tables.

## Module Syllabus (12 Lessons)

- **Lesson 01**: Reusable UI Components - *Designing enterprise component libraries inspired by Shadcn UI and Radix.*
- **Lesson 02**: Compound Components - *Flexible multi-part component APIs that share implicit state.*
- **Lesson 03**: Implementing Compound Components - *Building internal context and sub-component exports.*
- **Lesson 04**: Render Props - *Sharing rendering logic by passing a function as children.*
- **Lesson 05**: Headless Components - *Unstyled accessible logic components.*
- **Lesson 06**: Modal / Dialog Component - *Portals, backdrop blur, focus trapping, and Esc key dismissal.*
- **Lesson 07**: Dropdown Menu Component - *Click outside dismissal and keyboard arrow navigation.*
- **Lesson 08**: Tabs Component - *Accessible tablist, tab, and tabpanel ARIA semantics.*
- **Lesson 09**: Data Table Component - *Reusable data tables with sorting, filtering, and selection.*
- **Lesson 10**: Pagination Component - *Page numbers, ellipses, previous/next controls, and page size.*
- **Lesson 11**: Toast Notification System - *Global toast notifications queue with auto-dismissal.*
- **Lesson 12**: Advanced Component Patterns - *Polymorphic components with the `as` prop.*
