# Module 19: Advanced Components

ស្ថាបត្យកម្ម Reusable UI Component កម្រិត Enterprise, Compound Components, Render Props, Headless Components, Modals, Dropdowns, Data Tables, និង Polymorphic Components។

## Module Syllabus (12 Lessons)

- **Lesson 01**: Reusable UI Components - *ការរចនា និងបង្កើត Component Library កម្រិត Enterprise ដោយយកលំនាំតាម Shadcn UI និង Radix UI។*
- **Lesson 02**: Compound Components - *ការបង្កើត Component APIs ដែលមានច្រើនផ្នែកតូចៗធ្វើការរួមគ្នា និងចែករំលែក State ដោយស្វ័យប្រវត្តិ (Implicit State)។*
- **Lesson 03**: Implementing Compound Components - *ការបង្កើត Internal React Context ដើម្បីភ្ជាប់ទំនាក់ទំនងរវាង Parent Container និង Sub-components។*
- **Lesson 04**: Render Props - *ការចែករំលែក State និង Logic តាមរយៈការបញ្ជូនអនុគមន៍ជា Prop ឬ Children (Function as a Child)។*
- **Lesson 05**: Headless Components - *ការស្វែងយល់ពី Headless UI (Radix UI, Headless UI) ដែលផ្តោតលើ Logic, Accessibility (A11y), និង Keyboard Navigation ដោយគ្មាន CSS។*
- **Lesson 06**: Modal / Dialog Component - *ការបង្កើតផ្ទាំង Modal Dialog ពេញលេញជាមួយ React Portal, Backdrop Blur, Focus Trapping, និងការចុចបិទដោយគ្រាប់ចុច Esc។*
- **Lesson 07**: Dropdown Menu Component - *ការបង្កើត Menu Dropdown ដែលអាចចុចបិទដោយស្វ័យប្រវត្តិតាមរយៈ Click Outside និងគាំទ្រ Keyboard Navigation។*
- **Lesson 08**: Tabs Component - *ការបង្កើតផ្ទាំង Tabs ស្របតាមស្តង់ដារ Accessibility ARIA (tablist, tab, tabpanel)។*
- **Lesson 09**: Data Table Component - *ការរចនា Reusable Data Table Component ជាមួយ TypeScript Generics, Dynamic Columns, Sorting, និង Custom Cell Rendering។*
- **Lesson 10**: Pagination Component - *ការបង្កើត Component ប្តូរទំព័រ (Pagination) រួមមានលេខទំព័រ សញ្ញាចុចៗ (...) និងប៊ូតុង Prev/Next។*
- **Lesson 11**: Toast Notification System - *ការបង្កើតប្រព័ន្ធសារជូនដំណឹង (Toast Queue) សកល ដែលអាចបាត់ទៅវិញដោយស្វ័យប្រវត្តិ (Auto-dismiss)។*
- **Lesson 12**: Advanced Component Patterns - *ការស្វែងយល់ពី Polymorphic Components (as prop) និង asChild Pattern ដ៏ពេញនិយមក្នុង Radix UI។*
