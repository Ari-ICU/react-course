# Authentication Concepts

Authentication proves WHO you are (e.g. valid credentials). Authorization determines WHAT you are permitted to do (e.g. Admin vs Student roles).

### Key Concepts & Rules:

- JWT: JSON Web Token containing cryptographically signed user claims.
- Sessions: Stateful server-side session IDs stored in database.

### Code Example: JWT Token Structure

```jsx
// JWT Structure: header.payload.signature
// Decoded payload contains: { sub: "u123", role: "admin", exp: 1735689600 }
```
