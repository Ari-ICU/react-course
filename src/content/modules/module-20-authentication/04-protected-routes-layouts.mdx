# Protected Routes & Layouts

Gate entire layout route trees so that unauthenticated visitors are automatically forwarded to `/login`.

### Key Concepts & Rules:

- Redirect preserves intended destination URL.

### Code Example: Protected Layout Route

```jsx
export function ProtectedLayout() {
  const { isAuthenticated, isLoading } = useAuth();
  if (isLoading) return <LoadingScreen />;
  if (!isAuthenticated) return <Navigate to="/login" replace />;
  return <Outlet />;
}
```
