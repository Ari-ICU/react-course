# Protected Routes & Layouts

នៅក្នុង Single Page Application ទំព័រមួយចំនួនដូចជា Dashboard, Profile, ឬ Settings ត្រូវតែការពារមិនឱ្យអ្នកដែលមិនទាន់ Login អាចចូលមើលបានឡើយ។ ការប្រើប្រាស់ **Protected Route Layout** ជាមួយ React Router អនុញ្ញាតឱ្យយើងត្រួតពិនិត្យ Auth State នៅកន្លែងតែមួយ និង Redirect ពួកគេទៅកាន់ `/login` ប្រសិនបើគ្មានសិទ្ធិ។

### Key Concepts & Rules:

- បង្ហាញ Loading Spinner ដរាបណា `isLoading` នៅជា `true` (កំពុងផ្ទៀងផ្ទាត់ Session ដំបូង)។
- ប្រើ `<Navigate to="/login" state={{ from: location }} replace />` ដើម្បីបញ្ជូនទៅកាន់ទំព័រចូល។
- ប្រើ `<Outlet />` ដើម្បី Render ទំព័រកូនចៅទាំងអស់នៅពេលដែល Auth State ត្រឹមត្រូវ។

### Code Example: Protected Layout Route

```jsx
import { Navigate, Outlet, useLocation } from 'react-router-dom';
import { useAuth } from '@/features/auth/hooks/useAuth';

export function ProtectedLayout() {
  const { isAuthenticated, isLoading } = useAuth();
  const location = useLocation();

  // 1. កំពុងផ្ទៀងផ្ទាត់ Session ដំបូង
  if (isLoading) {
    return <div className="flex h-screen items-center justify-center">កំពុងផ្ទៀងផ្ទាត់...</div>;
  }

  // 2. បើមិនទាន់ Login បញ្ជូនទៅកាន់ /login ព្រមទាំងភ្ជាប់ location ដើម
  if (!isAuthenticated) {
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  // 3. បើ Login រួចហើយ អនុញ្ញាតឱ្យចូលមើលទំព័រខាងក្នុង
  return <Outlet />;
}
```
