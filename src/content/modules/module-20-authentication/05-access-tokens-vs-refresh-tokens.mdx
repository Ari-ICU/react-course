# Access Tokens vs Refresh Tokens

Access tokens expire quickly to minimize the window of vulnerability if intercepted. The refresh token requests a new access token seamlessly without forcing the user to log in again.

### Key Concepts & Rules:

- Access token: Sent in `Authorization: Bearer <token>` header.
- Refresh token: Sent to `/auth/refresh` endpoint.

### Code Example: Token Rotation Lifecycle

```jsx
// Token Lifecycle:
// 1. User logs in -> Receives Access Token (15m) + Refresh Token (7d)
// 2. Access Token expires -> App calls /refresh -> Receives new Access Token
// 3. User remains logged in seamlessly!
```
