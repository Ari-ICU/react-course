# HttpOnly Cookies

HttpOnly cookies cannot be read by JavaScript `document.cookie`. This prevents cross-site scripting (XSS) attacks from stealing authentication sessions.

### Key Concepts & Rules:

- Browser sends cookie automatically with `credentials: 'include'`.
- Requires CORS configuration with `withCredentials: true`.

### Code Example: Configuring Axios for HttpOnly Cookies

```jsx
// Axios configuration for HttpOnly cookie sessions:
export const apiClient = axios.create({
  baseURL: '/api',
  withCredentials: true, // Sends and receives secure cookies!
});
```
