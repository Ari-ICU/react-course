# HttpOnly Cookies

**HttpOnly Cookie** គឺជាទម្រង់ Cookie ពិសេសដែលត្រូវបានកំណត់ដោយ Server តាមរយៈ Header `Set-Cookie: ...; HttpOnly; Secure; SameSite=Strict`។ លក្ខណៈពិសេសរបស់វាគឺ JavaScript ក្នុង Browser មិនអាចអានតម្លៃតាមរយៈ `document.cookie` បានឡើយ ដែលជាខែលការពារដ៏រឹងមាំបំផុតប្រឆាំងនឹង Cross-Site Scripting (XSS)។

### Key Concepts & Rules:

- Browser នឹងភ្ជាប់ Cookie នេះទៅកាន់ Server ដោយស្វ័យប្រវត្តិនូវរាល់ Request។
- តម្រូវឱ្យបើក CORS Configuration: `credentials: 'include'` ឬ `withCredentials: true`។
- ត្រូវកំណត់ `SameSite=Lax` ឬ `SameSite=Strict` ដើម្បីការពារការវាយប្រហារ CSRF។

### Code Example: Configuring Axios for HttpOnly Cookies

```jsx
import axios from 'axios';

// ការកំណត់រចនាសម្ព័ន្ធ Axios សម្រាប់ទទួល និងផ្ញើ Secure Cookies៖
export const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
  withCredentials: true, // ផ្ញើ Secure Cookies ទៅកាន់ Server គ្រប់ Request
  headers: {
    'Content-Type': 'application/json',
  },
});
```
