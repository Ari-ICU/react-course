# Handling 401 Unauthorized

នៅពេលដែល Access Token ផុតកំណត់ Server នឹងឆ្លើយតបមកវិញនូវ Status Code `401 Unauthorized`។ តាមរយៈការរៀបចំ **Axios Response Interceptor** យើងអាចស្ទាក់ចាប់កំហុសនេះ រួចហៅ API សុំ Token ថ្មីដោយស្ងាត់ៗ ហើយបញ្ជូន Request ដើមដែលបរាជ័យនោះឡើងវិញ (Retry Request) ដោយ User មិនបាច់ដឹងខ្លួនឡើយ។

### Key Concepts & Rules:

- ពិនិត្យលក្ខខណ្ឌ `error.response?.status === 401` និង `!originalRequest._retry`។
- ដាក់ទង់ `originalRequest._retry = true` ដើម្បីការពារ Infinite Loop។
- ប្រសិនបើ Refresh Token ក៏ផុតកំណត់ដែរ ត្រូវធ្វើការ Logout និង Redirect ទៅកាន់ទំព័រ Login។

### Code Example: Automatic 401 Token Refresh Interceptor

```jsx
import { apiClient } from '@/lib/apiClient';
import { refreshAccessToken, logoutUser } from '@/features/auth/services/authService';

apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;

    // ប្រសិនបើ Error 401 ហើយមិនទាន់បានព្យាយាម Retry
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;

      try {
        // 1. ស្នើសុំ Access Token ថ្មីពី Server
        const newAccessToken = await refreshAccessToken();
        
        // 2. ដាក់ Token ថ្មីចូលទៅក្នុង Header នៃ Request ដើម
        originalRequest.headers.Authorization = `Bearer ${newAccessToken}`;
        
        // 3. ហៅ Request ដើមម្តងទៀតដោយជោគជ័យ
        return apiClient(originalRequest);
      } catch (refreshError) {
        // បើ Refresh បរាជ័យ បង្ខំឱ្យ Logout ភ្លាម
        logoutUser();
        window.location.href = '/login?session_expired=true';
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }
);
```
