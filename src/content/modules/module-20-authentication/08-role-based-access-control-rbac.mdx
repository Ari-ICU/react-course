# Role-Based Access Control (RBAC)

Hide or disable actions (like Delete, Edit, or Admin Dashboard) based on whether `user.role === 'admin'`.

### Key Concepts & Rules:

- Always enforce authorization on the backend; frontend RBAC is solely for UX!

### Code Example: Declarative RoleGate Component

```tsx
export function RoleGate({ allowedRoles, children }: { allowedRoles: string[]; children: React.ReactNode }) {
  const { user } = useAuth();
  if (!user || !allowedRoles.includes(user.role)) return null;
  return <>{children}</>;
}
```
