# Secure Logout

ដំណើរការ Logout ប្រកបដោយសុវត្ថិភាពមិនមែនត្រឹមតែជាការលុប State ក្នុង Browser ប៉ុណ្ណោះទេ។ វាទាមទារឱ្យមានការជូនដំណឹងទៅកាន់ Backend Server ដើម្បី Revoke/Blacklist Refresh Token, សម្អាត Storage ក្នុង Client, សម្អាត TanStack Query Cache, និងប្តូរទិសដៅទៅកាន់ទំព័រ Login។

### Key Concepts & Rules:

- ហៅ API `POST /api/auth/logout` ដើម្បីឱ្យ Server លុប Session ឬ Refresh Cookie ចោល។
- ហៅ `queryClient.clear()` ដើម្បីសម្អាតរាល់ទិន្នន័យសម្ងាត់ទាំងអស់ក្នុង RAM Cache។
- Reset Zustand Auth Store ឱ្យមកសភាពដើម (`user: null`, `token: null`)។

### Code Example: Complete Secure Logout Sequence

```jsx
import { apiClient } from '@/lib/apiClient';
import { queryClient } from '@/lib/queryClient';
import { useAuthStore } from '@/features/auth/store/useAuthStore';

export async function secureLogout() {
  try {
    // 1. បញ្ជូនសញ្ញាទៅ Backend ដើម្បី Revoke Refresh Token & សម្អាត Cookie
    await apiClient.post('/auth/logout');
  } catch (error) {
    console.warn('Logout API error, clearing local state anyway:', error);
  } finally {
    // 2. សម្អាតរាល់ Cached Queries ក្នុង TanStack Query (ការពារការធ្លាយទិន្នន័យ)
    queryClient.clear();

    // 3. Reset Local Auth Store
    useAuthStore.getState().clearAuth();

    // 4. បញ្ជូន User ទៅកាន់ទំព័រ Login
    window.location.href = '/login';
  }
}
```
