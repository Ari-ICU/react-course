# Authentication Architecture

Colocate auth services, tokens, guards, and context into a dedicated `@/features/auth` slice.

### Key Concepts & Rules:

- Clean encapsulation of security concerns.

### Code Example: Auth Feature Directory Layout

```tsx
features/auth/
├── components/LoginForm.tsx, RoleGate.tsx
├── hooks/useAuth.ts
├── services/authService.ts
└── store/useAuthStore.ts
```
