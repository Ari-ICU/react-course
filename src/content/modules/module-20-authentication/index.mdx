# Module 20: Authentication

JWT tokens, refresh tokens, HttpOnly cookies, protected routes, role-based access control (RBAC), and 401 interceptors.

## Module Syllabus (10 Lessons)

- **Lesson 01**: Authentication Concepts - *Authentication vs authorization, sessions vs JWT tokens.*
- **Lesson 02**: Login & Register UI - *Form design, password visibility toggles, and validation.*
- **Lesson 03**: Authentication State - *Managing current session, user profile, and token in memory.*
- **Lesson 04**: Protected Routes & Layouts - *Preventing unauthorized access to private pages.*
- **Lesson 05**: Access Tokens vs Refresh Tokens - *Short-lived access tokens (15m) + long-lived refresh tokens (7d).*
- **Lesson 06**: HttpOnly Cookies - *The most secure storage mechanism against XSS attacks.*
- **Lesson 07**: Handling 401 Unauthorized - *Automatic token refresh queue with Axios interceptors.*
- **Lesson 08**: Role-Based Access Control (RBAC) - *Restricting UI elements based on user roles.*
- **Lesson 09**: Secure Logout - *Clearing tokens and invalidating server sessions.*
- **Lesson 10**: Authentication Architecture - *Enterprise auth structure across hooks, stores, and interceptors.*
