# Form Registration ({...register})

`register('name')` returns `onChange`, `onBlur`, `ref`, and `name` attributes to spread onto the input.

### Key Concepts & Rules:

- No manual `value` or `onChange` state wiring required.

### Code Example: Input Registration and Error Display

```jsx
<div>
  <label className="block text-sm font-medium text-slate-300">Full Name</label>
  <input 
    {...register('name')} 
    className="w-full bg-slate-900 border border-slate-800 p-2 rounded text-white" 
  />
  {errors.name && <p className="text-xs text-rose-400 mt-1">{errors.name.message}</p>}
</div>
```
