# Dynamic Form Arrays (useFieldArray)

នៅក្នុងទម្រង់បែបបទស្មុគស្មាញ (ដូចជា ការបង្កើតវិក្កយបត្រ Invoice ដែលមានទំនិញច្រើនមុខ ឬការបញ្ចូលលេខទូរស័ព្ទច្រើនខ្សែ) ចំនួន Inputs មិនថេរនោះទេ។ Hook `useFieldArray` ផ្តល់នូវអនុគមន៍ជំនួយជាច្រើនដូចជា `append()`, `remove()`, `insert()`, និង `move()` សម្រាប់គ្រប់គ្រង Dynamic Array Fields យ៉ាងមានប្រសិទ្ធភាព។

### Key Concepts & Rules:

- ភ្ជាប់ជាមួយ `control` ពី `useForm()` និងបញ្ជាក់ `name` នៃ Array Property។
- ត្រូវតែប្រើ `key={field.id}` ជានិច្ចនៅពេល render បញ្ជីជួរដេក។
- ចុះឈ្មោះ Field តាមរយៈ Template Literal៖ `register(\`items.\${index}.name\`)`។

### Code Example: Dynamic Inputs with useFieldArray

```jsx
import { useForm, useFieldArray } from 'react-hook-form';

export function InvoiceForm() {
  const { register, control, handleSubmit } = useForm();
  
  const { fields, append, remove } = useFieldArray({
    control,
    name: 'items',
  });

  return (
    <div className="space-y-3">
      {fields.map((field, index) => (
        <div key={field.id} className="flex gap-2 items-center">
          <input 
            {...register(`items.${index}.description`)} 
            placeholder="ឈ្មោះទំនិញ" 
            className="bg-slate-900 border border-slate-700 p-2 rounded"
          />
          <input 
            type="number"
            {...register(`items.${index}.price`)} 
            placeholder="តម្លៃ" 
            className="w-24 bg-slate-900 border border-slate-700 p-2 rounded"
          />
          <button 
            type="button" 
            onClick={() => remove(index)}
            className="text-red-400 hover:text-red-300"
          >
            លុប
          </button>
        </div>
      ))}

      <button 
        type="button" 
        onClick={() => append({ description: '', price: 0 })}
        className="px-3 py-1.5 bg-slate-800 hover:bg-slate-700 text-white rounded text-sm"
      >
        + បន្ថែមទំនិញ
      </button>
    </div>
  );
}
```
