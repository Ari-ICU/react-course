# Module 21: Forms & Validation (RHF + Zod)

React Hook Form, form registration, submission, Zod schema validation, resolvers, custom error messages, dynamic fields, and multi-step forms.

## Module Syllabus (7 Lessons)

- **Lesson 01**: Advanced React Forms - *Why uncontrolled forms with React Hook Form outperform controlled forms.*
- **Lesson 02**: Zod Schema Definition - *Declaring type-safe runtime validation schemas.*
- **Lesson 03**: React Hook Form + Zod Resolver - *Connecting Zod schemas to useForm.*
- **Lesson 04**: Form Registration ({...register}) - *Connecting native inputs to React Hook Form.*
- **Lesson 05**: Dynamic Form Arrays (useFieldArray) - *Adding and removing items dynamically (e.g. invoice line items).*
- **Lesson 06**: Multi-Step Form Wizard - *Building multi-page registration pipelines with step validation.*
- **Lesson 07**: Reusable RHF Field Components - *Integrating RHF with custom design system UI primitives.*
