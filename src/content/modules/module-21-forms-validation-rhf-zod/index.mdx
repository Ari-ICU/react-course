# Module 21: Forms & Validation (RHF + Zod)

ស្វែងយល់ពី React Hook Form, ការចុះឈ្មោះ Inputs (register), ការផ្ទៀងផ្ទាត់ទិន្នន័យជាមួយ Zod Schema Validation, resolvers, Dynamic Fields (useFieldArray), និង Multi-step Form Wizard។

## Module Syllabus (7 Lessons)

- **Lesson 01**: Advanced React Forms - *មូលហេតុដែល Uncontrolled Forms ជាមួយ React Hook Form មានល្បឿនលឿនជាង Controlled Forms ធម្មតា។*
- **Lesson 02**: Zod Schema Definition - *ការប្រកាស Type-safe Runtime Validation Schema ជាមួយបណ្ណាល័យ Zod និងការទាញយក Type ដោយស្វ័យប្រវត្តិតាមរយៈ z.infer។*
- **Lesson 03**: React Hook Form + Zod Resolver - *ការតភ្ជាប់ Zod Validation Schema ជាមួយ Hook useForm តាមរយៈ zodResolver។*
- **Lesson 04**: Form Registration ({...register}) - *ការភ្ជាប់ Native Input Elements ទៅកាន់ React Hook Form តាមរយៈ {...register('fieldName')}។*
- **Lesson 05**: Dynamic Form Arrays (useFieldArray) - *ការគ្រប់គ្រងបញ្ជី Input ដែលអាចបន្ថែម និងលុបបានតាមចិត្ត (Dynamic Fields) ដូចជា Invoice Items ឬ Phone Numbers តាមរយៈ useFieldArray។*
- **Lesson 06**: Multi-Step Form Wizard - *ការបែងចែក Form វែងៗជាដំណាក់កាលៗ (Multi-step) និងការផ្ទៀងផ្ទាត់ទិន្នន័យជាជំហានៗដោយប្រើ trigger()។*
- **Lesson 07**: Reusable RHF Field Components - *ការភ្ជាប់ Custom UI Widgets (ដូចជា Radix Select, DatePicker, Switch) ទៅកាន់ React Hook Form តាមរយៈ Component Controller។*
