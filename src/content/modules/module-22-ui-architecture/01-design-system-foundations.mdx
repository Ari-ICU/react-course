# Design System Foundations

A robust design system standardizes visual language across an entire engineering team using design tokens for colors, spacing, radius, and elevation.

### Key Concepts & Rules:

- HSL color variables enable effortless theme swapping (Dark/Light mode).
- Semantic color naming (`primary`, `muted`, `accent`, `destructive`).

### Code Example: CSS Variable Design Tokens

```jsx
:root {
  --background: 222.2 84% 4.9%;
  --foreground: 210 40% 98%;
  --primary: 217.2 91.2% 59.8%;
  --destructive: 0 62.8% 30.6%;
}
```
