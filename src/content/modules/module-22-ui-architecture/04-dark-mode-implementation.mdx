# Dark Mode Implementation

Toggle a `.dark` class on the root `<html>` element. Tailwind's `dark:` variant automatically updates all colors seamlessly.

### Key Concepts & Rules:

- Persist theme in `localStorage` and detect `prefers-color-scheme`.

### Code Example: Dark Mode Class Toggle

```tsx
export function toggleDarkMode() {
  const isDark = document.documentElement.classList.toggle('dark');
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
}
```
