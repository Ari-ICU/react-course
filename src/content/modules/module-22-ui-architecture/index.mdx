# Module 22: UI Architecture

Design systems, Shadcn UI architecture, component variants with CVA, layout systems, skeleton loaders, and dark mode.

## Module Syllabus (5 Lessons)

- **Lesson 01**: Design System Foundations - *Color tokens, typography scales, spacing, and CSS variables.*
- **Lesson 02**: Component Variants with CVA - *Managing component style permutations cleanly.*
- **Lesson 03**: Responsive UI Architecture - *Mobile-first layouts with Tailwind breakpoints.*
- **Lesson 04**: Dark Mode Implementation - *CSS class-based dark mode toggling with system preference detection.*
- **Lesson 05**: Accessibility (a11y) - *Color contrast, screen readers, semantic tags, and keyboard focus.*
