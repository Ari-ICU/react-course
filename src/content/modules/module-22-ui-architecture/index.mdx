# Module 22: UI Architecture

ស្ថាបត្យកម្ម Design System, រចនាសម្ព័ន្ធបែប Shadcn UI, Component Variants ជាមួយ CVA, Responsive Layout Systems, Dark Mode Implementation, និង Accessibility (a11y)។

## Module Syllabus (5 Lessons)

- **Lesson 01**: Design System Foundations - *ការកំណត់ Design Tokens (Colors, Spacing, Typography, Radius) និងការប្រើប្រាស់ CSS Variables សម្រាប់ Design System ទាំងមូល។*
- **Lesson 02**: Component Variants with CVA - *ការគ្រប់គ្រង Style Permutations នៃ Component (Sizes, Variants, States) ដោយស្អាត និងមាន Type-Safety ជាមួយ Class Variance Authority (CVA)។*
- **Lesson 03**: Responsive UI Architecture - *ការរចនា Layout បែប Mobile-First ដោយប្រើប្រាស់ Tailwind Breakpoints (sm, md, lg, xl)។*
- **Lesson 04**: Dark Mode Implementation - *ការបង្កើតមុខងារ Dark Mode តាមរយៈ CSS Class (.dark), ការរក្សាទុកក្នុង localStorage, និងការចាប់យក System Preference។*
- **Lesson 05**: Accessibility (a11y) - *ការបង្កើត UI ដែលគាំទ្រ Accessibility (A11y) រួមមាន Color Contrast, Screen Readers, Semantic HTML Tags, និង Keyboard Focus Rings។*
