# Path Aliases

ការប្រើប្រាស់ Relative Paths ដ៏វែងអន្លាយដូចជា `import { Button } from '../../../../components/ui/button'` មិនត្រឹមតែមើលទៅច្របូកច្របល់ប៉ុណ្ណោះទេ ប៉ុន្តែវាងាយនឹងបណ្តាលឱ្យខូច (Broken Imports) យ៉ាងខ្លាំងនៅពេលអ្នកផ្លាស់ប្តូរទីតាំងឯកសារ។ តាមរយៈការកំណត់ **Path Aliases** (`@/*`) នៅក្នុង `tsconfig.json` យើងអាច Import ពី Root `src/` ដោយផ្ទាល់ពីគ្រប់ទីកន្លែង។

### Key Concepts & Rules:

- កំណត់ `baseUrl: "."` និង `paths: { "@/*": ["./src/*"] }` ក្នុង `tsconfig.json`។
- ជួយឱ្យការ Refactor ឬចម្លងកូដរវាង Folders មានភាពរលូន និងគ្មានកំហុស។
- អាចកំណត់ Aliases បន្ថែមដូចជា `@components/*` ឬ `@features/*` តាមការចង់បាន។

### Code Example: Path Alias tsconfig Configuration

```json
// tsconfig.json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"],
      "@components/*": ["./src/components/*"],
      "@features/*": ["./src/features/*"]
    }
  }
}

// របៀប Import ស្អាត និងមានរបៀប៖
// import { Button } from '@/components/ui/button';
// import { useAuth } from '@/features/auth';
```
