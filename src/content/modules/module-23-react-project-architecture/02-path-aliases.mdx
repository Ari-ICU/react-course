# Path Aliases

Configure `@/*` in `tsconfig.json` so you never write `../../../../components/ui/button` again.

### Key Concepts & Rules:

- Makes copying and moving files between folders painless.

### Code Example: Path Alias tsconfig Configuration

```tsx
// tsconfig.json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```
