# Configuration Hygiene

Enforce strict TypeScript (`strict: true`) and automated lint rules to prevent bugs before code hits pull requests.

### Key Concepts & Rules:

- Enforce consistent code style across engineering teams.

### Code Example: Strict TypeScript Configuration

```tsx
// tsconfig.json
"compilerOptions": {
  "strict": true,
  "noUncheckedIndexedAccess": true
}
```
