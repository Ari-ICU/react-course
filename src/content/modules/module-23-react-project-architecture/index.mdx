# Module 23: React Project Architecture

រចនាសម្ព័ន្ធ Folder ដែលអាចពង្រីកបាន (Scalable Folder Structures), ស្ថាបត្យកម្ម Feature-based, Shared Services, ការរៀបចំ Types, Path Aliases (@/), និងស្តង់ដារ Configuration Hygiene។

## Module Syllabus (3 Lessons)

- **Lesson 01**: Feature-Based Architecture - *ការរៀបចំរចនាសម្ព័ន្ធកម្មវិធីតាម Business Domain (Features) ជំនួសឱ្យការបែងចែកតាមប្រភេទឯកសារបច្ចេកទេស (File Types)។*
- **Lesson 02**: Path Aliases - *ការលុបបំបាត់ Relative Paths ដ៏វែងអន្លាយ (`../../../../`) តាមរយៈការកំណត់ Path Aliases `@/*` ក្នុង tsconfig.json។*
- **Lesson 03**: Configuration Hygiene - *ការកំណត់ស្តង់ដារ TypeScript Strict Mode, ESLint, Prettier, និង Environment Variables ដើម្បីទប់ស្កាត់ Bugs មុនពេល Push កូដ។*
