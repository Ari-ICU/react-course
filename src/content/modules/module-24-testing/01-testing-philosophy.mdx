# Testing Philosophy

គោលការណ៍ស្នូលនៃការធ្វើតេស្តកម្មវិធី React ទំនើប គឺការធ្វើតេស្តលើកម្មវិធីរបស់អ្នកតាមរបៀបដែលអ្នកប្រើប្រាស់ពិតប្រាកដប្រាស្រ័យទាក់ទងជាមួយវា។ ជំនួសឱ្យការធ្វើតេស្តលម្អិតលើ Implementation Details (ដូចជា ឈ្មោះ State ឬឈ្មោះ Internal Methods ដែលងាយនឹងខូចពេល Refactor) យើងផ្តោតលើអ្វីដែលបង្ហាញនៅលើអេក្រង់ (DOM Output) និងប្រតិកម្មចំពោះសកម្មភាពចុច ឬវាយអក្សររបស់ User។

### Key Concepts & Rules:

- **Unit Tests**: ធ្វើតេស្តលើ Pure Functions, Math Calculations, និង Helper Utilities (លឿនបំផុត)។
- **Component Tests (RTL)**: ធ្វើតេស្តលើការ Render នៃ Component និង User Events ជាមួយ React Testing Library។
- **E2E Tests (Playwright / Cypress)**: ធ្វើតេស្តលើ User Flows ពេញលេញតាំងពីដើមដល់ចប់នៅលើ Real Browser។

### Code Example: Installing Testing Stack

```bash
# ដំឡើង Vitest, React Testing Library, User Event, និង JSDOM
npm install -D vitest @testing-library/react @testing-library/user-event jsdom
```
