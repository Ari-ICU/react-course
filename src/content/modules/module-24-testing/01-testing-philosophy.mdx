# Testing Philosophy

គោលការណ៍ស្នូលនៃការធ្វើតេស្តកម្មវិធី React ទំនើប គឺការធ្វើតេស្តលើកម្មវិធីរបស់អ្នកតាមរបៀបដែលអ្នកប្រើប្រាស់ពិតប្រាកដប្រាស្រ័យទាក់ទងជាមួយវា។ ជំនួសឱ្យការធ្វើតេស្តលម្អិតលើ Implementation Details (ដូចជា ឈ្មោះ State ឬឈ្មោះ Internal Methods ដែលងាយនឹងខូចពេល Refactor) យើងផ្តោតលើអ្វីដែលបង្ហាញនៅលើអេក្រង់ (DOM Output) និងប្រតិកម្មចំពោះសកម្មភាពចុច ឬវាយអក្សររបស់ User។

### Key Concepts & Rules:

- **Unit Tests**: ធ្វើតេស្តលើ Pure Functions, Math Calculations, និង Helper Utilities (លឿនបំផុត)។
- **Component Tests (RTL)**: ធ្វើតេស្តលើការ Render នៃ Component និង User Events ជាមួយ React Testing Library។
- **E2E Tests (Playwright / Cypress)**: ធ្វើតេស្តលើ User Flows ពេញលេញតាំងពីដើមដល់ចប់នៅលើ Real Browser។

### Code Example: Testing User Behavior with RTL

```jsx
// 1. Install: npm install -D vitest @testing-library/react @testing-library/user-event jsdom

import { describe, it, expect } from 'vitest';
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { LoginForm } from './LoginForm';

describe('LoginForm User Experience', () => {
  it('allows user to type credentials and see success greeting', async () => {
    const user = userEvent.setup();
    render(<LoginForm />);

    // Test from user perspective: finding input by accessible label
    const emailInput = screen.getByLabelText(/email address/i);
    const submitBtn = screen.getByRole('button', { name: /log in/i });

    // Simulate real user typing and clicking
    await user.type(emailInput, 'student@reactcourse.com');
    await user.click(submitBtn);

    // Verify DOM updates that the user can actually perceive:
    expect(screen.getByText(/welcome back/i)).toBeInTheDocument();
  });
});
```
