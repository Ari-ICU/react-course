# Mocking API Requests (MSW)

MSW intercepts HTTP requests at the network level, returning mock JSON without modifying component code.

### Key Concepts & Rules:

- Provides highest confidence testing for loading, error, and data states.

### Code Example: Mock Service Worker Server Handler

```tsx
import { http, HttpResponse } from 'msw';
import { setupServer } from 'msw/node';

export const server = setupServer(
  http.get('/api/students', () => {
    return HttpResponse.json([{ id: '1', name: 'Alice', gpa: 3.9 }]);
  })
);
```
