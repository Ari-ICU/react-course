# Mocking API Requests (MSW)

**Mock Service Worker (MSW)** គឺជាបណ្ណាល័យស្តង់ដារមាសសម្រាប់ការក្លែងបន្លំ API (API Mocking) ក្នុងប្រព័ន្ធ Ecosystem នៃ JavaScript។ ជំនួសឱ្យការ Mock អនុគមន៍ `fetch` ឬ `axios` ដោយប្រើ `vi.fn()` ដែលងាយប្រឈមនឹងកំហុស MSW ធ្វើការស្ទាក់ចាប់ HTTP Requests នៅកម្រិត Network Layer ដោយផ្ទាល់ ដែលធ្វើឱ្យកូដតេស្តដំណើរការដូចទៅនឹង Server ពិតប្រាកដ។

### Key Concepts & Rules:

- ស្ទាក់ចាប់ Network Calls ដោយមិនចាំបាច់កែប្រែកូដ Application Code ឡើយ។
- ងាយស្រួលសរសេរតេស្តសាកល្បងករណីជួប Error 500, 404, ឬ Network Timeout។
- ចែករំលែក Mock Handlers ដូចគ្នារវាងការធ្វើ Unit Tests (Node.js) និងការ Develop ក្នុង Browser។

### Code Example: Mock Service Worker Server Handler

```jsx
import { http, HttpResponse } from 'msw';
import { setupServer } from 'msw/node';

// កំណត់ API Handlers សម្រាប់ស្ទាក់ចាប់ Endpoint:
export const server = setupServer(
  http.get('/api/students', () => {
    return HttpResponse.json([
      { id: '1', name: 'សោភា', gpa: 3.9 },
      { id: '2', name: 'រដ្ឋា', gpa: 3.7 },
    ]);
  })
);

// ក្នុង setupTests.ts:
// beforeAll(() => server.listen());
// afterEach(() => server.resetHandlers());
// afterAll(() => server.close());
```
