# Module 24: Testing

ទស្សនវិជ្ជានៃការធ្វើតេស្ត (Testing Philosophy), ការប្រើប្រាស់ Vitest, React Testing Library (RTL), ការធ្វើតេស្តលើ User Interactions, ការ Mocking API Requests តាមរយៈ MSW, និងការរៀបចំរចនាសម្ព័ន្ធ Tests។

## Module Syllabus (3 Lessons)

- **Lesson 01**: Testing Philosophy - *ពីរ៉ាមីតនៃការធ្វើតេស្ត (Testing Pyramid)៖ Unit Tests, Component Integration Tests, និង End-to-End (E2E) Tests។*
- **Lesson 02**: React Testing Library - *ការស្វែងរក Elements តាមរយៈ Role, Label, និង Text ស្របតាមស្តង់ដារ Accessibility និងការសាកល្បង User Events។*
- **Lesson 04**: Mocking API Requests (MSW) - *ការប្រើប្រាស់ Mock Service Worker (MSW) ដើម្បីស្ទាក់ចាប់ និងក្លែងបន្លំ Network Requests យ៉ាងជាក់ស្តែងបំផុត។*
