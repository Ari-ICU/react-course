# React Security Basics

By default, React escapes all strings rendered inside JSX before inserting them into the DOM, neutralizing basic `<script>` injection attacks.

### Key Concepts & Rules:

- Automatic string escaping prevents HTML injection.

### Code Example: Automatic XSS Escaping

```jsx
// If userInput is "<script>alert('hack')</script>",
// React renders it as safe plain text: &lt;script&gt;...
```
