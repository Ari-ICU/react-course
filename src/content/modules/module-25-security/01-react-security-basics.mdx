# React Security Basics

ការវាយប្រហារ **Cross-Site Scripting (XSS)** កើតឡើងនៅពេលដែលជនអនាមិកអាចបញ្ចូលកូដ JavaScript បំពានចូលទៅក្នុងគេហទំព័រ ដើម្បីលួច Session Cookies, Tokens ឬក្លែងបន្លំជា User។ React ត្រូវបានរចនាឡើងជាមួយនឹងប្រព័ន្ធសុវត្ថិភាពដ៏រឹងមាំតាំងពីគ្រឹះ ដោយវាធ្វើការ **Auto-escaping** រាល់ String ទាំងអស់ដែលត្រូវបាន Render ក្នុង JSX មុនពេលបញ្ចូលទៅក្នុង Real DOM។

### Key Concepts & Rules:

- React បំប្លែងតួអក្សរគ្រោះថ្នាក់ (ដូចជា `<`, `>`, `&`, `"`) ទៅជា HTML Entities ដោយស្វ័យប្រវត្តិ។
- ទប់ស្កាត់ការដំណើរការកូដ `<script>alert('hack')</script>` ដែល User បញ្ចូលតាមរយៈ Form។
- មិនត្រូវប្រើ `eval()` ឬបង្កើត HTML តាមរយៈ String Concatenation ឡើយ។

### Code Example: Automatic XSS Escaping

```jsx
import React from 'react';

interface CommentProps {
  author: string;
  commentText: string;
  websiteUrl?: string;
}

export function UserCommentSecurityDemo({ author, commentText, websiteUrl }: CommentProps) {
  // 1. React AUTO-ESCAPES all strings injected into JSX expressions:
  // Even if commentText contains: "<script>stealTokens()</script>" or "<img src=x onerror=alert(1)>"
  // React converts them into safe string text: &lt;script&gt;stealTokens()&lt;/script&gt;
  return (
    <div className="p-4 bg-slate-900 border border-slate-800 rounded-xl space-y-2">
      <div className="flex items-center justify-between">
        <span className="font-bold text-white">{author}</span>
        
        {/* 2. Security best practice: Prevent tab-napping on external links */}
        {websiteUrl && (
          <a
            href={websiteUrl}
            target="_blank"
            rel="noopener noreferrer"
            className="text-xs text-blue-400 hover:underline"
          >
            Website
          </a>
        )}
      </div>

      <p className="text-slate-300 text-sm">{commentText}</p>
    </div>
  );
}
```
