# dangerouslySetInnerHTML

If you must render rich HTML from CMS feeds, ALWAYS sanitize it with `DOMPurify` before passing to `dangerouslySetInnerHTML`.

### Key Concepts & Rules:

- Never pass un-sanitized user input to `dangerouslySetInnerHTML`.

### Code Example: Safe HTML Sanitization with DOMPurify

```jsx
import DOMPurify from 'dompurify';

export function SafeHtml({ rawContent }: { rawContent: string }) {
  const cleanHtml = DOMPurify.sanitize(rawContent);
  return <div dangerouslySetInnerHTML={{ __html: cleanHtml }} />;
}
```
