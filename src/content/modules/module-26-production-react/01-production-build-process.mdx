# Production Build Process

Running `npm run build` generates an optimized static distribution with minified JavaScript, compressed CSS, and stripped development warnings.

### Key Concepts & Rules:

- Build bundles are hashed for immutable browser caching.

### Code Example: Production Build Command

```jsx
npm run build && npm run start
```
