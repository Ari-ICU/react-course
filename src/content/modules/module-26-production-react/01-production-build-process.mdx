# Production Build Process

ដំណើរការ **Production Build** (`npm run build`) គឺជាដំណាក់កាលបំប្លែងកូដ React (JSX, TypeScript, CSS modules) ឱ្យទៅជា Static Assets (HTML, CSS, JavaScript) ដែលត្រូវបាន Optimized ខ្ពស់បំផុត។ នៅដំណាក់កាលនេះ Bundler នឹងលុបចោលរាល់ Development Warnings, ធ្វើ **Minification** (បង្រួមឈ្មោះ Variables និងលុប Whitespace), អនុវត្ត **Tree-shaking** (កាត់ចោលកូដណាដែលមិនដែលត្រូវបានហៅប្រើប្រាស់ - Dead Code Elimination), និងបំបែក Chunk ដោយផ្អែកលើ Route (Code Splitting)។

### Key Concepts & Rules:

- **Minification & Compression**: បង្រួមកូដ JavaScript និង CSS ឱ្យនៅទំហំតូចបំផុត រួមជាមួយការ Enable Gzip/Brotli compression នៅលើ Web Server (Nginx/Cloudflare)។
- **Dead-Code Elimination (Tree-shaking)**: បំបាត់ចោល Modules ឬ Functions ណាដែល Import មកតែមិនដែលប្រើក្នុងកម្មវិធី។
- **Content Hashing**: រាល់ Chunk JS/CSS មានបន្ថែម Unique Hash ក្នុង Filename ដើម្បីការពារកុំឱ្យ Browser សន្សំ Cache ចាស់ពេលមានការ Update កូដថ្មី។
- **Bundle Analyzer**: ប្រើប្រាស់ Tool ដូចជា `rollup-plugin-visualizer` ឬ `@next/bundle-analyzer` ដើម្បីពិនិត្យមើល Dependencies ណាដែលស៊ីទំហំធំខុសប្រក្រតី។

### Code Example: Production Build & Analysis Scripts

```json
{
  "name": "my-enterprise-react-app",
  "scripts": {
    "dev": "vite",
    "build": "tsc -b && vite build",
    "preview": "vite preview",
    "build:analyze": "vite build --mode analyze"
  },
  "dependencies": {
    "react": "^19.0.0",
    "react-dom": "^19.0.0"
  },
  "devDependencies": {
    "@types/react": "^19.0.0",
    "rollup-plugin-visualizer": "^5.14.0",
    "typescript": "^5.7.0",
    "vite": "^6.0.0"
  }
}
```
