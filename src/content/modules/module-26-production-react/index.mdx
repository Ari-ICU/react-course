# Module 26: Production React

ការរៀបចំ Production Build, Error Boundaries ទប់ស្កាត់ White Screen Crash, SEO Metadata, Bundle Optimization, Tree-shaking, និង Pre-flight Production Checklist មុនពេល Deploy គម្រោងទៅកាន់ Cloud។

## Module Syllabus (3 Lessons)

- **Lesson 01**: Production Build Process - *ការធ្វើ Minification, Dead-code elimination, Tree-shaking, និងការបង្រួម Bundle សម្រាប់ Production Deployment។*

- **Lesson 03**: Production Checklist - *បញ្ជីត្រួតពិនិត្យ Pre-flight គ្រប់ជ្រុងជ្រោយ (TypeScript, Linting, SEO, Performance, Caching) មុនពេល Ship ទៅ Production។*
