# Module 27: Real-World Projects

គម្រោងអនុវត្តផ្ទាល់ជាក់ស្ដែងកម្រិត Real-World ចំនួន 6 ដែលត្រូវបានរចនាឡើងដើម្បីពង្រឹងជំនាញតាំងពីគ្រឹះរហូតដល់កម្រិត Enterprise Architecture៖ Todo App, Student Management System, Product Dashboard, Auth Portal, E-Commerce Storefront, និង Final Capstone Enterprise Application។

## Module Syllabus (6 Lessons)

- **Lesson 01**: Project 01: Todo Management App - *កម្មវិធីគ្រប់គ្រងកិច្ចការងារជាមួយ localStorage persistence, dynamic filtering, និង search។*
- **Lesson 02**: Project 02: Student Management System - *ផ្ទាំង Admin CRUD ពេញលេញសម្រាប់គ្រប់គ្រងទិន្នន័យសិស្ស ជាមួយ Pagination និង Form Validation ច្រើនកម្រិត។*
- **Lesson 03**: Project 03: Product Management Dashboard - *ផ្ទាំង Dashboard សន្និធិផលិតផលភ្ជាប់ជាមួយ REST API, Loading Skeletons, និង Inventory Metrics។*
- **Lesson 04**: Project 04: Authentication Dashboard - *ប្រព័ន្ធគ្រប់គ្រងសិទ្ធិ Role-Based Access Control (RBAC) ជាមួយ JWT Tokens, Refresh Interceptor, និង Protected Routes។*
- **Lesson 05**: Project 05: E-Commerce Frontend - *ហាងទំនិញ Online ពេញលេញជាមួយ Zustand Cart Store, Wishlist, និង Multi-step Checkout Pipeline។*
- **Lesson 06**: Project 06: Final Capstone Application - *កម្មវិធី Full-Scale Enterprise React កម្រិតកំពូលដែលរួមបញ្ចូលចំណេះដឹងពី Module 01 ដល់ Module 26 ទាំងអស់។*
